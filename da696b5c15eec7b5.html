12. JavaSE 第一阶段实战项目：学生管理系统

按章节学习你的知识，慢慢成林

知识框架

text
学生管理系统
├── 项目介绍
│   └── 对数组中学生对象进行增删改查操作
├── 功能模块
│   ├── 添加学生
│   ├── 查看所有学生（含排序）
│   ├── 修改学生信息
│   ├── 删除学生
│   └── 退出系统
└── 代码结构（4个类）
    ├── Student.java          → 数据模型（JavaBean）
    ├── ArrayUtils.java       → 工具类（通过id查索引）
    ├── StudentView.java      → 操作页面（菜单+功能方法）
    └── Test01.java           → 程序入口（启动）

生活类比：
把这个项目想象成学校的"学生花名册"。花名册是一个固定大小的表格（数组），你可以往里面写人（添加）、查人（查看）、改人（修改）、划掉人（删除）。JavaBean 就是每一条学生信息的"格式模板"，工具类就是"专门帮你找人的助手"。

核心概念

1. JavaBean（数据模型）

JavaBean 是一种规范的 Java 类，用于封装数据。特点：

  • 所有成员变量用 private 修饰（封装）
  • 提供无参构造方法和有参构造方法
  • 为每个成员变量提供 get / set 方法

类比： JavaBean 就像一张"学生信息登记表"，表上有编号、姓名、年龄、性别这几个空格，每个空格都有对应的读写接口。

2. 数组存储对象

本项目使用 Student[] 数组存储学生对象，数组长度固定为 50，代表班级最多放 50 名学生。用 count 变量记录当前实际存储的学生数量。

注意： 不能直接遍历全部 50 个位置，因为没存对象的位置是 null，调用 get 方法会报空指针异常（NullPointerException）。应只遍历 count 次。

3. System.arraycopy（数组复制）

删除数组中某个元素时，由于数组定长，不能直接移除，需要借助新数组，将被删除元素前后的数据分两段复制到新数组中。

text
原数组: [A, B, C, D, E]  → 删除 C（索引2）
前半段: [A, B]           → 复制到新数组的 0~1
后半段: [D, E]           → 复制到新数组的 2~3
新数组: [A, B, D, E]

4. 工具类（ArrayUtils）

工具类的构造方法是 private 的，防止外部 new 对象。工具类中的方法都是 static 的，可以直接用类名调用。核心方法是 findIndexById，根据学号找到该学生在数组中的索引位置。

3.3 操作页面 — StudentView.java（菜单 + 骨架）

public class StudentView {
    /*
     * 将 Scanner 对象提升到成员变量位置
     * 原因：后面多个方法都要键盘录入，如果每次都 new Scanner，会重复创建对象
     * 放到成员变量，整个类共用同一个 Scanner 即可
     */
    Scanner sc = new Scanner(System.in);

    /*
     * 定义老数组，长度 50，表示班级最多存 50 名学生
     * 放到成员变量，所有方法都可以访问这个数组
     */
    Student[] students = new Student[50];

    /*
     * count：记录数组中实际存储的学生数量
     * 初始值为 0，每添加一个学生就 +1，删除一个就 -1
     * 避免遍历时访问到 null 对象（防止空指针异常）
     */
    int count = 0;

    /*
     * 新数组（删除时使用）：长度比老数组小 1
     * 原因：数组定长，删除元素需要创建新数组
     * 由于一次只删一个，新数组长度 = 老数组长度 - 1
     */
    Student[] newStudents = new Student[students.length - 1];

    /*
     * start() 方法：展示主菜单，根据用户输入调用对应功能
     * 用 while(true) 循环，使系统持续运行直到用户选择退出
     */
    public void start() {
        while (true) { // 死循环，保持系统一直运行
            System.out.println("-----------学生管理系统-----------");
            System.out.println("1 添加学生");
            System.out.println("2 修改学生");
            System.out.println("3 删除学生");
            System.out.println("4 查看学生");
            System.out.println("5 退出系统");
            System.out.println("请选择(1-5):");

            int num = sc.nextInt(); // 接收用户输入的菜单选项
            System.out.println("--------------------------------");

            switch (num) { // 根据选项跳转到对应功能
                case 1:
                    addStudent();    // 调用添加方法
                    break;
                case 2:
                    updateStudent(); // 调用修改方法
                    break;
                case 3:
                    deleteStudent(); // 调用删除方法
                    break;
                case 4:
                    findAllStudent(); // 调用查看方法
                    break;
                case 5:
                    System.out.println("是否退出?按0为退出/按9为取消");
                    int key = sc.nextInt(); // 接收用户的确认选择
                    if (key == 0) {
                        System.out.println("再见,欢迎再来");
                        return; // return 结束 start() 方法，程序退出
                    } else if (key == 9) {
                        break; // break 只是跳出 switch，回到 while 继续循环
                    }
            }
        }
    }

    // 以下为各功能方法，详见 3.5 ~ 3.8
    private void findAllStudent() { }
    private void deleteStudent()  { }
    private void updateStudent()  { }
    private void addStudent()     { }
}

3.4 工具类 — ArrayUtils.java

java
public class ArrayUtils {
    // 私有构造方法：防止外部通过 new ArrayUtils() 创建对象
    // 工具类不需要实例，所有方法都是 static 的，直接用类名调用
    private ArrayUtils() {
    }

    /**
     * 根据学号在数组中找到对应的索引位置
     *
     * @param students 学生数组
     * @param id       要查找的学号
     * @param count    数组中实际存储的学生数量（防止遍历到 null）
     * @return 找到则返回索引，找不到则返回 -1
     */
    public static int findIndexById(Student[] students, int id, int count) {
        // 只遍历 count 次，避免访问 null 位置
        for (int i = 0; i < count; i++) {
            // 比较每个学生的 id 是否与目标 id 相等
            if (id == students[i].getId()) {
                return i; // 找到了，返回当前索引
            }
        }
        return -1; // 遍历完没找到，返回 -1 表示不存在
    }
}

3.5 添加功能 — addStudent()

private void addStudent() {
    // 第一步：键盘录入学生信息
    System.out.println("请您输入学生学号:");
    int id = sc.nextInt();         // 读取学号（整数）

    System.out.println("请您输入学生姓名:");
    String name = sc.next();       // 读取姓名（字符串，遇到空格停止）

    System.out.println("请您输入学生年龄:");
    int age = sc.nextInt();        // 读取年龄（整数）

    System.out.println("请您输入学生性别:");
    String sex = sc.next();        // 读取性别（字符串）

    // 第二步：将录入的信息封装成 Student 对象
    Student student = new Student(id, name, age, sex);

    // 第三步：将 Student 对象放到数组中
    // students[count] 表示当前"第一个空位置"，因为 count 从 0 开始
    students[count] = student;

    // 第四步：count 自增，记录新增了一个学生
    count++;

    System.out.println("添加成功!!!");
}

说明： 添加逻辑就是"往花名册下一个空行填数据"。count 既代表"当前空位索引"，也代表"已存多少人"，非常巧妙。

3.6 查看功能 — findAllStudent()

java
private void findAllStudent() {
    // 打印表头
    System.out.println("学号" + "\t" + "姓名" + "\t" + "年龄" + "\t" + "性别");

    /*
     * 冒泡排序：按学号从小到大排列
     * 目的：防止删除某个学生后再重新添加同学号的学生时出现顺序混乱
     * 外层循环控制排序轮数，内层循环控制每轮比较次数
     */
    for (int j = 0; j < count - 1; j++) {           // 外层：共 count-1 轮
        for (int i = 0; i < count - 1 - j; i++) {   // 内层：每轮减少一次比较
            // 相邻两个学生的学号比较，如果前面的大于后面的，就交换位置
            if (students[i].getId() > students[i + 1].getId()) {
                Student temp = students[i];          // 临时变量保存前者
                students[i] = students[i + 1];       // 前者换成后者
                students[i + 1] = temp;              // 后者换成原来的前者
            }
        }
    }

    // 判断 count 是否为 0（即班级中没有任何学生）
    if (count == 0) {
        System.out.println("对不起,现在班级没有学生,待开班.........");
    } else {
        // count 是几就遍历几次，避免访问到数组中值为 null 的位置
        for (int i = 0; i < count; i++) {
            // 格式化输出每个学生的信息（\t 是制表符，用于对齐列）
            System.out.println(
                students[i].getId()   + "\t" +
                students[i].getName() + "\t" +
                students[i].getAge()  + "\t" +
                students[i].getSex()
            );
        }
    }
}

3.7 修改功能 — updateStudent()

java
private void updateStudent() {
    // 第一步：录入要修改的学生学号
    System.out.println("请您输入要修改的学生学号:");
    int id = sc.nextInt();

    /*
     * 第二步：注意！不能直接用 id 当索引来存储新学生对象
     * 原因：id（学号）和学生在数组中的索引不一定相同
     *       例如：学号为 1003 的学生，可能存在数组的第 2 个位置（索引 1）
     * 解决：通过工具类 ArrayUtils 的 findIndexById 方法，根据 id 查找实际索引
     */
    int updateIndex = ArrayUtils.findIndexById(students, id, count);

    // 第三步：录入修改后的新信息
    System.out.println("请您输入学生姓名:");
    String name = sc.next();

    System.out.println("请您输入学生年龄:");
    int age = sc.nextInt();

    System.out.println("请您输入学生性别:");
    String sex = sc.next();

    // 第四步：用新信息创建新的 Student 对象（id 不变，其他信息用新输入的）
    Student student = new Student(id, name, age, sex);

    // 第五步：用新对象替换数组中原来位置的旧对象
    students[updateIndex] = student;

    System.out.println("修改成功!!!");
}

说明： 修改本质是"把旧档案撕掉，换上一份新档案"，但位置不变（索引不变）。

3.8 删除功能 — deleteStudent()

[图示：删除操作的数组复制示意图 —— 被删除元素前后各一段，分两次复制到新数组中]

java
private void deleteStudent() {
    // 第一步：录入要删除的学生学号
    System.out.println("请您输入要删除的学生学号:");
    int id = sc.nextInt();

    // 第二步：通过工具类根据 id 查找该学生在数组中的索引位置
    int removeIndex = ArrayUtils.findIndexById(students, id, count);

    /*
     * 第三步：用 System.arraycopy 分两段将数据复制到新数组
     *
     * System.arraycopy(源数组, 源起始位置, 目标数组, 目标起始位置, 复制长度)
     *
     * 第一次：复制被删除元素"前面"的部分
     *   从 students 的 0 位置开始，复制 removeIndex 个元素到 newStudents 的 0 位置
     */
    System.arraycopy(students, 0, newStudents, 0, removeIndex);

    /*
     * 第二次：复制被删除元素"后面"的部分
     *   从 students 的 removeIndex+1 位置开始（跳过被删的那个）
     *   复制到 newStudents 的 removeIndex 位置
     *   复制长度 = 总长度 - 被删位置 - 1（即剩余元素个数）
     */
    System.arraycopy(students, removeIndex + 1, newStudents, removeIndex,
                     students.length - removeIndex - 1);

    // 第四步：将新数组的引用赋给老数组变量（让 students 指向新数组）
    students = newStudents;

    // 第五步：count 自减，记录学生数量减少了一个
    count--;

    System.out.println("删除成功");
}

说明： 因为数组是定长的（不像 ArrayList 可以自动缩容），删除操作需要"另起炉灶"创建新数组，把保留的数据搬过去。

常见报错与解决方法

1. NullPointerException（空指针异常）

出现场景： 遍历学生数组时用了 i < students.length（50）而不是 i < count，访问到了空位置，调用 .getId() 等方法时报错。

text
Exception in thread "main" java.lang.NullPointerException
    at StudentView.findAllStudent(StudentView.java:xx)

解决方法： 把循环条件改成 i < count，只遍历有实际数据的位置。

2. ArrayIndexOutOfBoundsException（数组越界）

出现场景 1： 添加学生时超过了数组容量（count >= 50）。

text
Exception in thread "main" java.lang.ArrayIndexOutOfBoundsException: Index 50 out of bounds for length 50

解决方法： 添加前先判断 if (count < students.length)，满了就提示"班级已满"。

出现场景 2： System.arraycopy 的长度参数计算错误，超出了目标数组范围。

解决方法： 仔细检查复制长度计算公式 students.length - removeIndex - 1。

3. 删除后再添加出现乱序

出现场景： 删了学号 2 的学生，又添加了一个新学生（比如学号 1），查看时新学生显示在列表末尾，顺序乱了。

解决方法： 查看功能中加入冒泡排序，每次查看前先按学号排序（代码中已有实现）。

4. 修改/删除时找不到学号（返回 -1）

出现场景： 输入的学号不存在，findIndexById 返回 -1，之后用 -1 作为索引会抛 ArrayIndexOutOfBoundsException。

解决方法： 拿到 index 后先判断是否为 -1：

java
int updateIndex = ArrayUtils.findIndexById(students, id, count);
if (updateIndex == -1) {
    System.out.println("没有找到该学号的学生，请重新输入！");
    return; // 或 continue
}

5. sc.nextInt() 和 sc.next() 混用导致换行符残留

出现场景： sc.nextInt() 读完数字后，回车符（\n）留在缓冲区。下一次调用 sc.next() 读字符串时，直接读到了空白，导致姓名/性别没有正常录入。

解决方法： 在 nextInt() 后加一行 sc.nextLine() 消耗掉残留的换行符，然后改用 sc.nextLine() 读取字符串：

java
int id = sc.nextInt();
sc.nextLine(); // 消耗残留换行符
String name = sc.nextLine(); // 改用 nextLine 读取完整字符串

面试常问

Q1：JavaBean 的规范是什么？为什么成员变量要用 private？

JavaBean 规范：私有成员变量 + 无参构造 + getter/setter 方法。private 是封装的体现，外部无法直接访问字段，只能通过 get/set 方法，方便后续在 setter 中加入数据校验逻辑（比如年龄不能为负数）。

Q2：项目中为什么不用 ArrayList 而用数组？

这是 JavaSE 第一阶段的练习项目，目的是熟悉数组操作（增删改查、System.arraycopy 等）的底层原理。ArrayList 的底层本质也是数组，理解了数组操作才能更好地理解集合框架。实际开发中优先用 ArrayList。

Q3：System.arraycopy 和 Arrays.copyOf 有什么区别？

  • System.arraycopy：是 native 方法，可以精确控制源和目标的起始位置与复制长度，灵活但写法稍繁琐。
  • Arrays.copyOf：内部调用 System.arraycopy，只能从 0 开始复制，自动扩容（多出来的位置为默认值），写法更简洁。
  • 本项目删除功能需要分段复制（前半段 + 后半段），所以必须用 System.arraycopy。

Q4：工具类的构造方法为什么要用 private 修饰？

工具类中所有方法都是 static 的，不需要创建实例就能调用。私有构造方法能防止外部通过 new ArrayUtils() 创建无意义的对象，是一种良好的编程规范（例如 Java 标准库中的 Math 类也是这样做的）。

Q5：while(true) 中的 return 和 break 有什么区别？

  • break：只跳出当前层的循环或 switch，对外层结构无影响。如果 break 写在 switch 里，只是退出 switch，while 还在继续。
  • return：结束整个方法的执行，直接返回调用处。在 start() 中用 return 可以彻底结束系统。

Q6：这个项目用数组存储对象有什么局限性？如何改进？

局限性：

  1. 容量固定（最多 50 人），无法动态扩展
  2. 删除操作需要创建新数组，比较麻烦
  3. 数据不能持久化（程序关闭后数据丢失）

改进方向：

  1. 用 ArrayList<Student> 替代数组，解决容量限制和删除麻烦的问题
  2. 加入 id 重复校验（添加时检查学号是否已存在）
  3. 加入文件读写（IO 流）或数据库（JDBC）实现数据持久化
