01 快速入门：starter、容器与自动配置

约 2 分钟阅读你的知识，慢慢成林

原文：第2—27页。优先级：必学。前置：Java对象、接口、异常，Maven基本概念。

Spring Boot像一套已经配好常用工具的工作台：starter帮你引入一组相关依赖，自动配置根据当前条件提供默认组件，配置文件用来调整参数。边界：它不会替你编写业务，也不是导入一个starter所有场景都会无条件生效。

最短闭环：建立与课程相同依赖版本的工程 → 创建主启动类 → 写一个Controller → 启动 → 浏览器访问 → 打包运行。先验证HTTP接口能通，再深入自动配置源码。

java
// 放在主程序扫描包内；工程需有web starter
@RestController
class HelloController {
    @GetMapping("/hello")
    String hello() { return "Hello, Spring Boot"; }
}

请求链是“浏览器 → 嵌入式服务器 → Spring MVC → 你的方法 → 响应”。@RestController让返回值作为响应内容处理；普通@Controller返回字符串时通常涉及视图解析。默认扫描范围与主程序包位置有关，扫描不到Controller会导致映射不存在。

配置先掌握端口、YAML层级、配置绑定、日志级别。日志不是越多越好：用能定位问题的信息记录行为，不能把密码和令牌写进去。练习：新增/hello?name=小林并接收参数；改变端口后解释原地址为何失效。验收：能区分启动失败、404和方法内部异常。
