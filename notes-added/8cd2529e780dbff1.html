二、第一章 类与对象

2.1 面向过程 vs 面向对象

对比项 面向过程 面向对象
代表语言 C Java
核心思想 自己的事情自己干 自己的事情找别人干
生活类比 手洗衣服（找盆、放水、搓搓搓） 全自动洗衣机（按一下按钮）
优点 控制力强 代码复用，减少重复工作

通俗理解： 面向对象就是"懒人编程"。很多功能别人（Java 官方、第三方库）都已经实现好了，我们只需要找来对应的对象，直接调用就好，不需要关心它内部是怎么实现的。

什么时候用面向对象： 在一个类中，想使用另一个类的成员（变量或方法）时，就用面向对象思想编程。

怎么用：

  • 普通成员：new 对象名() 然后 . 点出成员
  • 带 static 的成员：直接用 类名.成员 调用，不需要 new

2.2 面向对象初体验 — 代码示例

下面这段代码演示了"找对象、用功能"的核心思路：Scanner 录入字符串、Random 生成随机数、Arrays 打印数组，我们都不需要关心它们内部怎么实现，直接 new 对象、调方法就行。

java
public class Demo01Object {
    public static void main(String[] args) {
        // 需求1: 使用 Scanner 录入字符串
        // sc 就是找来的对象, next() 是它实现好的功能
        Scanner sc = new Scanner(System.in);  // 创建 Scanner 对象, 绑定键盘输入
        String data = sc.next();               // 调用 next() 方法, 等待用户输入并返回字符串
        System.out.println("data = " + data); // 打印输入的内容

        System.out.println("===================================");

        // 需求2: 使用 Random 生成随机整数
        // rd 就是找来的对象, nextInt() 是它实现好的功能
        Random rd = new Random();              // 创建 Random 对象
        int data2 = rd.nextInt();               // 调用 nextInt() 方法, 生成一个随机整数
        System.out.println("data2 = " + data2); // 打印随机数

        System.out.println("====================================");

        // 需求3: 使用 Arrays 把数组转成 [1, 2, 3, 4] 这种格式打印
        int[] arr = {1, 2, 3, 4};                // 定义一个数组
        // Arrays.toString 会把数组元素拼成字符串返回, 无需自己写 for 循环
        System.out.println(Arrays.toString(arr)); // 输出: [1, 2, 3, 4]
    }
}

生活类比： 就像你去餐厅吃饭。你不需要自己种菜、洗菜、炒菜（面向过程），你只需要跟服务员说"来一份宫保鸡丁"（调用方法），后厨怎么做的你不关心，你只管吃（拿结果）就行。Scanner、Random、Arrays 就是 Java 提供的"后厨"。

2.3 类的定义

类的分类：

  • 测试类：带 main 方法的类，专门用来运行和测试代码
  • 实体类：一类事物的抽象表示，比如人类、狗类、猫类、手机类

实体类的组成部分：

组成 名称 定义位置 定义格式 默认值
属性 成员变量 类中方法外 数据类型 变量名 整数 0, 小数 0.0, 字符 '\u0000', 布尔 false, 引用 null
行为 成员方法 类中 修饰符 返回值类型 方法名(参数){...} —

注意： 成员方法和之前学的方法唯一区别就是——把 static 去掉。其他格式完全一样。

类定义图解（文字版）：

text
public class 类名 {
    // ↓ 属性（成员变量）—— 这类事物"有什么"
    数据类型 变量名1;
    数据类型 变量名2;

    // ↓ 行为（成员方法）—— 这类事物"能做什么"
    public 返回值类型 方法名1(参数) {
        方法体
    }
    public 返回值类型 方法名2(参数) {
        方法体
    }
}

2.5 对象的创建与使用

使用三步骤：

  1. 导包： import 包名.类名;

    • 同一个包下不需要导包
    • 不同包下需要导包
    • java.lang 包下的类（如 String）不需要导包
    • 初学阶段建议把类放在同一个包下，避免导包问题

  2. 创建对象： 类名 对象名 = new 类名();

    • 例如：Person person = new Person();

  3. 调用成员： 对象名.成员

    • 赋值：对象名.成员变量名 = 值;
    • 调用无参无返回值方法：对象名.方法名();
    • 调用有参无返回值方法：对象名.方法名(实参);
    • 调用无参有返回值方法：数据类型 变量名 = 对象名.方法名();
    • 调用有参有返回值方法：数据类型 变量名 = 对象名.方法名(实参);

对象使用 — 代码示例：

java
public class Demo01Person {
    public static void main(String[] args) {
        // 第一步: 创建 Person 对象
        Person person = new Person();  // new 关键字在堆内存中创建对象, 赋地址给 person 变量

        // 第二步: 先看默认值
        System.out.println(person.name);  // 输出: null (引用类型默认值)
        System.out.println(person.age);   // 输出: 0 (整数默认值)

        // 第三步: 为属性赋值
        person.name = "金莲";  // 给 name 属性赋值
        person.age = 26;       // 给 age 属性赋值

        // 第四步: 再次打印, 值已改变
        System.out.println(person.name);  // 输出: 金莲
        System.out.println(person.age);   // 输出: 26

        // 第五步: 调用成员方法
        person.eat();   // 输出: 人要干饭
        person.drink(); // 输出: 人要喝水
    }
}

2.7 匿名对象

什么是匿名对象： 只有等号右边的部分（new 出来的对象），没有等号左边的部分（没有变量名接收）。

理解：

text
int i = 10
// int 是数据类型, i 是变量名, 10 是真正的数据
Person p = new Person()
// Person 是类型, p 是对象名, new Person() 是真正的对象
// 匿名对象 = 直接用 new Person(), 不用 p 接收

使用格式： new 类名().成员

注意事项：

  • 只想单纯调用一个方法让方法执行时，可以考虑用匿名对象
  • 涉及到赋值，千万不要用匿名对象（因为每次 new 都是不同对象）

代码示例：

java
public class Person {
    String name;
    public void eat() {
        System.out.println("人要吃饭");
    }
}

public class Demo01Person {
    public static void main(String[] args) {
        // 原始方式: 有变量名 p 接收
        Person p = new Person();  // 创建对象, 用 p 保存地址
        p.name = "金莲";           // 通过 p 给 name 赋值
        System.out.println(p.name); // 通过 p 取值, 输出: 金莲
        p.eat();                   // 通过 p 调用方法, 输出: 人要吃饭

        System.out.println("=================");

        // 匿名对象方式: 没有变量名
        new Person().eat();  // 直接创建对象并调用方法, 输出: 人要吃饭

        new Person().name = "大郎";          // 给匿名对象的 name 赋值
        System.out.println(new Person().name); // 又 new 了一个新对象, name 是默认值 null
        // 原因: 两次 new 是两个不同的对象, 互不相干
    }
}

常见误区： 初学者以为 new Person().name = "大郎" 赋值后，后面的 new Person().name 能取到 "大郎"。其实两次 new Person() 是两个完全不同的对象，第二次 new 出来的 name 还是默认值 null。

2.8 对象内存图分析

由于没有图片，用文字详细说明内存分析过程。

2.8.1 一个对象的内存图

以 Person person = new Person(); person.name = "金莲"; person.eat(); 为例：

  1. 方法区：加载 Person.class 字节码文件，包含类的成员变量和方法信息
  2. 栈内存：main 方法进栈，声明 person 局部变量（存的是堆中的地址值）
  3. 堆内存：new Person() 在堆中开辟空间，存成员变量（name=null, age=0），并产生一个地址值（假设是 0x001）
  4. person.name = "金莲"：通过 person 的地址 0x001 找到堆中的空间，把 name 改成 "金莲"
  5. person.eat()：通过地址找到 eat 方法，eat 方法进栈执行，执行完弹栈

2.8.2 两个对象的内存图

以 Phone phone1 = new Phone(); Phone phone2 = new Phone(); 为例：

  • phone1 和 phone2 各自 new 出来，在堆内存中产生了两个不同的空间
  • 改变一个空间的数据不会影响另一个空间的数据
  • 就像两套独立的房子，各住各的，互不干扰

2.8.3 两个对象指向同一片空间

以 Phone phone1 = new Phone(); Phone phone2 = phone1; 为例：

  • phone2 = phone1 是把 phone1 保存的地址值赋给了 phone2
  • 此时 phone1 和 phone2 地址值相同，指向堆内存中的同一片空间
  • 操作的是同一片空间的数据，改变一个对象的数据会影响另一个对象
  • 就像两个人拿着同一把钥匙开同一个门，谁进去改了家具，另一个人再进去看到的也是改过的

三、第二章 成员变量与局部变量的区别

这是面试和笔试的高频考点，务必牢记五大区别。

3.1 五大区别总览

区别项 成员变量 局部变量 重要程度
1. 定义位置 类中方法外 方法中或参数位置 重点
2. 初始化值 有默认值，可直接使用 没有默认值，必须先赋值再使用 重点
3. 作用范围 作用于整个类 只作用于所在方法 重点
4. 内存位置 堆内存（跟着对象走） 栈内存（跟着方法走） 了解
5. 生命周期 随对象创建而产生，随对象消失而消失 随方法调用而产生，随方法结束而消失 了解

3.2 代码示例（逐行注释）

java
public class Person {
    String name;  // 成员变量: 定义在类中方法外, 有默认值 null

    public void eat() {
        int i = 10;  // 局部变量: 定义在方法内部, 必须先赋值再使用
        System.out.println(i);     // 输出: 10

        // 成员变量 name 不用手动赋值可以直接使用, 因为有默认值 null
        System.out.println(name);  // 输出: null
    }

    public void drink() {
        int j;  // 局部变量: 只声明未赋值
        // System.out.println(j);  // 编译报错! 局部变量没有默认值, 必须先赋值再使用
        System.out.println(name);   // 成员变量在所有方法中都能用, 输出: null

        // System.out.println(i);  // 编译报错! i 是 eat 方法的局部变量, 在 drink 中用不了
    }
}

3.3 生活类比

  • 成员变量就像"家里的冰箱"——放在固定位置（类中方法外），里面的东西有默认状态（空冰箱也是冰箱），全家所有人（整个类）都能用
  • 局部变量就像"外卖餐盒"——只在某顿饭（某个方法）中出现，用完就扔，而且必须你自己往里装东西才能吃（先赋值再使用）

3.4 常见报错

text
错误: 可能尚未初始化变量j
  System.out.println(j);
                    ^
原因: 局部变量 j 没有默认值, 必须先赋值再使用
解决: int j = 0; 先赋值, 再使用
text

  System.out.println(i);
                     ^
原因: i 是 eat 方法的局部变量, 在 drink 方法中访问不到

3.5 面试常问

Q1: 成员变量和局部变量有什么区别？

五大区别：定义位置不同（类中方法外 vs 方法内/参数）、初始化值不同（有默认值 vs 无默认值）、作用范围不同（整个类 vs 当前方法）、内存位置不同（堆 vs 栈）、生命周期不同（随对象 vs 随方法）。

Q2: 局部变量为什么不能有默认值？

局部变量在栈内存中，方法执行完就弹栈释放了。如果给默认值，每次方法调用都要初始化，浪费性能。所以 Java 要求开发者手动赋值，确保变量值是明确的。

Q3: 成员变量在堆中，局部变量在栈中，为什么？

成员变量属于对象，对象存在堆中，所以成员变量也在堆中。局部变量属于方法，方法执行在栈中（栈帧），所以局部变量在栈中。

四、第三章 综合练习：Citizen 与 MyDate

4.1 需求

定义一个类 MyDate，属性有 year、month、day。再定义一个类 Citizen（公民类），属性有 name（String 类型）、birthday（MyDate 类型）、idCard（String），为这三个属性赋值，然后将值取出来。

4.2 代码实现

java
// ========== MyDate.java ==========
public class MyDate {
    int year;   // 年, 默认值 0
    int month;  // 月, 默认值 0
    int day;    // 日, 默认值 0
}

// ========== Citizen.java ==========
public class Citizen {
    // 姓名
    String name;  // 默认值 null

    /*
      生日  MyDate 类型
      MyDate 属于自定义类型(引用数据类型)
      这种类型要操作之前必须要赋值
      怎么赋值?  需要new对象赋值
     */
    MyDate birthday = new MyDate(); // 创建 MyDate 对象, 这样 birthday 才有具体的堆内存空间

    // 身份证
    String idCard;  // 默认值 null
}

// ========== Test01.java ==========
public class Test01 {
    public static void main(String[] args) {
        Citizen citizen = new Citizen();  // 创建公民对象
        citizen.name = "涛哥";              // 给 name 赋值
        citizen.idCard = "111111111";      // 给 idCard 赋值

        /*
           citizen.birthday 获取的是 MyDate 对象
           再去点 year 获取的是 MyDate 对象中的 year
           这就是"链式调用"
         */
        citizen.birthday.year = 2000;   // 通过 citizen 找到 birthday(MyDate对象), 再找到 year 赋值
        citizen.birthday.month = 10;   // 同理给 month 赋值
        citizen.birthday.day = 10;     // 同理给 day 赋值

        // 输出: 涛哥,2000,111111111
        System.out.println(citizen.name + "," + citizen.birthday.year + "," + citizen.idCard);
    }
}

核心知识点： 给引用数据类型（自定义类）赋值，需要 new 对象。String 比较特殊，可以直接用 = 赋值。这个"链式调用"的思想（citizen.birthday.year）在后面的开发中非常常见。

五、第四章 封装

5.1 封装思想

面向对象三大特征： 封装、继承、多态。本章讲的是第一个——封装。

什么是封装： 将一个物品封装起来，外界不能直接使用了，提高了物品的安全性。

生活类比：

  • 买来一台洗衣机，我们只需要按按钮（公共接口）就能用，不需要了解里面的电机、电路板怎么运作（隐藏细节）
  • 洗衣机把内部复杂性藏起来，对外提供简单的按钮接口，这就是封装

封装的核心思想：

  1. 把该隐藏的隐藏起来（细节）
  2. 把该暴露的暴露出来（公共接口）
  3. 外界通过公共接口间接使用隐藏起来的细节

封装的体现形式：

  • 将代码放到一个方法中 → 方法本身就是封装的体现
  • 用 private 关键字修饰成员 → 最具代表性的封装

5.2 为什么要用 private

问题： 定义成员变量后，只要是 new 出来的对象，就可以随便调用、随便赋值，哪怕赋不合理的值也挡不住。

java
Person p = new Person();
p.age = -18;  // 年龄给了负数, 不合理但编译能通过!
p.name = "abc123!@#";  // 名字给了乱码, 也不合理

解决： 用 private 关键字将属性私有化。

private 关键字的特点：

  • 被private修饰的成员只能在本类中使用，在别的类中使用不了
  • 修饰成员变量：private 数据类型 变量名;
  • 修饰方法：把 public 改成 private，其他一样

5.3 get/set 方法

问题： 属性被 private 修饰后，外界直接调用不了，也不能直接赋值取值了。所以需要提供公共的接口——get/set 方法。

  • set 方法： 为属性赋值
  • get 方法： 获取属性值

5.4 封装完整代码示例

java
// ========== Person.java ==========
public class Person {
    private String name;  // 属性私有化, 外类不能直接访问
    private int age;     // 属性私有化, 外类不能直接访问

    // 为 name 提供 get/set 方法
    public void setName(String xingMing) {  // set 方法: 接收参数, 为成员变量赋值
        name = xingMing;  // 将参数赋值给成员变量 name
    }

    public String getName() {  // get 方法: 返回成员变量的值
        return name;  // 返回成员变量 name
    }

    // 为 age 提供 get/set 方法
    public void setAge(int nianLing) {  // set 方法: 接收参数, 为成员变量赋值
        if (nianLing < 0 || nianLing > 150) {  // 数据校验: 年龄不合理时
            System.out.println("你脑子是不是秀逗啦!岁数不合理");  // 提示错误
        } else {
            age = nianLing;  // 年龄合理才赋值
        }
    }

    public int getAge() {  // get 方法: 返回成员变量的值
        return age;  // 返回成员变量 age
    }
}

// ========== Test01.java ==========
public class Test01 {
    public static void main(String[] args) {
        Person person = new Person();

        // 以下两行直接访问会报错, 因为 private 修饰了
        // person.name = "涛哥";
        // person.age = -18;

        // 以下两行也直接访问不了
        // System.out.println(person.name);
        // System.out.println(person.age);

        // 正确方式: 通过 set 方法赋值
        person.setName("涛哥");  // 调用 setName 方法, 传入 "涛哥"
        person.setAge(18);       // 调用 setAge 方法, 传入 18

        // 通过 get 方法取值
        String name = person.getName();  // 调用 getName 方法, 接收返回值
        int age = person.getAge();        // 调用 getAge 方法, 接收返回值
        System.out.println(name + "..." + age);  // 输出: 涛哥...18
    }
}

小结：

  • 用 private 将属性封装起来，外界不能直接调用，保护了属性
  • 对外提供一套公共的接口（set/get 方法），让外界通过公共接口间接使用封装起来的属性
  • set 方法中可以加入数据校验逻辑，这是封装最大的价值

text

  person.name = "涛哥";
         ^
原因: name 被 private 修饰, 只能在 Person 类内部访问
解决: 使用 person.setName("涛哥") 代替

5.6 封装面试常问

Q1: 封装的好处是什么？

  1. 提高安全性（可以在 set 方法中加数据校验）
  2. 提高可维护性（内部逻辑变了，外部调用不用改）
  3. 提高可扩展性
  4. 隐藏实现细节，对外只暴露接口

Q2: private 和 public 的区别？

private 修饰的成员只能在本类中访问；public 修饰的成员可以在所有类中访问。

Q3: 为什么要用 set/get 方法而不是直接访问属性？

直接访问属性无法控制赋值的合法性（比如年龄给 -18），而 set 方法可以在赋值前做校验；get 方法可以在取值前做处理（比如脱敏）。

六、第五章 this 关键字

6.1 为什么需要 this

问题场景： 当成员变量和局部变量重名时，Java 遵循"就近原则"，会先访问局部变量。那怎么才能访问到成员变量呢？用 this。

java
public class Person {
    String name;  // 成员变量

    public void speak(String name) {  // 参数也是 name, 和成员变量重名
        // 不加 this: 就近原则, name 代表参数(局部变量)
        // 加 this: this.name 代表成员变量
        System.out.println(this.name + "您好,我是" + name);
    }
}

6.2 this 的本质

  • this 代表的是当前对象
  • 哪个对象调用了 this 所在的方法，this 就代表哪个对象
  • this.成员变量 —— 点出来的一定是成员变量

七、第六章 构造方法

7.1 构造方法概述

  • 概述： 方法名和类名一致并且能初始化对象的方法
  • 分类：
    • 无参构造：没有参数
    • 有参构造：有参数，参数是为指定的属性赋值
    • 满参构造：给所有属性赋值（和有参构造本质一样，记住有参无参即可）
  • 特点：
    • 方法名和类名完全一致
    • 没有返回值，连 void 都没有

7.2 无参构造

格式：

java
public 类名() {
    // 方法体
}

作用： new 对象使用

特点： 每个类中默认都有一个无参构造，不写也有，jvm 会自动提供

使用： 一 new 对象就是在调用构造方法

7.3 有参构造

格式：

java
public 类名(形参) {
    为属性赋值
}

作用：

  • new 对象
  • 为属性赋值（一步到位）

特点： jvm 不会自动提供有参构造。但是，一旦手写了有参构造，jvm 将不再提供无参构造。所以建议有参、无参的构造都手写上去。

7.4 构造方法完整代码示例

java
// ========== Person.java ==========
public class Person {
    private String name;
    private int age;

    // 无参构造
    public Person() {                       // 方法名和类名一致, 没有参数, 没有 void
        System.out.println("我是无参构造");  // new 对象时会执行
    }

    // 有参构造
    public Person(String name, int age) {  // 有两个参数
        this.name = name;  // this.name 是成员变量, name 是参数, 赋值
        this.age = age;     // this.age 是成员变量, age 是参数, 赋值
    }

    // set/get 方法
    public void setName(String name) {
        this.name = name;
    }
    public String getName() {
        return name;
    }
    public void setAge(int age) {
        this.age = age;
    }
    public int getAge() {
        return age;
    }
}

// ========== Test01.java ==========
public class Test01 {
    public static void main(String[] args) {
        // 调用无参构造创建对象
        Person person = new Person();  // 执行无参构造, 输出: 我是无参构造

        // 调用有参构造创建对象, 并同时赋值
        Person person2 = new Person("涛哥", 18);  // 传入两个参数
        System.out.println(person2.getName() + "..." + person2.getAge());  // 输出: 涛哥...18
    }
}

小技巧： 想知道调用的成员是哪个类中的哪个成员？按住 Ctrl 不放，鼠标点击对应的成员，会跳转到定义的位置。

7.5 构造方法常见报错

text
错误: 无法将类 Person中的构造器 Person应用到给定类型
  Person p = new Person();
             ^
原因: 只写了有参构造, 没写无参构造, jvm 不再自动提供无参构造
解决: 手动补写无参构造 public Person() {}

7.6 构造方法面试常问

Q1: 构造方法和普通方法的区别？

  1. 构造方法名必须和类名一致，普通方法名随意
  2. 构造方法没有返回值（连 void 都没有），普通方法必须有返回值类型（void 也算）
  3. 构造方法在 new 对象时自动调用，普通方法需要手动调用

Q2: 如果只写了有参构造，还能用 new 类名() 创建对象吗？

不能。一旦手写了有参构造，jvm 不再自动提供无参构造。需要手动补写无参构造才行。

Q3: 构造方法能被 private 修饰吗？

可以。工具类中的构造方法就是 private 修饰的，防止外部 new 对象（工具类都使用静态方法，不需要 new 对象）。

九、第八章 static 关键字

9.1 static 介绍

  • 概述： static 是一个静态关键字
  • 使用方式：
    • 修饰成员变量：static 数据类型 变量名;
    • 修饰方法：修饰符 static 返回值类型 方法名(形参){ 方法体; return 结果; }
  • 调用静态成员： 类名直接调用（不用 new 对象）

9.2 静态成员的特点

  1. 静态成员属于类成员，不属于对象成员（非静态的成员属于对象成员）
  2. 静态成员会随着类的加载而加载
  3. 静态成员优先于非静态成员存在在内存中
  4. 凡是根据静态成员所在的类创建出来的对象，都可以共享这个静态成员

9.3 static 代码示例

java
// ========== Student.java ==========
public class Student {
    String name;          // 非静态成员变量(对象成员): 每个对象独有
    int age;              // 非静态成员变量(对象成员): 每个对象独有
    static String classRoom;  // 静态成员变量(类成员): 所有对象共享
}

// ========== Test01.java ==========
public class Test01 {
    public static void main(String[] args) {
        // 先给静态成员赋值, 用类名调用
        Student.classRoom = "222";  // 类名.静态变量名 赋值

        // 创建第一个学生对象
        Student s1 = new Student();
        s1.name = "郭靖";   // 给 s1 的 name 赋值
        s1.age = 28;        // 给 s1 的 age 赋值
        // s1.classRoom = "111";  // 不推荐用对象名调用静态成员

        System.out.println(s1.name + "," + s1.age + "," + Student.classRoom);
        // 输出: 郭靖,28,222

        System.out.println("==============");

        // 创建第二个学生对象
        Student s2 = new Student();
        s2.name = "黄蓉";   // 给 s2 的 name 赋值
        s2.age = 26;        // 给 s2 的 age 赋值
        // s2.classRoom = "111";  // 不推荐用对象名调用静态成员

        System.out.println(s2.name + "," + s2.age + "," + Student.classRoom);
        // 输出: 黄蓉,26,222  <- classRoom 是共享的, 值还是 "222"
    }
}

生活类比： 静态变量就像教室里的黑板，每个学生（对象）都能看到同一块黑板。非静态变量就像每个学生的笔记本，每人一本，互不相同。

9.4 static 修饰成员的访问特点

这是重点中的重点，四种情况要记牢：

情况 能否访问 说明
静态方法中访问非静态成员 不能 需要 new 对象调用
非静态方法中访问静态成员 能 同类直接调用/类名调用，不同类类名调用
静态方法中访问静态成员 能 同类直接调用/类名调用，不同类类名调用
非静态方法中访问非静态成员 能 同类直接调用/new 对象调用，不同类 new 对象调用

总结口诀：

  • 不管在不在同一个类中，非静态成员都可以 new 对象调用
  • 不管在不在同一个类中，静态成员都可以类名调用

9.5 什么时候用 static

问题1： 能不能把所有成员都定义成静态的？

不能。 静态成员随着类的加载而加载，如果全变成静态的，类一加载就全部进内存，大量占用内存空间。

问题2： 那什么时候用 static？

一般在抽取工具类时，可以将工具类中的所有成员都定义成静态的。

问题3： 什么时候定义工具类？

写代码时发现有的功能在反复实现，代码一样功能一样，就可以抽取出来形成工具类。

12.1 数组翻转

概述： 数组对称索引位置上的元素互换。

比如 {1,2,3,4,5,6,7} 翻转后变成 {7,6,5,4,3,2,1}。

java
public class Demo01Reverse {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5, 6, 7};  // 定义数组

        // 双指针法: min 从头开始, max 从尾开始, 互换后向中间靠拢
        for (int min = 0, max = arr.length - 1; min < max; min++, max--) {
            // 交换 arr[min] 和 arr[max]
            int temp = arr[min];   // 临时变量保存 arr[min]
            arr[min] = arr[max];   // arr[min] 取 arr[max] 的值
            arr[max] = temp;       // arr[max] 取 temp(原来的 arr[min])
        }

        // 遍历打印翻转后的数组
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");  // 输出: 7 6 5 4 3 2 1
        }
    }
}

12.2 冒泡排序

原理： 数组中相邻元素两两比较，前一个比后一个大就交换位置。每圈比较完，最大的元素就"冒泡"到最后。

java
public class Demo02Bubble {
    public static void main(String[] args) {
        int[] arr = {5, 4, 3, 2, 1};  // 定义待排序数组

        /*
           外层循环代表比较了几圈
           n个元素需要比较 n-1 圈
         */
        for (int j = 0; j < arr.length - 1; j++) {
            /*
              内层循环代表每一圈比较的次数
              每圈都少比较一次(因为前面的圈已经排好了一些)
             */
            for (int i = 0; i < arr.length - 1 - j; i++) {
                if (arr[i] > arr[i + 1]) {       // 相邻元素比较
                    int temp = arr[i];           // 临时变量
                    arr[i] = arr[i + 1];         // 交换位置
                    arr[i + 1] = temp;           // 交换位置
                }
            }
        }

        // 遍历打印排序后的数组
        for (int i = 0; i < arr.length; i++) {
            System.out.print(arr[i] + " ");  // 输出: 1 2 3 4 5
        }
    }
}

冒泡排序详细过程（以 {5,4,3,2,1} 为例）：

text
第一圈(j=0): 比较4次
  4 5 3 2 1 -> 4 3 5 2 1 -> 4 3 2 5 1 -> 4 3 2 1 5  (5 到位)
第二圈(j=1): 比较3次
  3 4 2 1 5 -> 3 2 4 1 5 -> 3 2 1 4 5  (4 到位)
第三圈(j=2): 比较2次
  2 3 1 4 5 -> 2 1 3 4 5  (3 到位)
第四圈(j=3): 比较1次
  1 2 3 4 5  (2 到位, 排序完成)

12.3 二分查找

前提： 数组中的数据必须是有序的。

原理： 每次找中间索引对应的元素进行比较，每次查询少一半数据。

java
public class Demo03Binary {
    public static void main(String[] args) {
        int[] arr = {1, 2, 3, 4, 5, 6, 7, 8, 9};  // 有序数组
        int index = binary(arr, 60);               // 查找 60
        System.out.println(index);                  // 输出: -1 (没找到)
    }

    public static int binary(int[] arr, int data) {
        // 定义三个变量, 分别代表最小索引、最大索引、中间索引
        int min = 0;              // 最小索引
        int max = arr.length - 1;  // 最大索引
        int mid = 0;              // 中间索引

        while (min <= max) {                  // 只要范围有效就继续查
            mid = (min + max) / 2;            // 计算中间索引
            if (data > arr[mid]) {             // 要找的数据比中间值大
                min = mid + 1;                 // 去右半边找, 更新 min
            } else if (data < arr[mid]) {      // 要找的数据比中间值小
                max = mid - 1;                 // 去左半边找, 更新 max
            } else {                           // 找到了
                return mid;                     // 返回索引
            }
        }

        return -1;  // 没找到, 返回 -1
    }
}

12.4 数组算法面试常问

Q1: 冒泡排序的时间复杂度是多少？

O(n²)。外层 n-1 圈，内层最多 n-1 次，总共约 n*(n-1)/2 次比较。

Q2: 二分查找的时间复杂度是多少？

O(log n)。每次查找少一半数据。

Q3: 二分查找的前提条件是什么？

数组必须是有序的。如果无序，需要先排序再查找。

14.1 基本数据类型做方法参数传递

核心： 基本类型做方法参数传递，传递的是值，不是变量本身。

java
public class Demo01Param {
    public static void main(String[] args) {
        int a = 10;  // main 方法中的局部变量 a
        int b = 20;  // main 方法中的局部变量 b
        method(a, b);               // 传入 a 和 b 的值(10, 20)
        System.out.println(a);      // 输出: 10 (a 没有变)
        System.out.println(b);      // 输出: 20 (b 没有变)
    }

    public static void method(int a, int b) {  // 方法内的 a, b 是独立的副本
        a += 10;  // 修改的是副本, 不影响 main 中的 a
        b += 20;  // 修改的是副本, 不影响 main 中的 b
        System.out.println(a);  // 输出: 20
        System.out.println(b);  // 输出: 40
    }
}

内存分析：

  • main 方法进栈，a=10, b=20
  • method 进栈，把 a=10 和 b=20 的值复制一份传进去
  • method 中修改的是自己栈帧里的副本，不影响 main 里的 a 和 b
  • method 执行完弹栈，副本消失

14.3 参数传递面试常问

Q1: Java 是值传递还是引用传递？

Java 只有值传递。传基本类型时传的是值的副本；传引用类型时传的是地址值的副本。但因为地址指向同一块堆内存，通过地址修改内容，原始对象也会变化，所以看起来像引用传递。

Q2: 为什么基本类型传递后不影响原来的值，引用类型传递后会影响？

基本类型传的是值的副本，方法里操作副本，原值不受影响。引用类型传的是地址值的副本，但地址指向同一个堆内存空间，通过地址修改堆中的数据，原来的引用也能看到变化。

十五、第十四章 命令行参数（了解）

通过命令行给 main 方法的形参 String[] args 传递参数，这就是命令行参数。

java
public class TestCommandParam {
    // 形参：String[] args 用来接收命令行参数
    public static void main(String[] args) {
        for (int i = 0; i < args.length; i++) {
            System.out.println("第" + (i + 1) + "个参数的值是：" + args[i]);
        }
    }
}

运行命令示例：

text
java TestCommandParam               // args.length = 0, 不输出
java TestCommandParam 1 2 3        // 输出: 第1个参数1, 第2个参数2, 第3个参数3
java TestCommandParam hello atguigu // 输出: 第1个参数hello, 第2个参数atguigu

十九、本章小结

本章是 Java 面向对象的基础章节，核心内容总结如下：

类与对象（模块七）

  • 类是一类事物的抽象描述（模板），对象是类的具体实例
  • 创建对象的三步：导包 → new 对象 → 调用成员
  • 成员变量有默认值，局部变量没有默认值
  • 匿名对象只能调用方法，不能用于赋值

封装（模块八）

  • 核心思想：隐藏细节，对外提供公共接口
  • private 关键字：只能在本类使用，外类不能直接调用
  • set/get 方法：外界通过接口间接操作私有属性
  • this 关键字：代表当前对象，区分重名的成员变量和局部变量
  • 构造方法：new 对象时自动调用，无参构造 jvm 自动提供，有参构造需手写
  • 标准 JavaBean：私有属性 + 无参构造 + 有参构造 + set/get 方法

扩展（模块九前半部分）

  • static：静态成员属于类，类名调用，所有对象共享
  • 可变参数：本质是数组，必须放参数列表最后
  • 递归：方法自己调用自己，必须有出口
  • 冒泡排序：相邻元素比较交换，时间复杂度 O(n²)
  • 二分查找：有序数组每次砍半查找，时间复杂度 O(log n)
  • 对象数组：存放对象引用的数组
  • 参数传递：基本类型传值副本，引用类型传地址副本

学习建议：

  1. 一定要自己动手写一个完整的标准 JavaBean（至少练习 5 遍）
  2. 理解 this 关键字的本质（谁调用 this 就是谁）
  3. 能手写冒泡排序和二分查找（这两个是高频笔试题）
  4. 多画内存图，理解对象在内存中的存储方式
