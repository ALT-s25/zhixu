一、什么是 MybatisPlus

1.1 MyBatis 的痛点

用 MyBatis 写每张表的 CRUD，要写大量重复 XML 或注解：

java
// 每张表都要写这些方法！烦死了
insertUser(User user);
deleteUserById(Long id);
updateUser(User user);
selectUserById(Long id);
selectAll();

1.2 MybatisPlus 的解决

只需继承 BaseMapper<T>，立刻拥有所有 CRUD 方法！

java
// 一行代码，18个现成方法
public interface UserMapper extends BaseMapper<User> {
    // 什么都不写，insert/delete/update/select 全有了
}

官方说法：MyBatis-Plus（简称 MP）是 MyBatis 的增强工具，在 MyBatis 基础上只做增强不做改变，为简化开发、提高效率而生。

二、快速入门 ⭐⭐

2.1 依赖

xml
<!-- 添加 MybatisPlus 依赖（代替 mybatis-spring-boot-starter） -->
<dependency>
    <groupId>com.baomidou</groupId>
    <artifactId>mybatis-plus-boot-starter</artifactId>
    <version>3.5.3.1</version>
</dependency>
<dependency>
    <groupId>mysql</groupId>
    <artifactId>mysql-connector-java</artifactId>
</dependency>

⚠ MybatisPlus 已包含 MyBatis，不需要再引入 mybatis-spring-boot-starter，否则版本冲突。

2.2 配置

yaml
spring:
  datasource:
    url: jdbc:mysql://localhost:3306/mydb?useSSL=false&serverTimezone=Asia/Shanghai
    username: root
    password: root1234
    driver-class-name: com.mysql.cj.jdbc.Driver

mybatis-plus:
  configuration:
    log-impl: org.apache.ibatis.logging.stdout.StdOutImpl   # 打印 SQL 日志（开发用）
  global-config:
    db-config:
      id-type: auto          # 主键策略：auto = 数据库自增
      update-strategy: not_null  # 更新时只更新非 null 字段

2.3 实体类

java
@Data
@TableName("user")  // 对应的表名（类名与表名一致时可省略）
public class User {

    @TableId(type = IdType.AUTO)  // 主键，AUTO = 数据库自增
    private Long id;

    private String username;

    private String password;

    @TableField("nick_name")   // 字段名与属性名不一致时用
    private String nickName;

    @TableField(exist = false)  // 该字段在数据库中不存在
    private String tempField;

    @TableLogic   // 逻辑删除字段（软删除）
    private Integer deleted;
}

2.4 Mapper 接口

java
// 只需继承 BaseMapper，18 个 CRUD 方法全有了！
@Mapper
public interface UserMapper extends BaseMapper<User> {
    // 自定义 SQL 仍然在这里写
}

2.5 使用

java
@SpringBootTest
class UserMapperTest {

    @Autowired
    private UserMapper userMapper;

    @Test
    void testInsert() {
        User user = new User();
        user.setUsername("Jack");
        user.setPassword("123456");
        userMapper.insert(user);         // 自动设置 id
        System.out.println("id = " + user.getId());   // 拿到自增的 id
    }

    @Test
    void testSelectById() {
        User user = userMapper.selectById(1L);
        System.out.println(user);
    }

    @Test
    void testUpdate() {
        User user = new User();
        user.setId(1L);
        user.setPassword("654321");
        userMapper.updateById(user);     // 只更新非 null 字段
    }

    @Test
    void testDelete() {
        userMapper.deleteById(1L);
    }

    @Test
    void testSelectList() {
        List<User> users = userMapper.selectList(null);  // null = 无条件，查全部
        users.forEach(System.out::println);
    }
}

三、条件构造器（Wrapper）⭐⭐⭐

3.1 什么是 Wrapper

用 Java 代码构建 SQL 的 WHERE 条件，不用写 SQL 字符串。

3.2 QueryWrapper（查询 / 删除）

java
// 查询：name = 'Jack' AND age >= 18
QueryWrapper<User> wrapper = new QueryWrapper<User>()
    .eq("username", "Jack")        // username = 'Jack'
    .ge("age", 18)                  // age >= 18
    .like("email", "@qq.com")      // email LIKE '%@qq.com%'
    .orderByDesc("create_time")    // ORDER BY create_time DESC
    .last("LIMIT 10");              // 拼接到 SQL 末尾

List<User> users = userMapper.selectList(wrapper);

常用方法：

方法 SQL 含义 示例
eq("col", val) col = val 精确匹配
ne("col", val) col != val 不等于
gt/ge("col", val) col > / >= val 大于/大于等于
lt/le("col", val) col < / <= val 小于/小于等于
like("col", val) col LIKE %val% 模糊匹配
likeLeft/Right %val / val% 左/右模糊
between("col", a, b) col BETWEEN a AND b 区间
in("col", list) col IN (...) 包含
isNull/isNotNull col IS NULL / NOT NULL 空值
orderByAsc/Desc ORDER BY col ASC/DESC 排序
select("col1", "col2") SELECT col1, col2 指定查询字段

3.3 UpdateWrapper（更新）

java
// UPDATE user SET status=0 WHERE (age < 18)
UpdateWrapper<User> wrapper = new UpdateWrapper<User>()
    .set("status", 0)              // SET status = 0
    .lt("age", 18);                // WHERE age < 18

userMapper.update(null, wrapper);  // 第一个参数 null 表示不用实体类

3.4 LambdaQueryWrapper（推荐，避免写错字段名）⭐

java
// 用 Lambda 引用字段，编译时检查，不怕写错字段名
LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<User>()
    .eq(User::getUsername, "Jack")       // username = 'Jack'
    .ge(User::getAge, 18)               // age >= 18
    .like(User::getEmail, "@qq.com")    // email LIKE '%@qq.com%'
    .orderByDesc(User::getCreateTime);  // ORDER BY create_time DESC

List<User> users = userMapper.selectList(wrapper);

条件构建（动态 SQL）：

java
String name = "Jack";      // 可能是 null
Integer age = null;         // 条件不传，不加入 SQL

LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<User>()
    // 第一个参数是 boolean：false 时不加这个条件
    .eq(name != null, User::getUsername, name)
    .ge(age != null, User::getAge, age);

四、IService 接口（Service 层）⭐⭐

4.1 为什么用 IService

BaseMapper 只提供 Mapper 层操作，IService 在 Service 层封装了更多业务方法（批量操作等）。

4.2 实现步骤

java
// 1. Service 接口继承 IService
public interface UserService extends IService<User> {
    // 自定义方法
}

// 2. Service 实现类继承 ServiceImpl
@Service
public class UserServiceImpl extends ServiceImpl<UserMapper, User> implements UserService {
    // 已有所有 CRUD，直接用
}

4.3 IService 常用方法

java
// 注入 Service
@Autowired
private UserService userService;

// =================== 增 ===================
userService.save(user);                       // 保存一个
userService.saveBatch(list);                  // 批量保存（推荐用这个！）
userService.saveOrUpdate(user);               // 有 id 则更新，无则插入

// =================== 删 ===================
userService.removeById(1L);
userService.removeByIds(Arrays.asList(1L, 2L, 3L));
userService.remove(wrapper);                   // 按条件删除

// =================== 改 ===================
userService.updateById(user);
userService.update(wrapper);
userService.lambdaUpdate().eq(User::getId, 1L).set(User::getStatus, 0).update();

// =================== 查 ===================
User user = userService.getById(1L);
List<User> list = userService.list();          // 查全部
List<User> list = userService.list(wrapper);   // 按条件查
long count = userService.count();              // 总数

// =================== 分页 ===================
Page<User> page = new Page<>(1, 10);           // 第 1 页，每页 10 条
Page<User> result = userService.page(page, wrapper);
result.getRecords();     // 当前页数据
result.getTotal();       // 总条数
result.getPages();       // 总页数

五、分页插件 ⭐⭐

5.1 配置分页插件

java
@Configuration
public class MybatisPlusConfig {

    @Bean
    public MybatisPlusInterceptor mybatisPlusInterceptor() {
        MybatisPlusInterceptor interceptor = new MybatisPlusInterceptor();
        // 分页拦截器（指定数据库类型）
        interceptor.addInnerInterceptor(new PaginationInnerInterceptor(DbType.MYSQL));
        return interceptor;
    }
}

5.2 使用分页

java
// 1. 创建分页对象（页码从 1 开始）
Page<User> page = new Page<>(pageNum, pageSize);

// 2. 执行分页查询
LambdaQueryWrapper<User> wrapper = new LambdaQueryWrapper<User>()
    .eq(User::getStatus, 1);

Page<User> result = userMapper.selectPage(page, wrapper);

// 3. 获取结果
List<User> records = result.getRecords();     // 当前页数据列表
long total = result.getTotal();              // 总记录数
long pages = result.getPages();              // 总页数
long current = result.getCurrent();          // 当前页码
long size = result.getSize();                // 每页大小

六、主键策略 ⭐

java
@TableId(type = IdType.AUTO)         // 数据库自增（推荐，小项目）
@TableId(type = IdType.ASSIGN_ID)    // 雪花算法（全局唯一，分布式用）
@TableId(type = IdType.ASSIGN_UUID)  // UUID（字符串，不推荐）
@TableId(type = IdType.INPUT)        // 手动输入
@TableId(type = IdType.NONE)         // 不设置

七、逻辑删除（软删除）⭐⭐

物理删除：真正从数据库删除记录（DELETE）。

逻辑删除：不删记录，只改一个标记字段（如 deleted=1），查询时自动过滤。

java
// 实体类加注解
@TableLogic
private Integer deleted;    // 0=正常，1=删除

// 配置（全局）
mybatis-plus:
  global-config:
    db-config:
      logic-delete-field: deleted    # 逻辑删除字段名
      logic-delete-value: 1          # 删除标记值
      logic-not-delete-value: 0      # 正常标记值

效果：

  • deleteById(id) 实际执行：UPDATE user SET deleted=1 WHERE id=?
  • selectById(id) 实际执行：SELECT ... WHERE id=? AND deleted=0

八、常见报错

报错 1：Property 'sqlSessionFactory' or 'sqlSessionTemplate' are required

text
原因：MybatisPlus 和 MyBatis 同时引入，版本冲突
解决：只保留 mybatis-plus-boot-starter，删除 mybatis-spring-boot-starter

报错 2：Field 'id' doesn't have a default value

text
原因：主键策略配置问题，AUTO_INCREMENT 没设好
解决：确认数据库 id 字段是 AUTO_INCREMENT；或 @TableId(type = IdType.AUTO)

报错 3：No property xxx found

text
原因：实体类属性名与数据库字段名不一致且没有配置映射
解决：加 @TableField("db_field_name") 注解

九、面试常问 ⭐⭐

💡 MybatisPlus 和 MyBatis 的区别？ MybatisPlus 是 MyBatis 的增强版，提供了通用 CRUD（BaseMapper/IService）、条件构造器、分页插件等，减少重复代码。底层还是 MyBatis。

💡 LambdaQueryWrapper 和 QueryWrapper 的区别？ LambdaQueryWrapper 用 Lambda 表达式（User::getName）引用字段，编译期检查，不怕写错字段名。QueryWrapper 用字符串写字段名，容易写错。推荐 LambdaQueryWrapper。

💡 逻辑删除的优缺点？ 优点：数据可追溯（不真删），方便数据恢复。 缺点：查询都要带 deleted=0 条件，唯一索引会失效（需加 deleted 到唯一索引）。

💡 MP 分页和 PageHelper 的区别？ MP 分页是拦截器方式，无侵入；PageHelper 是线程变量方式（PageHelper.startPage()），两者效果类似，SpringBoot 项目推荐 MP 自带分页。
