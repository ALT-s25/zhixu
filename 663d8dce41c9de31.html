第一章：Java概述

1.1 计算机语言发展史

语言共经历了三代演进：

  • 第一代：机器语言 — 全是 0 和 1 组成的指令，程序员要记住各种 0/1 组合，极其痛苦
  • 第二代：汇编语言 — 出现了 add 这样的助记词，仍然面向机器，速度很快，现在嵌入式开发还在用
  • 第三代：高级语言 — 更接近人类语言，Java、C、Python 等都属于此类

生活类比：机器语言就像用摩尔斯电码和人说话，汇编语言像用电报简写，高级语言才像正常说话。

无论哪一代，CPU 最终只认识 0 和 1，所有代码都会被翻译成 0/1 后才能执行。

2.1 字节与存储单位

重点记忆：

text
1 B（字节 Byte）= 8 bit（位/比特）
1 KB = 1024 B
1 MB = 1024 KB
1 GB = 1024 MB
1 TB = 1024 GB
往上还有：PB、EB、ZB ...

生活类比：1 bit 就像一个开关（开=1，关=0），8 个开关组合成 1 个字节，能表示 256 种状态（0~255）。

为什么是 1024 而不是 1000？ 因为计算机用二进制，2 的 10 次方 = 1024，最接近 1000，所以规定 1024 为换算单位。

2.3 JVM / JRE / JDK 的关系

text
JDK（Java开发工具包）
  ├── javac（编译工具）
  ├── java（运行工具）
  ├── jdb（调试工具）
  ├── jhat（内存分析工具）
  └── JRE（Java运行环境）
        ├── 核心类库
        └── JVM（Java虚拟机）
  • JVM（Java Virtual Machine）：Java 虚拟机，负责运行 .class 字节码文件
  • JRE（Java Runtime Environment）：Java 运行环境，包含 JVM + 核心类库，只用来运行程序
  • JDK（Java Development Kit）：Java 开发工具包，包含 JRE + 编译器等开发工具，开发必须安装 JDK

生活类比：JVM 是引擎，JRE 是整辆车，JDK 是车加上维修工具箱。你只是乘客（运行程序）时，有车就行；你是修车的（开发程序），才需要工具箱。

跨平台原理： Java 代码编译后生成 .class 字节码文件，字节码不能直接在操作系统上运行，而是交给 JVM 来运行。不同操作系统（Windows/Linux/Mac）各自有对应版本的 JVM，所以同一份 .class 文件在哪个系统上都能跑 —— 这就是"一次编写，到处运行"。

注意： 从 JDK 9 开始，JDK 目录中没有单独的 JRE 目录了，JDK 引入模块化技术，让开发者可以按需构建最小运行时，提高效率。

2.5 配置环境变量（JAVA_HOME）

为什么要配置环境变量？

javac 和 java 命令在 JDK 的 bin 目录里。如果不配置，只能在 bin 目录下使用这两个命令，非常不方便。配置环境变量后，在任意路径下都能使用 javac 和 java。

方式一（不推荐）： 直接把 jdk\bin 路径粘贴到 PATH 变量里

方式二（极力推荐）：配置 JAVA_HOME

步骤：

  1. 右键"此电脑" → 属性 → 高级系统设置 → 环境变量
  2. 在"系统变量"中新建：
    • 变量名：JAVA_HOME
    • 变量值：你的 JDK 安装根目录，例如 C:\Program Files\Java\jdk1.8.0_201
  3. 找到 PATH 变量，编辑，新增：%JAVA_HOME%\bin
  4. 点击确定，全部保存

验证是否配置成功： 打开新的 CMD 窗口，输入 java -version，能看到版本号就成功了。

可能遇到的问题： 电脑重启后环境变量失效

  • 解法1：打开环境变量设置界面，什么都不改，直接点确定
  • 解法2：直接把 bin 路径粘进 PATH 用了 IDEA 之后就不会有这个问题了

第三章：第一个 Java 程序

3.1 开发三步骤

text
编写  →  编译  →  运行
步骤 操作 命令 产出文件
编写 创建 .java 文件，写代码 文本编辑器 xxx.java

注意： 运行时用 java 类名，不要写成 java 类名.class，不需要后缀名。

3.2 HelloWorld 完整代码

java
// class 是关键字，表示定义一个类
// Demo01HelloWorld 是类名，必须和 .java 文件名完全一致（大小写也要一样）
public class Demo01HelloWorld {

    // main 方法是程序的入口，JVM 执行代码从这里开始
    // 这一行必须原封不动地写，一个字母都不能改
    public static void main(String[] args) {

        // System.out.println 是输出语句，把括号里的内容打印到控制台
        // println 自带换行，print 不换行
        System.out.println("HelloWorld");
    }
}

每一行的含义解释：

  • public class Demo01HelloWorld — 定义一个名叫 Demo01HelloWorld 的公开类
  • public static void main(String[] args) — 程序入口，JVM 找到这里开始执行，这行写法固定，必须一字不差
  • System.out.println("HelloWorld") — 输出语句，打印内容到控制台

3.4 println 和 print 的区别

java
public class Demo05HelloWorld {
    public static void main(String[] args) {
        // println：打印后自动换行
        System.out.println("床前明月光");  // 输出后换行
        System.out.println("疑是地上霜");  // 输出后换行

        // print：打印后不换行，下一次输出紧跟在后面
        System.out.print("举头望明月");    // 不换行
        System.out.print("低头思故乡");    // 不换行，紧接在上一行后面
    }
}

输出结果：

text
床前明月光
疑是地上霜
举头望明月低头思故乡

3.5 注意事项（新手高频踩坑）

  1. 类名必须和 .java 文件名完全一致（包括大小写）
  2. 所有标点符号必须是英文格式（冒号、分号、括号、引号都要英文）
  3. 不要把 main 写成 mian（这是最高频的拼写错误）
  4. System 和 String 的 S 要大写
  5. 括号要成对写，先写 {}，再在里面写内容
  6. 每条语句末尾加 ; 分号，代表这句话结束了

3.6 字符编码问题

text
编码：保存数据的过程（写文件时用什么编码）
解码：读数据的过程（读文件时用什么编码）
原则：编码和解码必须使用同一套编码规范，否则出现乱码
编码规范 说明
GBK 专为中文设计，一个中文汉字占 2 个字节，ANSI 代表 GBK
UTF-8 国际通用，一个中文汉字占 3 个字节

DOS 命令窗口默认使用 GBK 编码。如果你的 .java 文件保存时用 UTF-8，编译时可能出现乱码。解决办法：编译时加参数 javac -encoding UTF-8 文件名.java

第四章：常量与变量

4.1 常量

常量：在代码运行过程中，值不会发生改变的数据。

分类 举例 说明
整数常量 1、-100、0 所有整数
小数常量 1.5、2.0、-3.14 所有带小数点的数
字符常量 'A'、'1'、' '（空格）、'\t'（Tab） 用单引号包裹，必须有且只能有一个内容
字符串常量 "hello"、""、"你好" 用双引号包裹，内容随意（可以为空）
布尔常量 true、false 只有这两个值，不要加引号
空常量 null 代表数据不存在，不能直接打印输出

字符常量的合法与非法举例：

text
'1'      ✓ 合法（一个字符）
' '      ✓ 合法（一个空格）
'\t'     ✓ 合法（Tab 是一个字符）
'11'     ✗ 非法（两个字符）
''       ✗ 非法（空的，没有内容）
'   '    ✗ 非法（三个空格，超过一个）
java
public class Demo01Constant {
    public static void main(String[] args) {
        // 整数常量
        System.out.println(1);    // 输出：1
        System.out.println(-1);   // 输出：-1

        // 小数常量
        System.out.println(1.5);  // 输出：1.5

        // 字符常量 —— 单引号中必须有且只能有一个内容
        System.out.println('1');      // 输出：1
        System.out.println(' ');      // 输出：一个空格（合法）
        // System.out.println('11'); // 编译报错！两个字符不合法

        // 字符串常量
        System.out.println("hello"); // 输出：hello
        System.out.println("");      // 输出：空行（双引号中可以没有内容）

        // 布尔常量
        System.out.println(true);    // 输出：true
        System.out.println(false);   // 输出：false

        // 空常量 —— null 不能直接打印
        // System.out.println(null); // 编译报错！
    }
}

常量做运算：

java
public class Demo02Constant {
    public static void main(String[] args) {
        System.out.println(10 + 3);    // 加法，结果：13
        System.out.println(10 - 3);    // 减法，结果：7
        System.out.println(10 * 3);    // 乘法，结果：30

        // 除法注意事项：
        // /前后如果都是整数，结果只取整数部分（直接截断，不是四舍五入）
        System.out.println(10 / 3);    // 结果：3（不是3.33，直接截断小数）

        // /前后只要有一个数带小数点，结果就是正常小数
        System.out.println(10.0 / 3);  // 结果：3.3333333333333335
        System.out.println(10 / 3.0);  // 结果：3.3333333333333335
    }
}

4.2 基本数据类型（4类8种）

Java 基本数据类型一共 8 种，分为 4 大类：

大类 数据类型 关键字 内存占用 取值范围
整型 字节型 byte 1字节 -128 ~ 127
整型 短整型 short 2字节 -32768 ~ 32767
整型 整型（默认） int 4字节 约正负 21 亿（-2^31 ~ 2^31-1）
整型 长整型 long 8字节 约正负 922 亿亿（-2^63 ~ 2^63-1）
浮点型 单精度 float 4字节 小数位约 7 位精度
浮点型 双精度（默认） double 8字节 小数位约 16 位精度

布尔型 布尔型 boolean 1字节 true / false

关键记忆点：

  • 整数字面量默认是 int；小数字面量默认是 double
  • 定义 long 型变量，数值后面要加 L，例如：long x = 100L;
  • 定义 float 型变量，数值后面要加 F，例如：float x = 2.5F;

float 和 double 的区别：

  • float 小数位最多 7 位有效数字
  • double 小数位最多 16 位有效数字
  • 切记：浮点数直接参与运算有精度损失问题，将来开发建议用 BigDecimal

引用数据类型： 除了 8 种基本类型，其余都是引用类型，包括：类（class）、数组、接口、枚举、注解。String 字符串是引用类型，但定义方式和基本类型一样。

4.3 变量的定义与使用

变量：在代码运行过程中，值会根据不同情况随时发生改变的数据。

生活类比：变量就像一个贴了标签的盒子，盒子（变量名）是固定的，但里面装的东西（值）可以换。

定义方式：

java
// 方式一：定义的同时赋值（最常用）
数据类型 变量名 = 值;
int age = 20;

// 方式二：先定义，后赋值
数据类型 变量名;
变量名 = 值;
int age;
age = 20;

// 方式三：一次定义多个相同类型的变量
int i, j, k;
i = 10;
j = 20;
k = 30;

// 或者合并写法
int i = 10, j = 20, k = 30;

读等号的正确方式： 先看等号右边，再看等号左边 → 把右边的值赋值给左边的变量

各种数据类型的变量定义示例：

java
public class Demo03Var {
    public static void main(String[] args) {
        // byte 类型：范围 -128~127，超出范围会报错
        byte num1 = 100;
        System.out.println(num1);  // 输出：100

        // short 类型
        short num2 = 1000;
        num2 = 1001;              // 变量的值可以修改
        System.out.println(num2); // 输出：1001

        // int 类型：整数的默认类型
        int num3 = 10000;
        num3 = 1;                 // 修改变量值
        System.out.println(num3); // 输出：1

4.6 标识符命名规范

第五章：数据类型转换

5.1 什么时候会发生类型转换

  1. 等号左右两边类型不一致时（赋值时）
  2. 不同类型的数据做运算时

取值范围从小到大的顺序：

text
byte < short < char < int < long < float < double

记忆口诀：byte、short、char 三兄弟 → int → long → float → double

5.2 自动类型转换（小转大）

规则： 取值范围小的类型自动变成取值范围大的类型，不需要手动操作。

生活类比：把一杯水倒进一个大桶里，水会自动扩散到更大的空间，不会丢失任何水。

两种场景：

  1. 取值范围小的类型赋值给取值范围大的类型
  2. 不同类型做运算，小类型自动提升为大类型
java
public class Demo09DataType {
    public static void main(String[] args) {
        // 场景 1：赋值时自动转换
        // 等号右边 100 是 int（整数默认是 int）
        // 等号左边是 long
        // int 自动转成 long，不需要手动写任何东西
        long num1 = 100;
        System.out.println(num1);  // 输出：100

        // 场景 2：运算时自动转换
        int i = 10;
        double b = 2.5;
        // int + double 运算时，int 自动提升为 double，然后再相加
        // 相当于：double + double = double
        double sum = i + b;
        System.out.println(sum);   // 输出：12.5
    }
}

5.3 强制类型转换（大转小）

规则： 取值范围大的类型转成小的类型，必须手动加强转符号，可能造成数据丢失。

语法： 取值范围小的类型 变量名 = (取值范围小的类型) 取值范围大的值;

生活类比：把一大桶水倒进一个小杯子里，小杯子装不下，会溢出（数据丢失）。

java
public class Demo10DataType {

        // float num1 = (float)2.5; // 强转，合法
        float num1 = 2.5F;         // 加 F 后缀，更简单
        System.out.println(num1);  // 输出：2.5

}

public class Demo11DataType {

        // 100亿 = 10,000,000,000

  1. byte、short 定义时，如果等号右边是整数常量（非变量），且不超出范围，JVM 自动完成类型转换，不需要手写强转：

    java

  3. 复合赋值运算符（+=、-= 等）遇到 byte/short 时，JVM 自动转型，不需要手动强转（见第九章赋值运算符）。

第七章：位运算符（了解）

位运算直接对数字的二进制位进行操作，速度极快。了解规则即可，实际开发较少直接用。

7.1 原码、反码、补码

计算机实际存储的是补码，我们看到的结果是原码转换出来的。

正数 负数
原码、反码、补码关系 三者完全一致 三者不同

负数的转换规则：

text
原码 → 反码：最高位（符号位）不变，其余位 0 和 1 互换
反码 → 补码：在反码基础上 +1

举例：-9 的补码

text
原码：1000 0000 0000 0000 0000 0000 0000 1001
反码：1111 1111 1111 1111 1111 1111 1111 0110
补码：1111 1111 1111 1111 1111 1111 1111 0111

正数二进制最高位为 0；负数二进制最高位为 1

7.2 移位运算符

运算符 名称 规则 快速计算
<< 左移 左移 n 位，右边补 0 相当于 × 2^n
>> 右移 右移 n 位，左边补符号位 相当于 ÷ 2^n（向下取整）
>>> 无符号右移 右移 n 位，左边无条件补 0 负数结果变正数
text
2 << 2  = 2 × 4 = 8
9 >> 2  = 9 ÷ 4 = 2（向下取整）
-9 >> 2 = -9 ÷ 4 = -3（向下取整，-2.25向下取整是-3）
-9 >>> 2 = 1073741821（负数无符号右移结果变为正数）

笔试题： 8 >>> 32 等于多少？ 答：等于 8（相当于没有移动）。超过该类型总位数时，实际移动位数 = n % 总位数 = 32 % 32 = 0

7.3 按位运算符

运算符 名称 规则
& 按位与 对应位都是 1 才为 1（有 0 则 0）
\| 按位或 对应位只要有 1 即为 1（有 1 则 1）
^ 按位异或 对应位相同为 0，不同为 1
~ 按位取反 0 变 1，1 变 0

~10 = -11    （所有位取反，结果为 -11）

+ 号的特殊用途：字符串拼接

规则： 任何类型的数据遇到字符串，+ 就不再是加法，而是字符串拼接，把内容直接拼到字符串后面

java
public class Demo02Arithmetic {
    public static void main(String[] args) {
        int i = 10;
        int j = 3;

        // i+j 先算加法得 13，再遇到 "" 就变成字符串 "13"
        System.out.println(i + j + "");     // 输出：13

        // i+j 先算得 13，遇到 "" 变成 "13"，再拼接 1 变成 "131"
        System.out.println(i + j + "" + 1); // 输出：131

        // i 先遇到 "" 变成字符串 "10"，然后拼接 j 得 "103"
        System.out.println(i + "" + j);     // 输出：103（不是13！）

        // 想要先计算加法再拼接字符串，用小括号提升优先级
        System.out.println("i和j之和为：" + (i + j)); // 输出：i和j之和为：13
    }
}

生活类比：+ 号遇到字符串就像胶水碰到东西，后面的一切都会粘上去变成字符串，不再做计算了。

        // 混合使用：++j（前置），先加1再用
        int j = 100;
        int result01 = ++j;             // 先 j+1=101，再把 101 赋给 result01
        System.out.println("result01 = " + result01);  // 输出：result01 = 101
        System.out.println(j);          // 输出：101

        System.out.println("==================");

        // 混合使用：k++（后置），先用原值再加1
        int k = 10;
        int result02 = k++;             // 先把 10 赋给 result02，然后 k 再变成 11
        System.out.println("result02 = " + result02);  // 输出：result02 = 10（原值！）
        System.out.println(k);          // 输出：11（k 已经加了1）

        System.out.println("==================");

        // 在输出语句中使用后置++
        int z = 100;
        System.out.println(z++);  // 先打印原值 100，打印完后 z 变成 101
        System.out.println(z);    // 输出：101

        System.out.println("==================");

        // 复杂混合使用（面试常考，实际开发不要这么写！）
        int x = 10;
        int y = 20;
        // x++ 先用 10，然后 x 变成 11
        // --y 先 y-1=19，再用 19
        // ++x 先 x+1=12，再用 12
        // 10 + 19 + 12 = 41
        int result03 = x++ + --y + ++x;
        System.out.println("result03 = " + result03);  // 输出：41

        System.out.println("=======================");

        // 经典面试题：c = c++ 结果是什么？
        int c = 10;
        c = c++;  // 先把 c 的原值 10 存起来准备赋给 c，然后 c+1=11，再把存的 10 赋回 c
        System.out.println(c);  // 输出：10（不是11！）
        // 解释：c++ 是先用原值（10），再自增。整句赋值最终把"先用的原值 10"赋给了 c
    }
}

关系运算符的结果只有两种：true 或 false，常用于条件判断。

public class Demo01Compare {

9.5 逻辑运算符

用于连接多个 boolean 结果，最终结果仍然是 boolean。

符号 名称 规则
&& 双与（且） 有假则假：两边都是 true 才是 true
\|\| 双或（或） 有真则真：有一边是 true 就是 true
! 非（取反） !true → false；!false → true
^ 异或 两边相同为 false，不同为 true

短路效果（非常重要！）：

符号 短路条件 效果
&& 左边为 false 右边不会执行，整体直接为 false
\|\| 左边为 true 右边不会执行，整体直接为 true

单与 & 和双与 && 的区别：

&（单与） &&（双与）
结果规则 有假则假（相同） 有假则假（相同）
短路效果 无（左边 false，右边继续执行） 有（左边 false，右边不执行）
用作位运算 是（前后是数字时） 否
java
public class Demo01Logic {
    public static void main(String[] args) {
        int i = 10;
        int j = 20;
        int k = 10;

        // && 有假则假：i>j 是 false，i==k 是 true，false && true = false
        boolean result01 = (i > j) && (i == k);
        System.out.println("result01 = " + result01);  // 输出：false

        // || 有真则真：i>j 是 false，i==k 是 true，false || true = true
        boolean result02 = (i > j) || (i == k);
        System.out.println("result02 = " + result02);  // 输出：true

        // ^ 异或：false ^ true = true（不同）
        boolean result03 = (i > j) ^ (i == k);
        System.out.println("result03 = " + result03);  // 输出：true

        // ! 取反：i>j 是 false，取反后是 true
        boolean result04 = !(i > j);
        System.out.println("result04 = " + result04);  // 输出：true
    }
}

短路效果演示：

java
public class Demo02Logic {
    public static void main(String[] args) {
        int a = 10;
        int b = 20;

        // 使用单与 &：a 先变成 11，b 先变成 21（两边都执行了）
        // boolean result01 = (++a > 100) & (++b > 10);

        // 使用双与 &&：++a>100 是 false，右边 ++b 不会执行
        // boolean result01 = (++a > 100) && (++b > 10);

        boolean result01 = (++a < 100) || (++b > 10);

        System.out.println("b = " + b);  // 输出：20（b 没有执行++，短路了）
    }
}

9.6 三元运算符

格式： boolean表达式 ? 表达式1 : 表达式2

执行流程：

  1. 先计算 boolean 表达式
  2. 如果结果是 true，整个三元运算符的结果就是 ? 后面的表达式1
  3. 如果结果是 false，整个三元运算符的结果就是 : 后面的表达式2

生活类比：三元运算符就像做选择题 → "考试及格了吗？是的话发糖，不是的话罚站"

练习1：判断分数是否及格

java
public class Demo01Ternary {
    public static void main(String[] args) {
        // 定义一个变量，表示小明的分数
        int score = 60;

        // score >= 60 是 true，所以取 ? 后面的 "及格"
        String result = score >= 60 ? "及格" : "不及格";
        System.out.println("result = " + result);  // 输出：及格
    }
}

练习2：求两个数的最大值

java
public class Demo02Ternary {
    public static void main(String[] args) {
        int old1 = 70;
        int old2 = 80;

        // old1 > old2 是 false（70 < 80），所以取 : 后面的 old2
        int max = old1 > old2 ? old1 : old2;
        System.out.println("max = " + max);  // 输出：80
    }
}

练习3：求三个数的最大值（三元运算符嵌套）

java
public class Demo03Ternary {
    public static void main(String[] args) {
        int old1 = 70;
        int old2 = 80;
        int old3 = 60;

        // 第一步：先比较 old1 和 old2，得到两者中的较大值 temp
        int temp = old1 > old2 ? old1 : old2;  // temp = 80

        // 第二步：再用 temp 和 old3 比较
        int max = temp > old3 ? temp : old3;    // max = 80（80 > 60）

        System.out.println("max = " + max);  // 输出：80
    }
}

常见报错与解决方法

报错1：cannot find symbol（找不到符号）

text
Demo.java:5: error: cannot find symbol
    System.out.println(helloworld);

原因： 变量或方法名写错了、没有定义就使用

解决： 检查拼写，确认变量已经定义过

报错2：; expected（需要分号）

text
Demo.java:4: error: ';' expected

原因： 语句结尾没有写 ;

解决： 在语句末尾加上英文分号 ;

报错3：class Demo is public, should be declared in a file named Demo.java

原因： 类名和文件名不一致

解决： 修改类名或文件名，让两者完全一致（包括大小写）

报错4：incompatible types: possible lossy conversion（类型不兼容）

java
float f = 2.5; // 报错！2.5 默认是 double，不能直接赋给 float

解决： 加 F 后缀 → float f = 2.5F; 或强转 → float f = (float) 2.5;

报错5：variable might not have been initialized（变量可能未初始化）

java
int x;
System.out.println(x); // 报错！x 没有赋初始值

解决： 先给变量赋值再使用

报错6：IDEA 中 "找不到对应的发行源" / "不支持发行版本"

原因： 本地 JDK 版本和 IDEA 中设置的 Language Level 不匹配

解决： File → Project Structure → Project → 重新选择本地 JDK，Language Level 选对应版本

报错7：乱码问题

原因： 文件保存编码和 DOS 窗口编码不一致（文件是 UTF-8，DOS 是 GBK）

解决： 编译时指定编码：javac -encoding UTF-8 文件名.java

面试常问

Q1：Java 中的 8 种基本数据类型是什么？

byte（1字节）、short（2字节）、int（4字节，整数默认）、long（8字节）、float（4字节）、double（8字节，小数默认）、char（2字节）、boolean（1字节）

Q2：JVM、JRE、JDK 有什么区别？

  • JVM：Java 虚拟机，负责运行字节码，是跨平台的关键
  • JRE：Java 运行环境，包含 JVM + 核心类库，只用来运行程序
  • JDK：Java 开发工具包，包含 JRE + 编译器等工具，开发时必须安装

Q3：Java 是如何实现跨平台的？

Java 源代码编译后生成 .class 字节码文件，字节码不能直接运行在操作系统上，而是由各平台的 JVM 来运行。不同操作系统有对应版本的 JVM，所以同一份 .class 文件在任何装了 JVM 的系统上都能运行，实现"一次编写，到处运行"。

Q4：& 和 && 的区别是什么？

相同点：都是逻辑与，有假则假。 区别：&& 有短路效果，左边为 false 时右边不执行；& 两边都会执行。另外 & 还可以用作位运算符（前后是数字时）。

Q5：i++ 和 ++i 有什么区别？

单独使用没有区别，都是给 i 加 1。 混合使用时：

  • i++：先用 i 的原值，然后 i 再 +1
  • ++i：先 i +1，然后用加完后的新值

Q6：自动类型转换和强制类型转换各在什么情况下使用？

  • 自动类型转换（小转大）：取值范围小的类型自动变成大的类型，系统自动完成，无精度损失
  • 强制类型转换（大转小）：需要手动写强转符号 (目标类型)，可能有精度损失和数据溢出风险

Q7：为什么 double div = num1 / num2; 中 num1 和 num2 都是 int，结果是 3.0 而不是 3.333？

因为 num1 / num2 是 int 除以 int，计算时已经取整得到 3，然后再把 3 赋给 double 变量，所以是 3.0。如果想得到小数结果，应该写 double div = (double) num1 / num2; 或 double div = num1 * 1.0 / num2;

Q8：float 和 double 的精度各是多少位？

  • float：约 7 位有效小数位
  • double：约 16 位有效小数位
  • 实际开发中涉及精确计算（如金额），应使用 BigDecimal，不要用浮点数直接运算
