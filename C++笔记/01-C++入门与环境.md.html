二、C++ 历史与特点

2.1 简史

  • 1979：Bjarne Stroustrup 在贝尔实验室开发 "C with Classes"
  • 1983：更名为 C++
  • 1998：C++98 第一个 ISO 标准
  • 2011：C++11 重大更新（现代 C++ 起点）
  • 2014/2017/2020：持续演进

2.2 C++ 特点 ⭐

  • 面向对象：类、继承、多态、封装
  • 泛型编程：模板（template）
  • 高性能：零开销抽象，接近 C 的性能
  • 系统级：可直接操作内存（指针）
  • 多范式：过程、面向对象、泛型、函数式

三、C++ vs Java vs C ⭐

维度 C C++ Java
范式 过程 多范式 纯面向对象
内存管理 手动 手动 + 智能指针 GC
指针 ✅ ✅ ❌（无裸指针）
多继承 ❌ ✅（慎用） ❌（单继承 + 多接口）
编译 编译 编译 编译 + 解释
跨平台 需重新编译 需重新编译 字节码 + JVM
性能 ⭐⭐⭐⭐⭐ ⭐⭐⭐⭐ ⭐⭐⭐

四、第一个程序 HelloWorld

4.1 编写代码

新建 hello.cpp：

cpp
#include <iostream>

int main() {
    std::cout << "Hello, World!" << std::endl;
    return 0;
}

4.2 编译与运行

bash
# 编译（g++）
g++ hello.cpp -o hello

# 运行
./hello         # Linux/Mac
hello.exe       # Windows

⚠ C++ 文件扩展名：.cpp / .cc / .cxx，不要用 .c

4.3 注意事项

⚠ 常见坑：

  1. 每个 C++ 程序有且仅有一个 main 函数（程序入口）
  2. return 0 表示程序正常结束（C++ 隐式返回 0 可省略）
  3. 语句以分号 ; 结尾
  4. 大小写敏感
  5. #include 是预处理指令（不是语句）

五、编译与链接原理 ⭐⭐

5.1 编译流程

text
源代码 .cpp
    ↓ 预处理（处理 #include、宏）
预处理文件 .i
    ↓ 编译（生成汇编）
汇编文件 .s
    ↓ 汇编（生成机器码）
目标文件 .o
    ↓ 链接（合并多个 .o）
可执行文件 .exe / a.out

5.2 编译命令

bash
# 单文件
g++ hello.cpp -o hello

# 多文件
g++ main.cpp utils.cpp -o app

# 带调试信息
g++ -g main.cpp -o app

# 优化级别（O0/O1/O2/O3）
g++ -O2 main.cpp -o app

# 显示警告
g++ -Wall main.cpp -o app

# C++17 标准
g++ -std=c++17 main.cpp -o app

5.3 头文件 vs 源文件

文件 内容 用途
.h / .hpp 声明（类、函数声明） 给其他文件用
.cpp 定义（实现） 自己编译

经典结构：

text
myapp/
├── main.cpp
├── utils.h
├── utils.cpp

utils.h：

cpp
#pragma once          // 防止重复包含（推荐）
// 或：#ifndef UTILS_H  #define UTILS_H  ...  #endif

int add(int a, int b);

utils.cpp：

cpp
#include "utils.h"
int add(int a, int b) {
    return a + b;
}

main.cpp：

cpp
#include <iostream>
#include "utils.h"

int main() {
    std::cout << add(3, 5) << std::endl;
    return 0;
}

六、命名空间（namespace）⭐

6.1 为什么需要命名空间

避免命名冲突。

cpp
namespace my {
    int x = 10;
    void func() { }
}

my::x = 20;
my::func();

6.2 三种使用方式

cpp
// 1. 全限定
std::cout << "hi";

// 2. using 声明
using std::cout;
cout << "hi";

// 3. using 指令（慎用）
using namespace std;   // 把整个 std 引入，全局可用
cout << "hi";

⚠ 不要在头文件中 using namespace std;（会污染引用方的命名空间）

七、输入输出（cin / cout）⭐

cpp
#include <iostream>
using namespace std;

int main() {
    int age;
    string name;

    cout << "请输入姓名和年龄：";
    cin >> name >> age;             // 自动识别类型，空格分隔

    cout << name << " 今年 " << age << " 岁" << endl;

    // 格式化
    cout << hex << 255;             // 十六进制：ff
    cout << dec << 255;             // 十进制：255
    cout << fixed << setprecision(2) << 3.14159;  // 3.14
    return 0;
}

💡 cin/cout 慢？sync_with_stdio(false) 加速（详见后续 IO 章节）。

十、面试常问

💡 C++ 和 Java 的主要区别？ | 维度 | C++ | Java | |------|-----|------| | 编译 | 编译为机器码 | 编译为字节码 | | 内存 | 手动/智能指针 | GC | | 多继承 | ✅ | ❌ | | 指针 | ✅ | ❌ | | 性能 | 高 | 中 |

💡 C++11 有什么重大更新？ auto、decltype、lambda、右值引用、智能指针、nullptr、范围 for、初始化列表、移动语义等。

💡 #include <> 和 "" 的区别？

  • <>：系统头文件，先在系统路径查找
  • ""：自定义头文件，先在当前目录查找
