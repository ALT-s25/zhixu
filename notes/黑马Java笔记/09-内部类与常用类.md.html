## 二、内部类 ⭐⭐

### 2.1 什么是内部类

定义在**类里面**的类。

### 2.2 成员内部类

```java
public class Outer {
    private int x = 10;

    public class Inner {
        public void print() {
            System.out.println(x);   // 直接访问外部类私有成员
        }
    }

    public void test() {
        new Inner().print();
    }
}

// 使用
Outer outer = new Outer();
Outer.Inner inner = outer.new Inner();
inner.print();
```

### 2.3 静态内部类

```java
public class Outer {
    private static int x = 10;

    public static class Inner {
        public void print() {
            System.out.println(x);
        }
    }
}

// 使用
Outer.Inner inner = new Outer.Inner();
inner.print();
```

### 2.4 局部内部类

```java
public class Outer {
    public void method() {
        final int x = 10;     // Java 8+ 隐式 final

        class LocalInner {
            public void print() {
                System.out.println(x);
            }
        }

        new LocalInner().print();
    }
}
```

### 2.5 匿名内部类 ⭐⭐⭐

**没有名字的类**，一次性使用。常配合接口使用。

```java
interface Greeting {
    void sayHello();
}

public class Main {
    public static void main(String[] args) {
        // 匿名内部类
        Greeting g = new Greeting() {
            @Override
            public void sayHello() {
                System.out.println("Hello!");
            }
        };
        g.sayHello();

        // Lambda 简化（Java 8+）
        Greeting g2 = () -> System.out.println("Hello from Lambda!");
        g2.sayHello();
    }
}
```

### 2.6 黑马经典案例：按钮事件 ⭐⭐

```java
button.addActionListener(new ActionListener() {
    @Override
    public void actionPerformed(ActionEvent e) {
        System.out.println("按钮被点击");
    }
});
```

> ⚠ Lambda 优先。

## 三、包装类 ⭐⭐

### 3.1 8 种包装类

| 基本类型 | 包装类 |
|---------|--------|
| byte | Byte |
| short | Short |
| int | **Integer** |
| long | Long |
| float | Float |
| double | Double |
| char | Character |
| boolean | Boolean |

### 3.2 装箱与拆箱

```java
// 装箱：基本 → 包装
Integer i = 10;            // 自动装箱
Integer j = Integer.valueOf(10);

// 拆箱：包装 → 基本
int n = i;                  // 自动拆箱
int m = i.intValue();
```

### 3.3 自动装箱的坑 ⭐⭐

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b);   // true（缓存池）

Integer c = 128;
Integer d = 128;
System.out.println(c == d);   // false（超出缓存池）
```

> 💡 **缓存池范围** -128~127，超出后 == 失效，**必须用 equals**。

### 3.4 包装类常用方法

```java
int n = Integer.parseInt("123");       // 字符串 → int
String s = Integer.toString(123);       // int → 字符串
String s2 = String.valueOf(123);
int max = Integer.MAX_VALUE;
int min = Integer.MIN_VALUE;
```

### 3.5 黑马案例：字符串数字相加

```java
String s = "100";
int n = Integer.parseInt(s);
int result = n + 1;     // 101
```

## 四、日期类 ⭐⭐

### 4.1 Date 类（老）

```java
import java.util.Date;

Date d = new Date();
System.out.println(d);     // 当前时间
System.out.println(d.getTime());    // 时间戳（毫秒）
```

### 4.2 SimpleDateFormat

```java
import java.text.SimpleDateFormat;

SimpleDateFormat sdf = new SimpleDateFormat("yyyy-MM-dd HH:mm:ss");

// Date → String
Date d = new Date();
String s = sdf.format(d);

// String → Date
Date d2 = sdf.parse("2025-01-01 12:00:00");
```

**格式化符号**：
- `yyyy`：年
- `MM`：月
- `dd`：日
- `HH`：时（24 小时）
- `mm`：分
- `ss`：秒

### 4.3 Calendar 类

```java
import java.util.Calendar;

Calendar c = Calendar.getInstance();
c.set(2025, Calendar.JANUARY, 1);    // 设置日期
c.add(Calendar.DAY_OF_MONTH, 7);      // 加 7 天
Date d = c.getTime();
```

### 4.4 JDK 8 新时间 API ⭐⭐（推荐）

```java
import java.time.LocalDate;
import java.time.LocalDateTime;
import java.time.LocalTime;
import java.time.format.DateTimeFormatter;

LocalDate today = LocalDate.now();
LocalDate tomorrow = today.plusDays(1);

LocalDateTime now = LocalDateTime.now();

DateTimeFormatter fmt = DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss");
String s = now.format(fmt);
```

### 4.5 黑马经典案例 ⭐⭐

**计算两个日期相差多少天**：
```java
public static long daysBetween(Date d1, Date d2) {
    long diff = d2.getTime() - d1.getTime();
    return diff / (1000 * 60 * 60 * 24);
}
```

## 五、综合案例：黑马学生管理系统（升级版）⭐⭐⭐

```java
// Student.java
public class Student {
    private String id;
    private String name;
    private int age;
    private String gender;

    public Student() {}
    public Student(String id, String name, int age, String gender) {
        this.id = id;
        this.name = name;
        this.age = age;
        this.gender = gender;
    }

    // getter/setter 略

    @Override
    public String toString() {
        return "Student{id=" + id + ", name=" + name + ", age=" + age + ", gender=" + gender + "}";
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Student s = (Student) o;
        return Objects.equals(id, s.id);
    }
}

// StudentManager.java
public class StudentManager {
    private ArrayList<Student> students = new ArrayList<>();

    public void addStudent(Student s) {
        students.add(s);
    }

    public void removeStudent(String id) {
        students.removeIf(s -> s.getId().equals(id));
    }

    public Student findById(String id) {
        for (Student s : students) {
            if (s.getId().equals(id)) return s;
        }
        return null;
    }

    public void printAll() {
        for (Student s : students) {
            System.out.println(s);
        }
    }
}
```

## 六、面试常问 ⭐

> 💡 **`int` 和 `Integer` 区别？**
> - int：基本类型，默认 0
> - Integer：包装类，默认 null

> 💡 **自动装箱的缓存池？**
> -128~127

> 💡 **Date、Calendar、LocalDate 区别？**
> | Date | Calendar | LocalDate |
> |------|----------|-----------|
> | 老（可变线程不安全） | 老（线程安全但麻烦） | 新（线程安全，清晰） |

> 💡 **内部类的作用？**
> - 访问外部类私有成员
> - 隐藏类的实现
> - 便于组织代码
