二、函数式编程思想 ⭐

面向对象：做一件事，找一个能解决它的对象，调用方法。 函数式编程：只要结果，不关心过程。

Java 8 引入 Lambda，把函数作为参数传递。

三、函数式接口 ⭐⭐

只有一个抽象方法的接口（可以用 @FunctionalInterface 标注）。

java
@FunctionalInterface
public interface MyFunction {
    void run();
}

@FunctionalInterface
public interface Calculator {
    int calc(int a, int b);
}

常见函数式接口（java.util.function）

接口 抽象方法 用途
Runnable run() 无参无返回值
Supplier<T> T get() 生产数据
Consumer<T> void accept(T) 消费数据
Function<T,R> R apply(T) 类型转换
Predicate<T> boolean test(T) 条件判断
java
// Supplier：提供数据
Supplier<Integer> s = () -> (int)(Math.random() * 100);

// Consumer：消费数据
Consumer<String> c = System.out::println;

// Function：转换
Function<String, Integer> f = Integer::parseInt;

// Predicate：判断
Predicate<Integer> p = x -> x > 0;

四、Lambda 表达式 ⭐⭐⭐

4.1 基本语法

java
(参数列表) -> { 方法体 }

4.2 三种形式

java
// 1. 无参无返回值
Runnable r = () -> System.out.println("hi");

// 2. 有参有返回值
Calculator c = (a, b) -> a + b;

// 3. 单行可省略大括号
Comparator<Integer> cmp = (a, b) -> Integer.compare(a, b);

4.3 黑马经典案例

java
// 1. 线程
new Thread(() -> System.out.println("hello")).start();

// 2. 比较器
Collections.sort(list, (a, b) -> b - a);

// 3. 事件监听
button.addActionListener(e -> System.out.println("clicked"));

4.4 省略规则

  • 参数类型可省略
  • 单参数可省略括号
  • 单语句可省略大括号和 return
java
x -> x * 2       // 等价于 (x) -> { return x * 2; }

五、方法引用 ⭐⭐

Lambda 的简化版，用 :: 引用已有方法。

5.1 静态方法引用

java
Function<String, Integer> f1 = Integer::parseInt;
// 等价 (s) -> Integer.parseInt(s)

5.2 实例方法引用

java
Consumer<String> c1 = System.out::println;
// 等价 (s) -> System.out.println(s)

5.3 任意对象方法引用

java
Comparator<String> cmp = String::compareToIgnoreCase;

5.4 构造方法引用

java
Supplier<ArrayList> s1 = ArrayList::new;

六、Stream 流 ⭐⭐⭐⭐

6.1 什么是 Stream

集合的流式处理，流水线式操作数据。

6.2 三步操作

  1. 获取流：list.stream()
  2. 中间操作（filter、map、sorted）
  3. 终结操作（collect、forEach、count）

6.3 获取流

java
List<String> list = Arrays.asList("a", "b", "c");
Stream<String> stream = list.stream();

int[] arr = {1, 2, 3};
IntStream intStream = Arrays.stream(arr);

6.4 中间操作 ⭐⭐

操作 作用
filter 过滤
map 转换
sorted 排序
distinct 去重
limit 限制个数
skip 跳过
flatMap 扁平化
java
List<String> result = list.stream()
    .filter(s -> s.length() > 2)        // 过滤
    .map(String::toUpperCase)           // 转大写
    .distinct()                         // 去重
    .sorted()                           // 排序
    .collect(Collectors.toList());

6.5 终结操作 ⭐⭐

操作 作用
forEach 遍历
count 计数
collect 收集
reduce 归约
anyMatch/allMatch 匹配
java
long count = list.stream().filter(s -> s.length() > 2).count();

boolean anyMatch = list.stream().anyMatch(s -> s.startsWith("a"));

6.6 collect 收集到集合 ⭐⭐

java
List<String> list = stream.collect(Collectors.toList());
Set<String> set = stream.collect(Collectors.toSet());
Map<String, Integer> map = stream.collect(
    Collectors.toMap(s -> s, String::length));

// 分组
Map<Integer, List<String>> grouped = stream.collect(
    Collectors.groupingBy(String::length));

// 分区
Map<Boolean, List<String>> partitioned = stream.collect(
    Collectors.partitioningBy(s -> s.length() > 3));

6.7 黑马经典案例 ⭐⭐⭐

java
List<Student> students = Arrays.asList(
    new Student("张三", 95),
    new Student("李四", 82),
    new Student("王五", 76),
    new Student("赵六", 58)
);

// 1. 找出及格的学生
List<String> passNames = students.stream()
    .filter(s -> s.getScore() >= 60)
    .map(Student::getName)
    .collect(Collectors.toList());

// 2. 按成绩排序
List<Student> sorted = students.stream()
    .sorted(Comparator.comparingInt(Student::getScore).reversed())
    .collect(Collectors.toList());

// 3. 统计各分数段人数
Map<String, Long> stats = students.stream()
    .collect(Collectors.groupingBy(
        s -> {
            if (s.getScore() >= 90) return "A";
            else if (s.getScore() >= 80) return "B";
            else if (s.getScore() >= 70) return "C";
            else return "D";
        },
        Collectors.counting()
    ));

// 4. 最高分 / 平均分
Optional<Student> top = students.stream()
    .max(Comparator.comparingInt(Student::getScore));

double avg = students.stream()
    .mapToInt(Student::getScore)
    .average()
    .orElse(0);

七、Optional ⭐

避免 NullPointerException。

java
Optional<String> opt = Optional.ofNullable("hello");

if (opt.isPresent()) System.out.println(opt.get());

// 默认值
String s = opt.orElse("default");

// 抛出异常
String s = opt.orElseThrow(() -> new RuntimeException("空"));

八、力扣实战 ⭐⭐

LeetCode 136. 只出现一次的数字（Stream）

java
class Solution {
    public int singleNumber(int[] nums) {
        return Arrays.stream(nums).reduce(0, (a, b) -> a ^ b);
    }
}

LeetCode 169. 多数元素

java
class Solution {
    public int majorityElement(int[] nums) {
        Map<Integer, Long> map = Arrays.stream(nums)
            .boxed()
            .collect(Collectors.groupingBy(
                Function.identity(),
                Collectors.counting()));
        return map.entrySet().stream()
            .max(Map.Entry.comparingByValue())
            .get()
            .getKey();
    }
}

九、面试常问 ⭐⭐

💡 Lambda 表达式的本质？ 匿名函数对象，编译为 invokeDynamic 指令。

💡 Stream 的中间操作和终结操作区别？

  • 中间操作：返回新 Stream，可链式
  • 终结操作：返回具体结果，触发处理

💡 map vs flatMap？
