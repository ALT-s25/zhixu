三、String 类 ⭐⭐⭐（黑马重点）

3.1 String 本质

java
public final class String
    implements java.io.Serializable, Comparable<String>, CharSequence {
    private final char value[];   // 内部是 final char[]
}

⚠ String 不可变！

3.2 字符串常量池 ⭐⭐

java
String s1 = "hello";     // 走常量池

System.out.println(s1 == s2);     // true
System.out.println(s1 == s3);     // false
System.out.println(s1.equals(s3)); // true

3.3 String 常用方法 ⭐⭐⭐

java

3.4 黑马经典案例 ⭐⭐

案例 1：用户名校验

java
public static boolean checkUsername(String username) {
    if (username.length() < 6 || username.length() > 12) return false;
    if (!Character.isLetter(username.charAt(0))) return false;
    for (int i = 0; i < username.length(); i++) {
        char c = username.charAt(i);
        if (!Character.isLetterOrDigit(c) && c != '_') return false;
    }
    return true;
}

案例 2：字符串反转

java
public static String reverse(String s) {
    return new StringBuilder(s).reverse().toString();
}

案例 3：统计字符出现次数

java
public static int countChar(String s, char target) {
    int count = 0;
    for (int i = 0; i < s.length(); i++) {
        if (s.charAt(i) == target) count++;
    }
    return count;
}

五、ArrayList 集合 ⭐⭐⭐

黑马视频单独：数组、ArrayList 是 Java 中最常用的容器。

5.1 为什么用 ArrayList

数组长度固定，ArrayList 可变。

5.2 基本使用

java
import java.util.ArrayList;

ArrayList<String> list = new ArrayList<>();

// 添加
list.add("张三");
list.add("李四");
list.add(0, "王五");   // 指定位置插入

// 获取
list.get(0);              // "王五"
list.size();

// 删除
list.remove(0);            // 按下标
list.remove("张三");       // 按值（首次出现的）

// 修改
list.set(0, "赵六");

// 判断
list.contains("张三");
list.isEmpty();

// 遍历
for (int i = 0; i < list.size(); i++) {
    System.out.println(list.get(i));
}

for (String s : list) {
    System.out.println(s);
}

八、Object 类 ⭐

所有类的父类。

8.1 常用方法

java
// 1. toString：返回对象的字符串表示
// 默认：类名@哈希码
// 重写后：属性信息

@Override
public String toString() {
    return "Student{name=" + name + ", score=" + score + "}";
}

// 2. equals：比较两个对象是否相等
// 默认 ==，重写后比较内容

@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (o == null || getClass() != o.getClass()) return false;
    Student s = (Student) o;
    return score == s.score && Objects.equals(name, s.name);
}

// 3. hashCode：返回哈希码
// 重写 equals 必重写 hashCode

@Override
public int hashCode() {
    return Objects.hash(name, score);
}

public static String format(String template, Object... args) {
    StringBuilder sb = new StringBuilder(template);
    for (Object arg : args) {
        int idx = sb.indexOf("{}");
        if (idx >= 0) {
            sb.replace(idx, idx + 2, arg.toString());
        }
    }
    return sb.toString();
}

十、力扣实战 ⭐⭐

LeetCode 344. 反转字符串

java
class Solution {
    public void reverseString(char[] s) {
        int left = 0, right = s.length - 1;
        while (left < right) {
            char temp = s[left];
            s[left] = s[right];
            s[right] = temp;
            left++; right--;
        }
    }
}

LeetCode 387. 字符串中的第一个唯一字符

java
class Solution {
    public int firstUniqChar(String s) {
        int[] count = new int[26];
        for (char c : s.toCharArray()) count[c - 'a']++;
        for (int i = 0; i < s.length(); i++) {
            if (count[s.charAt(i) - 'a'] == 1) return i;
        }
        return -1;
    }
}

十一、面试常问 ⭐

💡 String 不可变的原因？

  1. final class 不能继承
  2. final char[] 内部数组不能修改
  3. 没有暴露修改方法

💡 == 和 equals 的区别？

  • == 基本类型比值，引用类型比地址
  • equals 默认 ==，但 String 等类重写后比内容

💡 String / StringBuilder / StringBuffer？

  • String 不可变（拼接差）
  • StringBuilder 可变（最快）
  • StringBuffer 可变（线程安全）

💡 new String("abc") 创建几个对象？ 1 或 2 个。字面量在常量池 + 堆对象（如果常量池不存在）。
