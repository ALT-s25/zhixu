二、File 类 ⭐⭐

2.1 File 表示

java
import java.io.File;

File f = new File("D:\\test.txt");

2.2 常用方法

java
// 判断
f.exists();        // 文件/目录是否存在
f.isFile();         // 是否是文件
f.isDirectory();    // 是否是目录

// 获取信息
f.getName();         // 文件名
f.getPath();         // 路径
f.getAbsolutePath(); // 绝对路径
f.length();          // 文件大小（字节）

// 创建/删除
f.createNewFile();   // 创建文件
dir.mkdir();          // 创建单层目录
dir.mkdirs();        // 创建多层目录
f.delete();          // 删除

// 列出内容
String[] list = dir.list();
File[] files = dir.listFiles();

2.3 黑马经典案例：递归遍历 ⭐⭐

java
public static void listFiles(File dir) {
    if (!dir.isDirectory()) return;
    File[] files = dir.listFiles();
    if (files == null) return;
    for (File f : files) {
        if (f.isFile()) {
            System.out.println("文件：" + f.getName());
        } else {
            System.out.println("目录：" + f.getName());
            listFiles(f);    // 递归
        }
    }
}

四、字节流 ⭐⭐

4.1 FileInputStream（读）

java
public void readFile(String path) throws IOException {
    try (FileInputStream fis = new FileInputStream(path)) {
        int b;
        while ((b = fis.read()) != -1) {
            System.out.print((char) b);
        }
    }
}

4.2 FileOutputStream（写）

java
public void writeFile(String path, String content) throws IOException {
    try (FileOutputStream fos = new FileOutputStream(path, true)) {
        fos.write(content.getBytes(StandardCharsets.UTF_8));
    }
}

4.3 黑马经典案例：文件复制 ⭐⭐⭐

java
public void copyFile(String src, String dst) throws IOException {
    try (FileInputStream fis = new FileInputStream(src);
         FileOutputStream fos = new FileOutputStream(dst)) {
        byte[] buf = new byte[1024];
        int len;
        while ((len = fis.read(buf)) != -1) {
            fos.write(buf, 0, len);
        }
}

4.4 缓冲字节流（性能更高）

java
public void bufferedCopy(String src, String dst) throws IOException {
    try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream(src));
         BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(dst))) {
        byte[] buf = new byte[1024];
        int len;
        while ((len = bis.read(buf)) != -1) {
            bos.write(buf, 0, len);
        }
    }
}

五、字符流 ⭐⭐

5.1 FileReader / FileWriter

java
try (FileReader fr = new FileReader(path)) {
    int c;
    while ((c = fr.read()) != -1) System.out.print((char) c);
}

try (FileWriter fw = new FileWriter(path)) {
    fw.write("Hello, World!");

5.2 BufferedReader / BufferedWriter ⭐⭐

java
try (BufferedReader br = new BufferedReader(new FileReader(path))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
}

try (BufferedWriter bw = new BufferedWriter(new FileWriter(path))) {
    bw.write("Hello");
    bw.newLine();   // 换行
}

六、转换流 ⭐

字节流 ↔ 字符流（指定编码）：

java
try (BufferedReader br = new BufferedReader(
        new InputStreamReader(new FileInputStream(path), "UTF-8"))) {
    String line;
    while ((line = br.readLine()) != null) System.out.println(line);
}

⚠ 黑马经典坑：中文乱码 = 没指定编码。

七、对象流 ⭐⭐（序列化）

7.1 序列化与反序列化

  • 序列化：对象 → 字节流
  • 反序列化：字节流 → 对象

7.2 序列化示例

java
public class Student implements Serializable {
    private static final long serialVersionUID = 1L;
    private String name;
    private int age;
    private transient String password;  // 不参与序列化
}

// 序列化
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("student.bin"))) {
    Student s = new Student();
    s.setName("张三");
    oos.writeObject(s);
}

// 反序列化
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("student.bin"))) {
    Student s = (Student) ois.readObject();
    System.out.println(s.getName());
}

⚠ 黑马经典：

  • 必须实现 Serializable
  • 加 serialVersionUID
  • transient 字段不序列化

九、黑马实战综合项目 ⭐⭐⭐

9.1 大文件复制（性能优化）

java
public static void bigFileCopy(String src, String dst) throws IOException {
    long start = System.currentTimeMillis();

    try (BufferedInputStream bis = new BufferedInputStream(
            new FileInputStream(src));
         BufferedOutputStream bos = new BufferedOutputStream(
            new FileOutputStream(dst))) {
        byte[] buf = new byte[8192];   // 8KB 缓冲区
        int len;
        while ((len = bis.read(buf)) != -1) {
            bos.write(buf, 0, len);
        }
    }

    long end = System.currentTimeMillis();
    System.out.println("复制完成，耗时：" + (end - start) + "ms");
}

9.2 文件夹复制

java
public static void copyDir(File src, File dst) throws IOException {
    if (!dst.exists()) dst.mkdirs();
    for (File f : src.listFiles()) {
        File dest = new File(dst, f.getName());
        if (f.isFile()) {
            // 复制文件
            Files.copy(f.toPath(), dest.toPath());
        } else {
            copyDir(f, dest);
        }
    }
}

9.3 日志记录器

java
public class Logger {
    private static final String LOG_FILE = "app.log";

    public static void info(String msg) {
        String timestamp = LocalDateTime.now()
            .format(DateTimeFormatter.ofPattern("yyyy-MM-dd HH:mm:ss"));
        String log = "[" + timestamp + "] INFO: " + msg + "\n";
        try (BufferedWriter bw = new BufferedWriter(
                new FileWriter(LOG_FILE, true))) {
            bw.write(log);
        } catch (IOException e) {
            e.printStackTrace();
        }
    }
}

十、项目场景（实战导向）⭐

🎯 场景 1：导出 CSV

java
public static void exportCSV(List<Student> students, String path) throws IOException {
    try (BufferedWriter bw = new BufferedWriter(
            new OutputStreamWriter(new FileOutputStream(path), "UTF-8"))) {
        bw.write("姓名,年龄,分数\n");
        for (Student s : students) {
            bw.write(s.getName() + "," + s.getAge() + "," + s.getScore() + "\n");
        }
}

十一、面试常问 ⭐⭐

💡 字节流 vs 字符流？

  • 字节流：图片、视频、二进制
  • 字符流：文本文件

💡 什么是序列化？为什么需要？ 把对象转为字节序列，便于存储或网络传输。

💡 transient 关键字？ 不参与序列化。

💡 try-with-resources 的好处？ 自动关闭资源，避免忘记 close。
