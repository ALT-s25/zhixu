## 二、枚举（enum）⭐⭐

### 2.1 基本定义

```java
public enum Color {
    RED, GREEN, BLUE;
}

Color c = Color.RED;
```

### 2.2 带属性和方法的枚举

```java
public enum Status {
    OK(200, "成功"),
    ERROR(500, "服务器错误"),
    NOT_FOUND(404, "未找到");

    private int code;
    private String msg;

    Status(int code, String msg) {
        this.code = code;
        this.msg = msg;
    }

    public int getCode() { return code; }
    public String getMsg() { return msg; }
}
```

## 三、设计模式概述

设计模式是**代码设计的经验总结**（GoF 23 种）。

- **创建型**：单例、工厂、抽象工厂、建造者、原型
- **结构型**：装饰者、适配器、代理、桥接、组合、外观、享元
- **行为型**：模板、策略、观察者、迭代器、责任链、命令、备忘录

## 四、单例模式 ⭐⭐⭐⭐

**一个类只有一个实例**。

### 4.1 饿汉式（线程安全）

```java
public class Singleton {
    private static final Singleton INSTANCE = new Singleton();

    private Singleton() {}

    public static Singleton getInstance() {
        return INSTANCE;
    }
}
```

### 4.2 懒汉式（线程不安全）

```java
public class Singleton {
    private static Singleton instance;

    private Singleton() {}

    public static Singleton getInstance() {
        if (instance == null) {
            instance = new Singleton();
        }
        return instance;
    }
}
```

### 4.3 双重检查（推荐）⭐⭐⭐⭐

```java
public class Singleton {
    private static volatile Singleton instance;

    private Singleton() {}

    public static Singleton getInstance() {
        if (instance == null) {
            synchronized (Singleton.class) {
                if (instance == null) {
                    instance = new Singleton();
                }
            }
        }
        return instance;
    }
}
```

> ⚠ **volatile 必须加**（防止指令重排）。

### 4.4 静态内部类（最佳）

```java
public class Singleton {
    private Singleton() {}

    private static class Holder {
        private static final Singleton INSTANCE = new Singleton();
    }

    public static Singleton getInstance() {
        return Holder.INSTANCE;
    }
}
```

### 4.5 枚举实现（最简洁）

```java
public enum Singleton {
    INSTANCE;

    public void doSomething() {
        // ...
    }
}
```

## 五、工厂模式 ⭐⭐⭐

**将对象的创建交给工厂类**。

### 5.1 简单工厂

```java
public interface Shape {
    void draw();
}

public class Circle implements Shape {
    public void draw() { System.out.println("画圆形"); }
}

public class Rectangle implements Shape {
    public void draw() { System.out.println("画矩形"); }
}

// 工厂
public class ShapeFactory {
    public static Shape create(String type) {
        if ("circle".equals(type)) return new Circle();
        if ("rectangle".equals(type)) return new Rectangle();
        return null;
    }
}

// 使用
Shape s = ShapeFactory.create("circle");
s.draw();
```

### 5.2 黑马经典：日志工厂 ⭐

```java
public interface Logger {
    void log(String msg);
}

public class ConsoleLogger implements Logger {
    public void log(String msg) { System.out.println(msg); }
}

public class FileLogger implements Logger {
    public void log(String msg) {
        // 写文件
    }
}

public class LoggerFactory {
    public static Logger create(String type) {
        if ("console".equals(type)) return new ConsoleLogger();
        if ("file".equals(type)) return new FileLogger();
        return new ConsoleLogger();   // 默认
    }
}
```

## 六、装饰者模式 ⭐⭐

**动态地给对象添加职责**，比继承更灵活。

### 黑马案例：IO 流包装

```java
InputStream is = new FileInputStream("test.txt");
InputStream bis = new BufferedInputStream(is);   // 装饰
InputStream gis = new GZIPInputStream(bis);      // 再装饰
```

### 自定义装饰者

```java
interface Beverage {
    String getDescription();
    double cost();
}

class Coffee implements Beverage {
    public String getDescription() { return "咖啡"; }
    public double cost() { return 20; }
}

// 装饰者
class MilkDecorator implements Beverage {
    private Beverage beverage;

    public MilkDecorator(Beverage b) { this.beverage = b; }

    public String getDescription() {
        return beverage.getDescription() + " + 牛奶";
    }
    public double cost() {
        return beverage.cost() + 5;
    }
}

// 使用
Beverage b = new MilkDecorator(new Coffee());
System.out.println(b.getDescription() + " " + b.cost());
// "咖啡 + 牛奶" 25
```

## 七、代理模式 ⭐⭐⭐

**为其他对象提供一种代理以控制对这个对象的访问**。

### 7.1 静态代理

```java
interface Service {
    void doService();
}

class RealService implements Service {
    public void doService() { System.out.println("真实服务"); }
}

class ProxyService implements Service {
    private RealService real;

    public ProxyService(RealService real) { this.real = real; }

    public void doService() {
        System.out.println("前���增强");
        real.doService();
        System.out.println("后置增强");
    }
}
```

### 7.2 动态代理 ⭐⭐⭐

```java
InvocationHandler handler = new InvocationHandler() {
    private final Object target;

    public InvocationHandler(Object target) { this.target = target; }

    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        System.out.println("前置增强");
        Object result = method.invoke(target, args);
        System.out.println("后置增强");
        return result;
    }
};

Service proxy = (Service) Proxy.newProxyInstance(
    real.getClass().getClassLoader(),
    real.getClass().getInterfaces(),
    handler
);
proxy.doService();
```

> 💡 **Spring AOP 就是动态代理**。

## 八、模板模式 ⭐

**定义算法骨架，将具体步骤延迟到子类**。

```java
abstract class BeverageTemplate {
    public final void make() {       // 模板方法（final）
        boilWater();
        brew();
        pourInCup();
        addCondiments();             // 抽象方法
    }

    void boilWater() { System.out.println("烧水"); }
    void pourInCup() { System.out.println("倒入杯中"); }
    abstract void brew();
    abstract void addCondiments();
}

class Tea extends BeverageTemplate {
    void brew() { System.out.println("泡茶"); }
    void addCondiments() { System.out.println("加柠檬"); }
}

class Coffee extends BeverageTemplate {
    void brew() { System.out.println("冲咖啡"); }
    void addCondiments() { System.out.println("加糖"); }
}
```

## 九、其他设计模式（了解）

### 9.1 策略模式

```java
interface Strategy {
    int execute(int a, int b);
}

class AddStrategy implements Strategy {
    public int execute(int a, int b) { return a + b; }
}

class Context {
    private Strategy strategy;
    public void setStrategy(Strategy s) { this.strategy = s; }
    public int execute(int a, int b) { return strategy.execute(a, b); }
}
```

### 9.2 观察者模式

```java
// 简易版：监听器机制
class EventBus {
    private List<Runnable> listeners = new ArrayList<>();
    public void register(Runnable listener) { listeners.add(listener); }
    public void fire() {
        for (Runnable l : listeners) l.run();
    }
}
```

## 十、黑马实战：JDBC 模板模式 ⭐⭐

```java
abstract class JdbcTemplate {
    public final Object execute(String sql) {
        try {
            Connection conn = getConnection();
            PreparedStatement ps = conn.prepareStatement(sql);
            ResultSet rs = ps.executeQuery();
            Object result = mapRow(rs);
            rs.close();
            ps.close();
            conn.close();
            return result;
        } catch (Exception e) {
            throw new RuntimeException(e);
        }
    }

    protected abstract Object mapRow(ResultSet rs) throws SQLException;
}

// 使用
public class UserQuery extends JdbcTemplate {
    protected Object mapRow(ResultSet rs) throws SQLException {
        User u = new User();
        u.setName(rs.getString("name"));
        return u;
    }
}
```

> 💡 **Spring JdbcTemplate 就是这种思路**。

## 十一、面试常问 ⭐⭐⭐

> 💡 **单例模式有哪几种实现？各自的优缺点？**
> | 方式 | 线程 | 性能 |
> |------|------|------|
> | 饿汉 | ✅ | 高 |
> | 懒汉 | ❌ | 中 |
> | 双重检查 | ✅ | 中 |
> | 静态内部类 | ✅ | 高 |
> | 枚举 | ✅ | 高 |

> 💡 **工厂模式和策略模式的区别？**
> - 工厂模式：创建对象
> - 策略模式：选择行为

> 💡 **动态代理 vs 静态代理？**
> - 静态：手动写代理类
> - 动态：运行时生成（如 JDK Proxy、CGLIB）

> 💡 **装饰者 vs 代理的��别？**
> - 装饰者：增强对象职责
> - 代理：控制对象访问
