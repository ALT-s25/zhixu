四、数据类型 ⭐

4.1 8 种基本数据类型

类别 类型 字节 取值范围
整数 byte 1 -128 ~ 127
整数 short 2 -32768 ~ 32767
整数 int 4 -2³¹ ~ 2³¹-1（约 ±21 亿）
整数 long 8 -2⁶³ ~ 2⁶³-1
浮点 float 4 ±3.4e38（7 位精度）
浮点 double 8 ±1.8e308（15 位精度）
字符 char 2 0 ~ 65535
布尔 boolean 1 true / false

记忆口诀：byte short int long → 1 2 4 8 字节；float double → 4 8 字节

4.3 引用数据类型

除 8 种基本类型外都是引用类型：

java

⚠ 黑马常见坑：

五、数据类型转换 ⭐⭐

5.1 自动类型转换（小→大）

java
int i = 100;
long l = i;            // int → long 自动转
double d = l;          // long → double 自动转

自动转换规则：byte → short → int → long → float → double （byte/short/char 在运算时自动转 int）

5.2 强制类型转换（大→小）

java
double d = 3.14;
int i = (int) d;       // i = 3（截断小数，不四舍五入）

int a = 200;
byte b = (byte) a;     // 溢出！b = -56

⚠ 黑马常考：

  • 截断 vs 四舍五入
  • 精度丢失
  • 整数溢出

5.3 实战练习 ⭐

java
// 练习 1
byte b1 = 10, b2 = 20;
byte b3 = b1 + b2;      // ❌ 编译错误（byte + byte 自动转 int）
int b3 = b1 + b2;       // ✅

// 练习 2
char c = 'A';
int n = c + 1;          // n = 66（char 转 int）

// 练习 3
double d = 12.5;
float f = (float) d;    // 必须强转

💡 项目应用：Web 接口返回金额时，要考虑 double 转 BigDecimal，避免精度问题。

七、键盘录入（Scanner）⭐

7.1 基本使用

java
import java.util.Scanner;

public class ScannerDemo {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("请输入姓名：");
        String name = sc.nextLine();

        System.out.print("请输入年龄：");
        int age = sc.nextInt();

        System.out.println("你好，" + name + "，" + age + " 岁");

        sc.close();
    }
}

7.2 next() vs nextLine()

方法 行为
next() 读到空格或换行停止
nextLine() 读到换行停止，读整行

7.3 实战练习

案例：用户登录

java
import java.util.Scanner;

public class Login {
    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);

        System.out.print("用户名：");
        String username = sc.nextLine();

        System.out.print("密码：");
        String password = sc.nextLine();

            System.out.println("登录成功");

    }
}

十、力扣实战 ⭐⭐

LeetCode 1. 两数之和

题目：给定数组和目标值，找出两个数的下标使其和等于目标值。

思路：用 HashMap 存 (值, 下标)，遍历时检查 target-num 是否在 map 中。

java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        return new int[0];
    }
}

本题涉及 HashMap 和循环基础，综合运用。学完集合再回顾更清晰。
