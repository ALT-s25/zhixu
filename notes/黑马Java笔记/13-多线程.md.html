二、进程 vs 线程 ⭐

维度 进程 线程
概念 运行的程序 进程内的执行流
资源 独立内存 共享进程内存
开销 大 小

💡 比喻：进程 = 工厂，线程 = 工人。

三、线程创建（3 种方式）⭐⭐

3.1 继承 Thread

java
public class MyThread extends Thread {
    @Override
    public void run() {
        for (int i = 0; i < 100; i++) {
            System.out.println(getName() + ": " + i);
        }
    }
}

MyThread t = new MyThread();
t.start();    // 启动新线程

3.2 实现 Runnable ⭐（推荐）

java
public class MyRunnable implements Runnable {
    @Override
    public void run() {
        for (int i = 0; i < 100; i++) {
            System.out.println(Thread.currentThread().getName() + ": " + i);
        }
    }
}

new Thread(new MyRunnable()).start();

// Lambda
new Thread(() -> System.out.println("Hello from " + Thread.currentThread().getName())).start();

3.3 实现 Callable（有返回值）

java
public class MyCallable implements Callable<Integer> {
    @Override
    public Integer call() {
        return 42;
    }
}

ExecutorService es = Executors.newSingleThreadExecutor();
Future<Integer> future = es.submit(new MyCallable());
int result = future.get();    // 阻塞获取

六、线程同步 ⭐⭐⭐⭐

6.1 为什么需要同步

多线程同时操作共享数据，可能产生数据不一致。

6.2 synchronized ⭐⭐⭐

同步方法

java
public synchronized void increment() {  // 锁 this
    count++;
}

同步代码块

java
public void increment() {
    synchronized (this) {
        count++;
    }
}

静态同步方法

java
public static synchronized void increment() {  // 锁 类.class
    count++;
}

⚠ 黑马经典：锁的是对象不是方法。

6.3 黑马经典案例：卖票 ⭐⭐⭐

java
public class Ticket implements Runnable {
    private int count = 100;

    @Override
    public void run() {
        while (true) {
            synchronized (this) {
                if (count <= 0) break;
                System.out.println(Thread.currentThread().getName() + " 卖票：" + count);
                count--;
            }
            // 模拟出票时间
            try { Thread.sleep(10); } catch (InterruptedException e) {}
        }
    }
}

// 测试
Ticket t = new Ticket();
new Thread(t, "窗口1").start();
new Thread(t, "窗口2").start();
new Thread(t, "窗口3").start();

6.4 Lock 接口（JDK 5+）

java
Lock lock = new ReentrantLock();

public void increment() {
    lock.lock();

    } finally {
        lock.unlock();
    }
}

七、死锁 ⭐

java
Object lockA = new Object();
Object lockB = new Object();

new Thread(() -> {
    synchronized (lockA) {
        try { Thread.sleep(100); } catch (InterruptedException e) {}
        synchronized (lockB) { }
    }
}).start();

new Thread(() -> {
    synchronized (lockB) {
        try { Thread.sleep(100); } catch (InterruptedException e) {}
        synchronized (lockA) { }
    }
}).start();

八、线程通信 ⭐⭐

8.1 wait / notify

java
// 必须在 synchronized 中
synchronized (lock) {
    lock.wait();        // 等待
    lock.notify();       // 唤醒一个
    lock.notifyAll();    // 唤醒所有
}

⚠ wait 释放锁，sleep 不释放锁。

8.2 生产者-消费者 ⭐⭐⭐

java
public class ProducerConsumer {
    private static final int CAPACITY = 10;
    private Queue<Integer> queue = new LinkedList<>();
    private Object lock = new Object();

    public void produce() throws InterruptedException {
        while (true) {
            synchronized (lock) {
                while (queue.size() == CAPACITY) {   // 必须用 while
                    lock.wait();
                }
                queue.offer((int)(Math.random() * 100));
                lock.notify();
            }
            Thread.sleep(500);
        }
    }

    public void consume() throws InterruptedException {
        while (true) {
            synchronized (lock) {
                while (queue.isEmpty()) {
                    lock.wait();
                }
                queue.poll();
                lock.notify();
            }
            Thread.sleep(500);
        }
    }
}

⚠ 必须用 while 而非 if（防虚假唤醒）。

九、线程池 ⭐⭐⭐

9.1 为什么用线程池

  • 减少线程创建/销毁开销
  • 限制线程数

9.2 创建线程池

java
ExecutorService pool = Executors.newFixedThreadPool(5);    // 固定 5 线程
ExecutorService pool2 = Executors.newCachedThreadPool();   // 弹性
ExecutorService pool3 = Executors.newSingleThreadExecutor(); // 单线程

pool.execute(() -> System.out.println("Task"));
pool.shutdown();

9.3 自定义线程池（推荐）⭐⭐

java
ThreadPoolExecutor pool = new ThreadPoolExecutor(
    5, 10, 60, TimeUnit.SECONDS,
    new LinkedBlockingQueue<>(100),
    Executors.defaultThreadFactory(),
    new ThreadPoolExecutor.CallerRunsPolicy()
);

十、黑马小项目：模拟银行叫号 ⭐⭐

java
public class BankQueue {
    public static void main(String[] args) {
        ExecutorService pool = Executors.newFixedThreadPool(3);

        for (int i = 1; i <= 10; i++) {
            final int num = i;
            pool.execute(() -> {
                System.out.println("客户 " + num + " 办理业务");
                try { Thread.sleep(1000); } catch (InterruptedException e) {}
                System.out.println("客户 " + num + " 办完离开");
            });
        }

        pool.shutdown();
    }
}

十一、面试常问 ⭐⭐⭐

💡 创建线程的 3 种方式？

  1. 继承 Thread
  2. 实现 Runnable（推荐）
  3. 实现 Callable（有返回值）

💡 run() vs start()？

  • start()：启动新线程

💡 synchronized vs volatile？ | synchronized | volatile | |-------------|----------| | 原子性 ✅ | 原子性 ❌ | | 可见性 ✅ | 可见性 ✅ | | 阻塞 | 不阻塞 |

💡 sleep vs wait？ | sleep | wait | |-------|------| | 不释放锁 | 释放锁 | | Thread | Object |
