## 三、分支结构（if）

### 3.1 单分支

```java
if (条件) {
    // ...
}
```

### 3.2 双分支

```java
if (条件) {
    // ...
} else {
    // ...
}
```

### 3.3 多分支

```java
if (条件1) {
    // ...
} else if (条件2) {
    // ...
} else {
    // ...
}
```

### 3.4 if 嵌套

```java
if (外层条件) {
    if (内层条件) {
        // ...
    }
}
```

> 💡 **项目场景**：判断用户是否登录 → 判断是否有权限 → 执行业务

## 四、分支结构（switch）⭐

### 4.1 基本语法

```java
switch (表达式) {
    case 值1:
        // ...
        break;
    case 值2:
        // ...
        break;
    default:
        // 都不匹配
}
```

### 4.2 黑马经典案例 ⭐⭐

**根据月份判断季节**：
```java
int month = 3;
String season;
switch (month) {
    case 12:
    case 1:
    case 2:
        season = "冬季";
        break;
    case 3:
    case 4:
    case 5:
        season = "春季";
        break;
    // ...
}
```

### 4.3 switch 新特性（Java 14+）

```java
// 箭头语法（不需要 break）
String day = "MON";
String result = switch (day) {
    case "MON", "TUE", "WED", "THU", "FRI" -> "工作日";
    case "SAT", "SUN" -> "周末";
    default -> "未知";
};
```

### 4.4 switch 表达式支持类型

- **byte, short, int, char, String, enum**
- ❌ 不支持 long, float, double, boolean

> ⚠ **黑马常见坑**：
> - **case 穿透**：不写 break 会继续执行下个 case
> - case 必须是**常量**，不能是变量

## 五、循环结构 ⭐

### 5.1 for 循环 ⭐⭐

**基本语法**：
```java
for (初始化; 条件; 迭代表达式) {
    // 循环体
}
```

**黑马经典案例 - 9×9 乘法表**：
```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i*j) + "\t");
    }
    System.out.println();
}
```

### 5.2 while 循环

```java
int i = 1;
while (i <= 5) {
    System.out.println(i);
    i++;
}
```

### 5.3 do-while 循环

```java
int i = 1;
do {
    System.out.println(i);
    i++;
} while (i <= 5);
```

**特点**：先执行再判断，**至少执行一次**。

### 5.4 三种循环的区别 ⭐

| 维度 | for | while | do-while |
|------|-----|-------|----------|
| 适用 | 循环次数已知 | 循环次数未知 | 至少执行一次 |
| 初始化 | 语法内置 | 外部 | 外部 |
| 特点 | 简洁 | 灵活 | 不管条件，先跑一次 |

### 5.5 死循环

```java
// 写法 1
for (;;) {
    // ...
}

// 写法 2
while (true) {
    // ...
}

// 用于服务端持续监听
```

## 六、跳转关键字

### 6.1 break

**终止当前循环**或 switch。

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) break;
    System.out.println(i);    // 0 1 2 3 4
}
```

### 6.2 continue

**跳过本次循环**，进入下一次。

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;    // 跳过偶数
    System.out.println(i);        // 1 3 5 7 9
}
```

### 6.3 return

**结束整个方法**。

## 七、循环嵌套 ⭐⭐

### 7.1 打印三角形

```java
// 直角三角形
for (int i = 1; i <= 5; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print("*");
    }
    System.out.println();
}
// 输出：
// *
// **
// ***
// ****
// *****

// 等腰三角形
for (int i = 1; i <= 5; i++) {
    for (int k = 5; k > i; k--) System.out.print(" ");
    for (int j = 1; j <= 2*i-1; j++) System.out.print("*");
    System.out.println();
}
```

### 7.2 嵌套循环的时间复杂度

**黑马面试常问**：
```java
for (int i = 0; i < n; i++) {
    for (int j = 0; j < n; j++) {
        // ...
    }
}
// 时间复杂度：O(n²)
```

## 八、项目场景（实战导向）⭐

### 🎯 场景 1：用户登录验证（while）

```java
Scanner sc = new Scanner(System.in);
int maxTry = 3;
int tryCount = 0;

while (tryCount < maxTry) {
    System.out.print("请输入密码：");
    String pwd = sc.nextLine();
    if (pwd.equals("123")) {
        System.out.println("登录成功");
        break;
    } else {
        tryCount++;
        System.out.println("密码错误，还剩 " + (maxTry - tryCount) + " 次机会");
    }
}
```

### 🎯 场景 2：菜单选择（switch）

```java
Scanner sc = new Scanner(System.in);
System.out.println("==== 主菜单 ====");
System.out.println("1. 查询");
System.out.println("2. 添加");
System.out.println("3. 删除");
System.out.println("0. 退出");

int choice = sc.nextInt();
switch (choice) {
    case 1: System.out.println("查询"); break;
    case 2: System.out.println("添加"); break;
    case 3: System.out.println("删除"); break;
    case 0: System.out.println("退出"); break;
    default: System.out.println("非法输入");
}
```

### 🎯 场景 3：分页处理（for）

```java
// 假设每页 10 条，查询第 3 页
int pageNum = 3;
int pageSize = 10;
int start = (pageNum - 1) * pageSize;    // 20
int end = start + pageSize;              // 30
```

## 九、力扣实战 ⭐⭐

### LeetCode 704. 二分查找

**思路**：有序数组中找 target，每次折半。

```java
class Solution {
    public int search(int[] nums, int target) {
        int left = 0, right = nums.length - 1;
        while (left <= right) {
            int mid = left + (right - left) / 2;   // 防溢出
            if (nums[mid] == target) return mid;
            else if (nums[mid] < target) left = mid + 1;
            else right = mid - 1;
        }
        return -1;
    }
}
```

### LeetCode 367. 有效的完全平方数

```java
class Solution {
    public boolean isPerfectSquare(int num) {
        long left = 1, right = num;
        while (left <= right) {
            long mid = left + (right - left) / 2;
            long sq = mid * mid;
            if (sq == num) return true;
            else if (sq < num) left = mid + 1;
            else right = mid - 1;
        }
        return false;
    }
}
```

## 十、面试常问 ⭐

> 💡 **三种循环怎么选？**
> - 次数已知 → for
> - 次数未知 → while
> - 至少执行一次 → do-while

> 💡 **break 和 continue 的区别？**
> - break：终止循环
> - continue：跳过本次

> 💡 **switch 支持 String 吗？**
> Java 7+ 支持。long/float/double 不支持。
