## 二、集合体系总览 ⭐⭐⭐

```
Collection (单列)
├── List (接口)：有序、可重复

├── HashMap：哈希表，最常用 ⭐⭐⭐
├── LinkedHashMap：保留插入顺序
├── Hashtable：古老线程安全
└── TreeMap：红黑树，键可排序
```

## 四、List 接口 ⭐⭐⭐

### 4.1 特点

- **有序**：按插入顺序
- **可重复**：相同元素可多次出现
- 可按下标访问

### 4.2 ArrayList ⭐⭐⭐（黑马重点）

**底层**：动态数组，初始 10，扩容 1.5 倍。

```java
List<String> list = new ArrayList<>();

// 增删改查
list.add("A");
list.add(1, "B");           // 指定位置插入
list.remove("A");            // 按值删除
list.remove(0);              // 按下标
list.set(0, "C");
list.get(0);
list.contains("A");
list.indexOf("A");
list.size();
list.isEmpty();
list.clear();

// 遍历
for (int i = 0; i < list.size(); i++) System.out.println(list.get(i));
for (String s : list) System.out.println(s);
```

### 4.3 LinkedList

**底层**：双向链表。

```java
LinkedList<String> list = new LinkedList<>();

list.addFirst("A");
list.addLast("B");
list.removeFirst();
list.removeLast();
list.getFirst();
list.getLast();
```

### 4.4 ArrayList vs LinkedList ⭐⭐

| 维度 | ArrayList | LinkedList |
|------|-----------|------------|
| 底层 | 数组 | 双向链表 |
| 随机访问 | O(1) | O(n) |
| 头尾增删 | O(n) | O(1) |
| 内存 | 少 | 多 |
| 场景 | 读多写少 | 增删频繁 |

## 五、Set 接口 ⭐⭐

### 5.1 特点

- **无序**（不保证插入顺序）
- **不可重复**（通过 hashCode + equals 判定）

### 5.2 HashSet ⭐⭐⭐（黑马重点）

```java
Set<String> set = new HashSet<>();

set.add("A");
set.add("B");
set.add("A");     // 不会重复添加
set.size();          // 2

for (String s : set) System.out.println(s);
```

### 5.3 HashSet 去重原理 ⭐⭐⭐

```java
class Student {
    String name;
    int age;

    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Student s = (Student) o;
        return age == s.age && Objects.equals(name, s.name);
    }
}
```

> ⚠ **黑马经典**：放进 HashSet 必须重写 `equals` 和 `hashCode`。

### 5.4 LinkedHashSet

保留**插入顺序**。

### 5.5 TreeSet ⭐

**自动排序**（红黑树）：

```java
Set<Integer> set = new TreeSet<>();
set.add(5); set.add(2); set.add(8);
System.out.println(set);   // [2, 5, 8]
```

## 六、泛型 ⭐⭐

### 6.1 为什么用泛型

```java
// 没有泛型
List list = new ArrayList();
list.add("hello");
list.add(123);          // 可以放任何类型
String s = (String) list.get(0);   // 必须强转

// 有泛型
List<String> list = new ArrayList<>();
list.add("hello");
list.add(123);          // ❌ 编译错误
String s = list.get(0);   // 不需要强转
```

### 6.2 自定义泛型类

```java
public class Box<T> {
    private T value;

    public T getValue() { return value; }
    public void setValue(T value) { this.value = value; }
}

Box<String> box = new Box<>();
box.setValue("hello");
String s = box.getValue();
```

### 6.3 泛型方法

```java
public <T> T getFirst(List<T> list) {
    return list.isEmpty() ? null : list.get(0);
}
```

### 6.4 通配符

```java
// ? extends：上限通配
public void process(List<? extends Number> list) { }
// ? super：下限通配
public void add(List<? super Integer> list) { }
```

> ⚠ **黑马经典**：PECS 原则（Producer Extends, Consumer Super）。

## 七、Map 接口 ⭐⭐⭐⭐

### 7.1 特点

- **键值对**（key-value）
- **键不可重复**，值可以

### 7.2 HashMap ⭐⭐⭐⭐（黑马重点，面试必问）

```java
Map<String, Integer> map = new HashMap<>();

map.put("apple", 5);
map.put("banana", 3);
map.put("apple", 8);        // 覆盖

map.get("apple");            // 8
map.getOrDefault("pear", 0); // 不存在返回默认值
map.containsKey("apple");
map.containsValue(5);
map.remove("banana");
map.size();
map.clear();

// 遍历（三种方式）
// 1. 遍历 key
for (String key : map.keySet()) {
    System.out.println(key + "=" + map.get(key));
}

// 2. 遍历 entry（推荐）
for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + "=" + e.getValue());
}

// 3. 遍历 value
for (Integer v : map.values()) {
    System.out.println(v);
}
```

### 7.3 HashMap 原理（黑马讲+面试必问）⭐⭐⭐⭐

**JDK 8+ 结构**：数组 + 链表 + 红黑树

```
table（默认 16）
   ↓
[i] → 链表（< 8）→ 红黑树（≥ 8）
```

**put 流程**：
1. 算 key 的 hash
2. 定位桶
3. 桶空：直接插入
4. 桶不空：遍历链表，key 相同覆盖；否则插入尾部
5. 链表 > 8 且数组 ≥ 64：转红黑树
6. size > threshold（容量 × 0.75）：扩容 2 倍

### 7.4 LinkedHashMap

保留**插入顺序**。

### 7.5 TreeMap ⭐

**键自动排序**（红黑树）。

### 7.6 HashMap vs Hashtable ⭐

| 维度 | HashMap | Hashtable |
|------|---------|-----------|
| 线程 | 不安全 | 安全 |
| null | 允许 key/value | 不允许 |
| 性能 | 高 | 低 |
| 推荐 | 单线程 | ❌（基本被淘汰） |

## 九、黑马小项目：学生成绩管理系统（集合版）⭐⭐⭐

```java
public class StudentManager {
    private Map<String, Student> students = new HashMap<>();

    public void addStudent(Student s) {
        students.put(s.getId(), s);
    }

    public Student findById(String id) {
        return students.get(id);
    }

    public void removeById(String id) {
        students.remove(id);
    }

    public List<Student> findAll() {
        return new ArrayList<>(students.values());
    }

    public List<Student> findByScoreRange(int min, int max) {
        return students.values().stream()
            .filter(s -> s.getScore() >= min && s.getScore() <= max)
            .collect(Collectors.toList());
    }

    public void printAll() {
        for (Student s : students.values()) {
            System.out.println(s);
        }
    }

    // 按成绩排序
    public List<Student> sortByScore() {
        List<Student> list = new ArrayList<>(students.values());
        Collections.sort(list, (a, b) -> b.getScore() - a.getScore());
        return list;
    }
}
```

```java
public static Map<Character, Integer> countChars(String s) {
    Map<Character, Integer> map = new HashMap<>();
    for (char c : s.toCharArray()) {
        map.merge(c, 1, Integer::sum);   // 累加
    }
    return map;
}
```

## 十一、力扣实战 ⭐⭐

### LeetCode 1. 两数之和

```java
class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int i = 0; i < nums.length; i++) {
            int complement = target - nums[i];
            if (map.containsKey(complement)) {
                return new int[]{map.get(complement), i};
            }
            map.put(nums[i], i);
        }
        return new int[0];
    }
}
```

### LeetCode 49. 字母异位词分组

```java
class Solution {
    public List<List<String>> groupAnagrams(String[] strs) {
        Map<String, List<String>> map = new HashMap<>();
        for (String s : strs) {
            char[] arr = s.toCharArray();
            Arrays.sort(arr);
            String key = new String(arr);
            map.computeIfAbsent(key, k -> new ArrayList<>()).add(s);
        }
        return new ArrayList<>(map.values());
    }
}
```

## 十二、面试常问 ⭐⭐⭐

> 💡 **ArrayList vs LinkedList？**
> - ArrayList：数组，随机访问 O(1)，增删 O(n)
> - LinkedList：链表，随机访问 O(n)，增删 O(1)

> 💡 **HashMap put 流程？**
> 1. 算 hash → 定位桶
> 2. 桶空：直接插入
> 3. 桶不空：遍历链表，key 相同覆盖；否则插入尾部
> 4. 链表 > 8 转红黑树
> 5. size > threshold 扩容 2 倍

> 💡 **HashMap 为什么用红黑树而不是 AVL？**
> 红黑树近似平衡，插入删除更快。

> 💡 **HashSet 去重原理？**
> hashCode + equals。
> 1. 先算 hash 找桶
> 2. 桶中无元素直接放
> 3. 有元素调 equals，相同则放弃

> 💡 **ConcurrentHashMap 1.7 vs 1.8？**
> 1.7 分段锁，1.8 CAS + synchronized。
