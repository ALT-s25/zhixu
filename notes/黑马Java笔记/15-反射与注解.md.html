二、注解 ⭐⭐

2.1 什么是注解

放在源码上的元数据，可被编译器、工具、框架读取。

java
@Override      // 编译器检查
@Deprecated    // 标记过时
@SuppressWarnings("unchecked")
@FunctionalInterface   // 函数式接口

2.2 内置注解

注解 作用
@Override 检查方法重写
@Deprecated 标记已过时
@SuppressWarnings 抑制警告
@FunctionalInterface 函数式接口

2.3 元注解（修饰注解的注解）

元注解 作用
@Target 注解能用在哪些位置
@Retention 注解的生命周期
@Documented 是否包含 Javadoc
@Inherited 子类能否继承
java
@Target({ElementType.METHOD, ElementType.FIELD})
@Retention(RetentionPolicy.RUNTIME)    // 运行时可被反射读取
public @interface MyAnnotation {
    String value() default "";
    int timeout() default 0;
}

2.4 自定义注解

java
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface MyTest {
    String value() default "test";
}

public class MyTestDemo {
    @MyTest("method1")
    public void testMethod1() { }
}

三、反射 ⭐⭐⭐⭐

3.1 什么是反射

运行时动态获取类的信息、调用方法、操作属性的机制。

应用：Spring 依赖注入、MyBatis ORM、Jackson 序列化、JUnit。

3.2 Class 对象 ⭐⭐⭐

每个类在 JVM 中只��一个 Class 对象。

java
// 3 种获取方式
Class<?> c1 = Student.class;
Class<?> c2 = studentObj.getClass();
Class<?> c3 = Class.forName("com.itheima.Student");

System.out.println(c1 == c2);   // true（同一个）

3.3 获取类信息

java
Class<?> c = Class.forName("com.itheima.Student");

c.getName();            // 全限定名
c.getSimpleName();      // 类名

// 构造器
Constructor<?>[] cons = c.getDeclaredConstructors();
Constructor<?> con = c.getDeclaredConstructor(String.class, int.class);

// 字段
Field[] fields = c.getDeclaredFields();
Field nameField = c.getDeclaredField("name");

// 方法
Method[] methods = c.getDeclaredMethods();
Method m = c.getDeclaredMethod("setName", String.class);

3.4 创建对象

java
// 通过 Class
Object obj = c.newInstance();          // 调用无参构造

// 通过 Constructor
Constructor<?> con = c.getDeclaredConstructor(String.class, int.class);
Object obj2 = con.newInstance("张三", 18);

3.5 调用方法

java
Method m = c.getDeclaredMethod("setName", String.class);
Object result = m.invoke(obj, "李四");

3.6 操作字段（含 private）⭐⭐

java
Field nameField = c.getDeclaredField("name");
nameField.setAccessible(true);          // 关闭访问检查

nameField.set(obj, "李四");              // 写入
Object value = nameField.get(obj);       // 读取

3.7 黑马经典案例：通用框架 ⭐⭐⭐

java
// 模拟"运行所有带 @MyTest 注解的方法"
public class TestRunner {
    public static void runTests(Class<?> testClass) {
        Method[] methods = testClass.getDeclaredMethods();
        for (Method m : methods) {
            if (m.isAnnotationPresent(MyTest.class)) {
                try {
                    Object instance = testClass.newInstance();
                    m.invoke(instance);
                    System.out.println("✓ " + m.getName());
                } catch (Exception e) {
                    System.out.println("✗ " + m.getName());
                }
            }
        }
    }
}

3.8 反射优缺点

✅ 优点：动态、灵活（框架基础） ❌ 缺点：性能差、破坏封装、安全风险

⚠ setAccessible(true) 可大幅提升反射性能。

四、综合实战：模拟 Spring IoC ⭐⭐⭐⭐

java
// 自定义注解
@Retention(RetentionPolicy.RUNTIME)
@Target(ElementType.FIELD)
public @interface Autowired {}

// 简易 IoC 容器
public class SimpleApplicationContext {
    private Map<String, Object> beans = new HashMap<>();

    public void scan(String packageName) {
        // 扫描类路径下的所有类
        // 实际项目用反射 + 注解实现
    }

    public Object getBean(String name) {
        return beans.get(name);
    }

    public <T> T getBean(Class<T> clazz) {
        for (Object bean : beans.values()) {
            if (clazz.isInstance(bean)) {
                return clazz.cast(bean);
            }
        }
        return null;
    }
}

五、面试常问 ⭐⭐⭐

💡 什么是反射？ 运行时动态获取类的信息、调用方法、操作属性的机制。

💡 Class 对象 3 种获取方式？

  1. 类名.class
  2. 对象.getClass()
  3. Class.forName("全限定类名")

💡 setAccessible(true) 的作用？ 关闭私有访问检查，可访问 private 字段/方法。

💡 注解的 @Retention 3 种策略？

  • SOURCE：源码期
  • CLASS：字节码期（默认）
  • RUNTIME：运行时（反射读取）

💡 反射的应用？ Spring IoC、AOP、ORM、测试框架、序列化。
