01 安装与连接：先分清服务器和客户端

约 1 分钟阅读你的知识，慢慢成林

目标：能连接MySQL，确定当前版本、当前数据库，并解释数据实际存在哪里。

把MySQL服务器想成保管账本的仓库，命令行、数据库管理软件都是服务窗口。关闭窗口不等于关闭仓库。这个类比只解释分工：客户端也可能缓存信息，但持久化的数据由数据库服务管理。

最短学习顺序：安装服务 → 确认服务启动 → 使用账号连接 → 查询版本 → 创建练习库 → 连接工具。不要先花很多时间美化数据库工具。

sql
SELECT VERSION();   -- 看服务器版本
SELECT DATABASE();  -- 看当前选择的库，未选库可能为NULL
SHOW DATABASES();   -- 查看当前账号有权限看到的库

连接失败按顺序检查：服务是否启动、主机和端口是否正确、账号是否正确、账号是否允许从当前来源连接。Access denied与连接超时不是同一个问题，重新安装通常不是第一步。

动手：连接成功后记下版本，退出客户端再连接。验收：能够解释“客户端窗口关了，数据为什么还在”。原安装说明见同书架的安装附录；示例密码不是你的实际密码。
