零基础导读：本章怎么学

先用泛型消除不必要的强转，再学习 Set 的相等规则；斗地主案例用于串联集合、洗牌、发牌。

先把这件事想明白

泛型让许多类型错误在编译时暴露。HashSet 的去重依赖 equals 与 hashCode 的共同契约，不是看打印文本是否相同。LinkedHashSet 维护迭代顺序；选择集合要同时考虑去重、顺序和操作需求。

最容易卡住的地方

作为哈希键使用后再修改参与 equals/hashCode 的字段，可能导致 contains 或 remove 找不到它。Set 不保证所有实现都按插入顺序遍历。

怎样使用后面的完整笔记

一次只读一个小节。看到代码先预测输出，再复制到独立练习工程运行，最后改一个输入验证自己的判断。讲义里有些标为 java 的代码框实际是说明文字或故意出错的反例，不要把整篇直接粘进一个源文件。先读完示例上下文，再决定要复制哪些类和方法。

用一个类比理解

Set像按规则去重的签到册，规则来自equals/hashCode。边界：长得一样、打印一样，不代表对象的相等规则已经实现。

下面是本站为理解本章补充的可运行示例，不冒充老师原代码。保存为 Lesson19.java，使用 JDK 17 或以上执行 javac -encoding UTF-8 Lesson19.java，再执行 java Lesson19。

public class Lesson19 {
    public static void main(String[] args) {
        var set=new java.util.LinkedHashSet<String>();
        set.add("Java");set.add("SQL");set.add("Java");
        System.out.println(set); // 保留第一次出现顺序
    }
}
