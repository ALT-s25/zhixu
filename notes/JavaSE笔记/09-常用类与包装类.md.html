## 二、Object 类

所有类的父类，常见方法：

### 2.1 toString()

```java
// 默认返回 类名@哈希码
System.out.println(obj.toString());   // com.kuangshen.Student@1540e19d

// 重写后
@Override
public String toString() {
    return "Student{name=" + name + ", age=" + age + "}";
}
```

### 2.2 equals()

```java
// 默认 == 比较（地址）
// 必须重写才能比较内容
@Override
public boolean equals(Object o) {
    if (this == o) return true;
    if (o == null || getClass() != o.getClass()) return false;
    Student s = (Student) o;
    return age == s.age && Objects.equals(name, s.name);
}
```

### 2.3 hashCode()

```java
// 重写 equals 必须重写 hashCode
// 原因：HashMap 等集合依赖 hashCode
@Override
public int hashCode() {
    return Objects.hash(name, age);
}
```

> 💡 **黄金法则**：
> - equals 相等 → hashCode 必须相等
> - hashCode 相等 → equals 不一定相等（哈希冲突）

## 三、String 类 ⭐⭐⭐

### 3.1 String 的本质

```java
public final class String
    implements java.io.Serializable, Comparable<String>, CharSequence {
    private final char value[];    // 内部是 final 字符数组
}
```

> 💡 **关键**：`final class` + `final char[]` → **String 不可变**！

### 3.2 String 不可变性（面试必问）

```java
String s = "hello";
s = s + " world";   // 不是修改 s，而是创建新对象 "hello world"
System.out.println(s);   // hello world
```

**内存示意**：
```
s 引用变化过程：
s ──→ "hello"     // 旧对象（失去引用，会被 GC）
s ──→ "hello world" // 新对象
```

**为什���设计成不可变？**
1. **安全性**：作为 HashMap key、数据库连接参数等，值不能变
2. **哈希缓存**：hashCode 可以缓存，不需要每次��算
3. **线程安全**：多线程共享安全，无需同步
4. **字符串常量池**：相同字符串可共享（节省内存）

### 3.3 字符串常量池 ⭐⭐

```java
String s1 = "hello";     // 走常量池
String s2 = "hello";     // 复用常量池的 "hello"
String s3 = new String("hello");   // new 强制新建对象

System.out.println(s1 == s2);   // true（同一对象）
System.out.println(s1 == s3);   // false（不同对象）
System.out.println(s1.equals(s3)); // true（内容相同）
```

> 💡 **intern()** 方法：将字符串放入常量池
```java
String s3 = new String("hello").intern();
System.out.println(s1 == s3);   // true
```

### 3.4 String 常用方法 ⭐⭐

| 方法 | 作用 | 示例 |
|------|------|------|
| `length()` | 长度 | `"abc".length()` → 3 |
| `charAt(int)` | 取字符 | `"abc".charAt(1)` → 'b' |
| `indexOf(String)` | 子串位置 | `"hello".indexOf("ll")` → 2 |
| `substring(int, int)` | 截取 | `"hello".substring(1, 3)` → "el" |
| `split(String)` | 拆分 | `"a,b,c".split(",")` → `["a","b","c"]` |
| `trim()` | 去两端空格 | `" hi ".trim()` → "hi" |
| `toLowerCase()` / `toUpperCase()` | 大小写转换 | |
| `replace(old, new)` | 替换 | `"hi".replace("h","H")` → "Hi" |
| `startsWith()` / `endsWith()` | 前缀/后缀判断 | |
| `contains(String)` | 是否包含 | |
| `compareTo(String)` | 字典序比较 | |
| `equalsIgnoreCase()` | 忽略大小写比较 | |
| `isEmpty()` | 是否为空 | `""` → true |
| `join(...)` | 拼接 | `String.join(",", "a","b")` → "a,b" |

### 3.5 String vs StringBuilder vs StringBuffer ⭐⭐⭐

| 维度 | String | StringBuilder | StringBuffer |
|------|--------|---------------|--------------|
| 可变性 | ❌ 不可变 | ✅ 可变 | ✅ 可变 |
| 线程安全 | ✅（因不可变） | ❌ 不安全 | ✅ synchronized |
| 性能 | 拼接时差 | 最高 | 中等 |
| 使用场景 | 少量拼接 | 单线程大量拼接 | 多线程大量拼接 |

```java
// ❌ String 拼接（创建大量临时对象）
String s = "";
for (int i = 0; i < 1000; i++) {
    s += i;    // 每次循环创建新 String
}

// ✅ StringBuilder 拼接（推荐）
StringBuilder sb = new StringBuilder();
for (int i = 0; i < 1000; i++) {
    sb.append(i);
}
String s = sb.toString();

// ✅ Java 8+：StringJoiner
StringJoiner sj = new StringJoiner(",");
for (int i = 0; i < 1000; i++) sj.add(String.valueOf(i));
String s = sj.toString();
```

## 五、包装类 ⭐⭐⭐

### 5.1 8 种基本类型对应的包装类

| 基本类型 | 包装类 |
|---------|--------|
| byte | Byte |
| short | Short |
| **int** | **Integer** |
| long | Long |
| float | Float |
| double | Double |
| char | Character |
| boolean | Boolean |

### 5.2 装箱与拆箱（自动）

```java
// 装箱：基本类型 → 包装类
Integer i = 10;         // 自动装箱
Integer j = Integer.valueOf(10);  // 手动装箱

// 拆箱：包装类 → 基本类型
int n = i;              // 自动拆箱
int m = i.intValue();   // 手动拆箱
```

### 5.3 自动装箱的坑 ⭐⭐

```java
Integer a = 127;
Integer b = 127;
System.out.println(a == b);   // true（缓存池）

Integer c = 128;
Integer d = 128;
System.out.println(c == d);   // false（超出缓存池）
```

> 💡 **缓存池**：Integer 默认缓存 **-128 ~ 127** 的值（可通过 JVM 参数调整）
> 包装类比较必须用 `.equals()`！

### 5.4 包装类常用方法

```java
// 字符串转数字
int n = Integer.parseInt("123");
double d = Double.parseDouble("3.14");
boolean b = Boolean.parseBoolean("true");

// 数字转字符串
String s = Integer.toString(123);   // "123"
String s2 = String.valueOf(123);     // "123"

// 最大值、最小值
int max = Integer.MAX_VALUE;
int min = Integer.MIN_VALUE;
```

### 5.5 int vs Integer ⭐⭐⭐

| 维度 | int | Integer |
|------|-----|---------|
| 类型 | 基本类型 | 引用类型 |
| 默认值 | 0 | null |
| 内存 | 4 字节 | 对象（更大） |
| 比较 | == | equals |
| 集合 | 不能放 | 可以放 |
| null | 不行 | 可以 |

```java
List<Integer> list = new ArrayList<>();    // 集合只能存对象
list.add(1);    // 自动装箱为 Integer
```

## 六、面试常问 ⭐⭐⭐

> 💡 **String 为什么是不可变的？**
> 1. 类被 `final` 修饰，不能被继承
> 2. 内部 `char[]` 被 `final` 修饰，不能修改
> 3. 没有提供修改内部数组的方法
>
> 设计原因：安全性（HashMap key）、线程安全、哈希缓存、字符串常量池。

> 💡 **String、StringBuilder、StringBuffer 区别？**
> | 类型 | 可变 | 线程 | 性能 |
> |------|------|------|------|
> | String | ❌ | ✅ | 拼接差 |
> | StringBuilder | ✅ | ❌ | 最快 |
> | StringBuffer | ✅ | ✅ | 较慢 |

> 💡 **`==` 和 `equals` 的区别？**
> - `==` 对基本类型比较值，对引用类型比较地址
> - `equals` 默认 ==，但 String、Integer 等类重写后比较内容
> - **包装类比较必须用 equals**

> 💡 **自动装箱和拆箱？**
> - 装箱：基本类型 → 包装类（编译器自动调用 `valueOf`）
> - 拆箱：包装类 → 基本类型（编译器自动调用 `intValue` 等）

> 💡 **Integer 缓存池范围？**
> -128 ~ 127，默认缓存，可通过 `-XX:AutoBoxCacheMax` 调整。
