三、List 接口 ⭐⭐⭐

3.1 List 特点

  • 有序：元素按插入顺序排列
  • 可重复：相同元素可多次出现
  • 可按下标访问

3.2 ArrayList ⭐⭐⭐（重点）

底层：动态数组，初始容量 10，扩容 1.5 倍。

java
List<String> list = new ArrayList<>();

// 增删改查
list.add("A");              // 末尾添加
list.add(1, "B");           // 指定位置插入
list.remove("A");           // 按值删除
list.remove(0);             // 按下标删除
list.set(0, "C");           // 替换
list.get(0);                // 按下标获取
list.contains("A");         // 是否包含
list.indexOf("A");          // 第一次出现的位置
list.size();                // 大小
list.isEmpty();             // 是否为空
list.clear();               // 清空
list.toArray();             // 转数组

ArrayList 扩容机制：

java
// 简化伪代码
int oldCapacity = elementData.length;
int newCapacity = oldCapacity + (oldCapacity >> 1);   // 1.5 倍
elementData = Arrays.copyOf(elementData, newCapacity);

3.3 LinkedList ⭐⭐

底层：双���链表。

java
LinkedList<String> list = new LinkedList<>();

list.addFirst("A");          // 头插
list.addLast("B");           // 尾插
list.getFirst();
list.getLast();
list.removeFirst();
list.removeLast();

// 实现栈
list.push("A");             // 头插
list.pop();                  // 头删

// 实现队列
list.offer("A");             // 尾插
list.poll();                  // 头删

3.4 ArrayList vs LinkedList ⭐⭐⭐

维度 ArrayList LinkedList
底层 数组 双向链表
随机访问 O(1) ✅ O(n) ❌
头部插入/删除 O(n) ❌ O(1) ✅
内存占用 较少 较多（每个节点多 2 个引用）
适用场景 读多写少 增删频繁

四、Set 接口 ⭐⭐⭐

4.1 Set 特点

  • 无序（不保证插入顺序）
  • 不可重复（通过 equals 和 hashCode 判定）

4.2 HashSet ⭐⭐⭐（重点）

底层：HashMap（值都是同一个占位对象）。

java
Set<String> set = new HashSet<>();

set.add("A");
set.add("B");
set.add("A");   // 不会重复添加
set.size();      // 2

// 遍历
for (String s : set) {
    System.out.println(s);
}

去重原理 ⭐⭐⭐：

  • 添加元素时，先算 hashCode 定位桶
  • 若桶中无元素，直接放
  • 若桶中有元素，调 equals 比较
  • 都相同则放弃添加
java
// 自定义类放进 HashSet 必须重写 equals 和 hashCode
public class Student {
    String name;
    int age;

    @Override
    public int hashCode() {
        return Objects.hash(name, age);
    }

    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Student s = (Student) o;
        return age == s.age && Objects.equals(name, s.name);
    }
}

4.3 LinkedHashSet

底层：哈希表 + 双向链表。保证插入顺序。

4.4 TreeSet ⭐

底层：红黑树。自动排序。

java
Set<Integer> set = new TreeSet<>();
set.add(5); set.add(2); set.add(8);
System.out.println(set);   // [2, 5, 8]（自动升序）

// 自定义排序：传 Comparator
Set<Student> stuSet = new TreeSet<>((a, b) -> a.age - b.age);

五、Map 接口 ⭐⭐⭐

5.1 Map 特点

  • 键值对（key-value）存储
  • 键不可重复，值可以重复
  • 一个键最多映射一个值

5.2 HashMap ⭐⭐⭐⭐（面试必问）

底层：JDK 8 之前是数组+链表，JDK 8+ 是数组 + 链表 + 红黑树。

5.2.1 基本使用

java
Map<String, Integer> map = new HashMap<>();

map.put("apple", 5);
map.put("banana", 3);
map.put("apple", 8);   // 覆盖，key 重复则 value 更新

map.get("apple");       // 8
map.getOrDefault("pear", 0);   // 不存在则默认值
map.containsKey("apple");
map.containsValue(5);
map.remove("banana");

map.size();
map.isEmpty();
map.clear();

// 遍历
// 1. 遍历 key
for (String key : map.keySet()) {
    System.out.println(key + "=" + map.get(key));
}

// 2. 遍历 entry（推荐）
for (Map.Entry<String, Integer> e : map.entrySet()) {
    System.out.println(e.getKey() + "=" + e.getValue());
}

// 3. 遍历 value
for (Integer v : map.values()) {
    System.out.println(v);
}

5.2.2 HashMap 原理（重要！）⭐⭐⭐

JDK 8 之前的结构：数组 + 链表

text
Entry[] table
   ↓
[0] → null
[1] → Entry(k1,v1) → Entry(k4,v4) → null
[2] → null
[3] → Entry(k2,v2) → null
[4] → Entry(k3,v3) → null
[15] → null

JDK 8+ 的结构：数组 + 链表 + 红黑树（链表长度 > 8 转红黑树）

text
table 数组（默认 16）
   ↓
[0]
[1] → 链表（< 8 个） → 红黑树（≥ 8 个）
[2]
...

5.2.3 put 流程（必背）⭐⭐⭐

  1. 计算 key 的 hash（(h = key.hashCode()) ^ (h >>> 16)）
  2. 根据 hash 计算数组下标 (n - 1) & hash
  3. 若桶为空，直接插入新节点
  4. 若桶不为空（链表）：
    • 遍历链表，key 相同则覆盖 value
    • 否则插入链表尾部
    • 若链表长度 > 8 且数组容量 ≥ 64，转红黑树
  5. 插入后 size > threshold（容量 × 加载因子，默认 0.75），扩容为 2 倍

5.2.4 get 流程

  1. 计算 key 的 hash
  2. 定位桶
  3. 桶中第一个节点：检查 hash 和 key
  4. 是红黑树：红黑树查找
  5. 是链表：链表遍历

5.2.5 关键参数

参数 默认 说明
初始容量 16 new HashMap()
加载因子 0.75 何时扩容
树化阈值 8 链表长度 > 8 转树
退化阈值 6 树 < 6 转回链表

💡 扩容是 rehash，性能开销大，预估容量可优化：new HashMap<>(64)

5.3 LinkedHashMap

特点：保留插入顺序。底层是哈希表 + 双向链表。

5.4 Hashtable

特点：古老，线程安全（synchronized）。不允许 null 键值。基本被淘汰。

维度 HashMap Hashtable ConcurrentHashMap
线程 ❌ 不安全 ✅ 全表锁 ✅ 分段锁/CAS
null ✅ 允许 ❌ 禁止 ❌ 禁止
性能 高 低 高
推荐 单线程 ❌ �� 多线程

5.5 TreeMap ⭐

底层：红黑树，键自动排序。

java
Map<String, Integer> map = new TreeMap<>((a, b) -> b.compareTo(a));   // 降序

六、Iterator 迭代器 ⭐

6.1 为什么需要迭代器

统一遍历集合的方式。

java
List<String> list = Arrays.asList("A", "B", "C");

Iterator<String> it = list.iterator();
while (it.hasNext()) {
    String s = it.next();
    System.out.println(s);
    if ("B".equals(s)) it.remove();   // 迭代器删除（安全）
}

// 增强 for 底层就是迭代器
for (String s : list) {
    System.out.println(s);
}

6.2 ListIterator ⭐

支持双向遍历 + 修改：

java
ListIterator<String> it = list.listIterator();
while (it.hasNext()) {          // 正向
    String s = it.next();
}
while (it.hasPrevious()) {      // 反向
    String s = it.previous();
}
it.set("D");    // 替换刚遍历的元素

java
List<Integer> list = new ArrayList<>(Arrays.asList(3, 1, 4, 1, 5));

// 排序
Collections.sort(list);                              // 升序

九、面试常问 ⭐⭐⭐

💡 ArrayList 和 LinkedList 区别？

  • ArrayList：数组，随机访问 O(1)，增删 O(n)
  • LinkedList：链表，随机访问 O(n)，增删 O(1)

💡 HashMap 的 put 流程？

  1. 算 hash → 定位桶
  2. 桶空：直接插入
  3. 桶不空：遍历链表，key 相同覆盖，否则追加到尾部
  4. 链表 > 8 转红黑树
  5. size > threshold 扩容 2 倍

💡 HashMap 扩容机制？ 默认容量 16、加载因子 0.75。扩容时容量翻倍，重新 rehash。

💡 为什么链表长度 > 8 转红黑树？ 链表查找 O(n)，红黑树 O(log n)。阈值 8 是时间和空间的平衡点。

💡 HashMap 为什么用红黑树而不是 AVL？ 红黑树近似平衡，插入删除更快，适合频繁修改的场景。

💡 HashMap 的 key 要满足什么条件？

  • 不可变（否则 put 后修改 hashCode 会丢失）
  • 正确重写 equals 和 hashCode
  • String、Integer 是好 key

💡 HashMap 和 Hashtable 区别？ | HashMap | Hashtable | |---------|-----------| | 线程不安全 | 线程安全 | | null 允许 | null 禁止 | | 性能好 | 性能差 |

💡 ConcurrentHashMap 1.7 vs 1.8？

  • 1.7：分段锁（Segment）
  • 1.8：CAS + synchronized（锁粒度更小）

十、本章小结

✅ 已掌握：

  • 集合框架整体结构（Collection / Map）
  • ArrayList / LinkedList 的使用和区别

  • HashMap 扩容机制、加载因子、树化阈值

  • Collections 工具类

✅ 易错点：

  • HashMap 允许 null 键值，Hashtable 不允许
