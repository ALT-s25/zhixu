二、File 类 ⭐

2.1 File 表示

File 类可以表示文件或目录（不实际存储数据）。

java
import java.io.File;

File f = new File("D:\\test.txt");
File dir = new File("D:\\myDir");

2.2 File 常用方法

java
// 判断
f.exists();       // 文件/目录是否存在
f.isFile();       // 是否是文件
f.isDirectory();  // 是否是目录
f.canRead();      // 可读
f.canWrite();     // 可写
f.canExecute();   // 可执行
f.isHidden();      // 隐藏

// 获取信息
f.getName();       // 文件名
f.getPath();       // 路径
f.getAbsolutePath();   // 绝对路径
f.length();        // 文件大小（字节）
f.lastModified();  // 最后修改时间

// 创建/删除
f.createNewFile(); // 创建文件
dir.mkdir();        // 创建单层目录
dir.mkdirs();      // 创建多层目录
f.delete();        // 删除文件或空目录

// 列出内容
String[] list = dir.list();                    // 文件名数组
File[] files = dir.listFiles();                // File 数组

2.3 递归遍历目录 ⭐

java
public static void listFiles(File dir, int level) {
    if (!dir.isDirectory()) return;
    File[] files = dir.listFiles();
    if (files == null) return;
    for (File f : files) {
        System.out.println("  ".repeat(level) + f.getName());
        if (f.isDirectory()) {
            listFiles(f, level + 1);    // 递���
        }
    }
}

三、IO 流分类 ⭐⭐⭐

3.1 按流向

类型 流
输入流 InputStream / Reader
输出流 OutputStream / Writer

3.2 按数据单位

类型 字节流 字符流
顶层抽象类 InputStream / OutputStream Reader / Writer
适合处理 图片、视频、二进制 文本文件

3.3 按功能

类型 作用
节点流 直接操作数据源
处理流（包装流） 包装节点流，提供额外功能（缓冲、转换）

四、字节流 ⭐⭐

4.1 FileInputStream（读字节）

java
public void readFile(String path) throws IOException {
    try (FileInputStream fis = new FileInputStream(path)) {
        int b;
        while ((b = fis.read()) != -1) {     // 一次读一个字节，返回 int
            System.out.print((char) b);
        }
    }
}

4.2 FileOutputStream（写字节）

java
public void writeFile(String path, String content) throws IOException {
    try (FileOutputStream fos = new FileOutputStream(path, true)) {  // true 表示追加
        fos.write(content.getBytes(StandardCharsets.UTF_8));
    }
}

4.3 经典案例：文件复制 ⭐⭐

java
public void copyFile(String src, String dst) throws IOException {
    try (FileInputStream fis = new FileInputStream(src);
         FileOutputStream fos = new FileOutputStream(dst)) {
        byte[] buf = new byte[1024];   // 缓冲区
        int len;
        while ((len = fis.read(buf)) != -1) {
            fos.write(buf, 0, len);    // 写入实际读取的长度
        }
    }
}

五、缓冲字节流 ⭐⭐

作用：默认 8KB 缓冲区，减少磁盘 IO 次数，性能大幅提升。

java
public void bufferedCopy(String src, String dst) throws IOException {
    try (BufferedInputStream bis = new BufferedInputStream(new FileInputStream(src));
         BufferedOutputStream bos = new BufferedOutputStream(new FileOutputStream(dst))) {
        byte[] buf = new byte[1024];
        int len;
        while ((len = bis.read(buf)) != -1) {
            bos.write(buf, 0, len);
        }
    }
}

💡 buffered 包装后：fis.read 会预读满缓冲区；bos.write 先写缓冲区，缓冲区满才真正写磁盘。

    }

6.2 缓冲字符流 ⭐⭐

java
try (BufferedReader br = new BufferedReader(new FileReader(path))) {
    String line;
    while ((line = br.readLine()) != null) {   // 一次读一行
        System.out.println(line);
    }
}

try (BufferedWriter bw = new BufferedWriter(new FileWriter(path))) {
    bw.write("Hello");
    bw.newLine();   // 平台无关的换行符
}

七、转换流 ⭐

7.1 字节流 ↔ 字符流

java
// InputStreamReader：将字节流转为字符流（指定编码）
try (BufferedReader br = new BufferedReader(
        new InputStreamReader(new FileInputStream(path), "UTF-8"))) {
    String line;
    while ((line = br.readLine()) != null) {
        System.out.println(line);
    }
}

// OutputStreamWriter：将字符流转为字节流
try (BufferedWriter bw = new BufferedWriter(
        new OutputStreamWriter(new FileOutputStream(path), "UTF-8"))) {
    bw.write("Hello, UTF-8!");
}

⚠ 常见坑：读写文件一定要显式指定编码（UTF-8），否则可能乱码。

八、对象流 ⭐⭐（序列化���

8.1 序列化与反序列化

  • 序列化：对象 → 字节流（保存到文件或网络传输）
  • 反序列化：字节流 → 对象

8.2 Serializable 接口

java
public class Student implements Serializable {
    private static final long serialVersionUID = 1L;   // 序列化版本号（强烈建议）
    private String name;
    private int age;
    // transient 修饰的字段不参与序列化
    private transient String password;
}

8.3 序列化与反序列化示例

java
// 序列化
try (ObjectOutputStream oos = new ObjectOutputStream(
        new FileOutputStream("student.bin"))) {
    Student s = new Student("张三", 18);
    oos.writeObject(s);
}

// 反序列化
try (ObjectInputStream ois = new ObjectInputStream(
        new FileInputStream("student.bin"))) {
    Student s = (Student) ois.readObject();
    System.out.println(s.getName());
}

8.4 关键点

  • 必须实现 Serializable 接口（标记接口，无方法）
  • serialVersionUID 用于版本兼容性
  • transient 字段不参与序列化
  • static 字段也不参与
  • 不想序列化的字段：用 transient

十、Properties ⭐

读取 .properties 配置文件：

java
// config.properties
// name=张三
// age=18

Properties props = new Properties();
try (InputStream is = new FileInputStream("config.properties")) {
    props.load(is);   // 加载
    System.out.println(props.getProperty("name"));
    System.out.println(props.getProperty("age", "default"));

    props.setProperty("gender", "male");
    // 保存回文件
    props.store(new FileOutputStream("config.properties"), null);
}

十一、面试常问 ⭐⭐

💡 字节流和字符流的区别？

  • 字节流按字节读取（InputStream/OutputStream），处理所有文件
  • 字符流按字符读取（Reader/Writer），处理文本文件
  • 字节流 + 编码 = 字符流

💡 BIO、NIO、AIO 的区别？

  • BIO（Block IO）：同步阻塞
  • NIO（Non-block IO）：同步非阻塞
  • AIO（Asynchronous IO）：异步非阻塞

💡 什么是序列化？为什么需要序列化？ 把 Java 对象转为字节序列，便于存储或网络传输。

💡 transient 关键字？ 不参与序列化的字段。

💡 Closeable 和 AutoCloseable？

  • Closeable：实现 close()，需要手动关闭
  • AutoCloseable：可在 try-with-resources 中自动关闭
