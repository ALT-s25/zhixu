二、注解（Annotation）⭐

2.1 什么是注解

注解是放在源码上的元数据，可以被编译器、工具、框架读取并使用。

java
@Override      // 编译器检查
@Deprecated    // 标记过时
@SuppressWarnings("unchecked")   // 抑制警告

2.2 内置注解

注解 作用
@Override 检查方法重写
@Deprecated 标记已过时
@SuppressWarnings 抑制警告
@FunctionalInterface 函数式接口（Lambda）
@SafeVarargs 抑制可变参数警告

2.3 元注解（修饰注解的注解）

元注解 作用
@Target 注解能用在哪些位置
@Retention 注解的生命周期
@Documented 是否包含在 Javadoc
@Inherited 子类能否继承父类的注解
java
@Target({
    ElementType.METHOD,        // 方法
    ElementType.FIELD,         // 字段
    ElementType.TYPE            // 类/接口
})
@Retention(RetentionPolicy.RUNTIME)   // 运行时保留（可被反射读取）
public @interface MyAnnotation {
    String value() default "";       // 注解参数
    int num() default 0;
}

2.4 自定义注解 ⭐

java
// 定义
@Target(ElementType.METHOD)
@Retention(RetentionPolicy.RUNTIME)
public @interface MyTest {
    String value() default "test";  // 有默认值的参数
    int timeout() default 1000;
}

// 使用
public class MyTestDemo {
    @MyTest(value = "method1", timeout = 2000)
    public void testMethod1() { }

    @MyTest("method2")      // value 是特殊参数，可省略名
    public void testMethod2() { }
}

三、反射（Reflection）⭐⭐⭐

3.1 什么是反���

运行时动态获取类的信息、调用方法、操作属性的机制。

关键："动态" —— 编译时不知道用哪个类，运行时才确定。

3.2 反射的应用场景

  • Spring 依赖注入（@Autowired）
  • MyBatis ORM 映射（@Select 注解）
  • JUnit 测试（@Test）
  • Jackson JSON 序列化
  • 动态代理

3.3 Class 对象 ⭐⭐⭐

每个类在 JVM 中只有一个 Class 对象，存放类的元数据。

java
// 3 种获取 Class 对象的方式
Class<?> c1 = Student.class;            // 1. 类名.class
Class<?> c2 = studentObj.getClass();    // 2. 对象.getClass()
Class<?> c3 = Class.forName("com.kuangshen.Student");   // 3. Class.forName（最常用）

System.out.println(c1 == c2);   // true（同一个 Class 对象）

3.4 反射获取类信息

java
Class<?> c = Class.forName("com.kuangshen.Student");

// 类名
c.getName();        // 全限定名 com.kuangshen.Student
c.getSimpleName();  // 类名 Student

// 构造器
Constructor<?>[] constructors = c.getDeclaredConstructors();
Constructor<?> constructor = c.getDeclaredConstructor(String.class, int.class);

// 字段
Field[] fields = c.getDeclaredFields();
Field nameField = c.getDeclaredField("name");

// 方法
Method[] methods = c.getDeclaredMethods();
Method sayHello = c.getDeclaredMethod("sayHello", String.class);

// 注解
Annotation[] annotations = c.getAnnotations();

3.5 创建对象 ⭐⭐

java
// 方式 1：调用无参构造器（必须有无参构造器）
Student s = (Student) c.newInstance();   // 已废弃（Java 9+）

// 方式 2：通过有参构造器
Constructor<?> constructor = c.getConstructor(String.class, int.class);
Student s = (Student) constructor.newInstance("张三", 18);

// 方式 3（Java 9+ 推荐）
Student s = (Student) c.getDeclaredConstructor(String.class, int.class)
    .newInstance("张三", 18);

3.6 调用方法 ⭐⭐

java
Student s = new Student("张三", 18);
Method sayHello = s.getClass().getDeclaredMethod("sayHello", String.class);

// 关键：invoke
Object result = sayHello.invoke(s, "World");
System.out.println(result);

3.7 操作字段（含 private）⭐⭐

java
Field nameField = s.getClass().getDeclaredField("name");

// 关键：setAccessible(true) 关闭安全检查
nameField.setAccessible(true);

nameField.set(s, "李四");   // 修改私有字段
Object value = nameField.get(s);  // 读取私有字段

⚠ setAccessible(true) 是反���最��用的"突破"手段。

3.8 完整示例 ⭐⭐⭐

java
public class ReflectionDemo {
    public static void main(String[] args) throws Exception {
        // 1. 通过反射创建对象
        Class<?> c = Class.forName("com.kuangshen.Student");
        Student s = (Student) c.getDeclaredConstructor(String.class, int.class)
            .newInstance("张三", 18);

        // 2. 调用方法
        Method m = c.getDeclaredMethod("sayHello", String.class);
        m.invoke(s, "World");

        // 3. 读取/修改私有字段
        Field nameField = c.getDeclaredField("name");
        nameField.setAccessible(true);
        nameField.set(s, "李四");

        System.out.println("修改后：" + nameField.get(s));
    }
}

四、反射的优缺点 ⭐

4.1 优点

  • 动态：运行时确定类、方法
  • 灵活：框架必备

4.2 缺点

  • 性能差：反射调用比直接调用慢
  • 安全风险：可访问 private，破坏封装
  • 可读性差

💡 优化：setAccessible(true) 可大幅提升性能（关闭安全检查）。

五、动态代理（了解）⭐⭐

动态代理是反射的典型应用（Spring AOP 核心）。

5.1 静态代理 vs 动态代理

维度 静态代理 动态代理
代理类 手动编写 运行时生成
灵活性 低 高

5.2 JDK 动态代理

java
// 接口
interface UserService {
    void add();
}

// 真实对象
class UserServiceImpl implements UserService {
    @Override
    public void add() {
        System.out.println("添加用户");
    }
}

// 代理处理器
class MyHandler implements InvocationHandler {
    private Object target;

    public MyHandler(Object target) {
        this.target = target;
    }

    @Override
    public Object invoke(Object proxy, Method method, Object[] args) throws Throwable {
        System.out.println("前置增强");
        Object result = method.invoke(target, args);
        System.out.println("后置增强");
        return result;
    }
}

// 使用
UserService target = new UserServiceImpl();
UserService proxy = (UserService) Proxy.newProxyInstance(
    target.getClass().getClassLoader(),
    target.getClass().getInterfaces(),
    new MyHandler(target)
);
proxy.add();
// 输出：
// 前置增强
// 添加用户
// 后置增强

七、面试常问 ⭐⭐⭐

💡 什么是反射？ 运行时动态获取类的信息、调用方法、操作属性的机制。

💡 获取 Class 对象的三种方式？

  1. 类名.class
  2. 对象.getClass()
  3. Class.forName("全限定类名")

💡 setAccessible(true) 的作用？ 关闭私有访问检查，可访问 private 字段/方法。

💡 注解的 @Retention 三种策略？

  • SOURCE：源码期，编译后丢弃
  • CLASS：字节码期，默认
  • RUNTIME：运行时，可被反射读取

💡 注解的作用？

  • 编译检查（@Override）
  • 编译时生成代码（Lombok）
  • 运行时被框架读取（Spring、MyBatis）

💡 反射的应用？ Spring IoC、AOP、ORM、测试框架、序列化

💡 Class.forName() 和 ClassLoader.loadClass() 区别？

  • forName：会初始化类（执行 static 代码块）
  • loadClass：只加载，不初始化
