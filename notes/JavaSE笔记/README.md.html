## 🎯 二刷者重点（哪些是必看、哪些可以快过）

### 🔴 必看、必须深入理解

| 模块 | 为什么重要 |
|------|-----------|
| 面向对象基础（5） | 整个 Java 的核心，类/对象没搞懂后面全崩 |
| 封装继承多态（6） | OOP 三大特性，面试必问 |
| 抽象类接口（7） | 实际项目天天用 |
| 集合框架（10） | 工作 80% 时间在用 ArrayList、HashMap |
| 多线程（12） | 面试高频 |

### 🟡 重要、但可快过

| 模块 | 学习策略 |
|------|----------|
| 基础语法（2、3） | 快过，重点是数据类型转换、运算符优先级 |
| 方法与数组（4） | 重点是数组内存分析、方法重载、值传递 vs 引用传递 |
| 异常（8） | 重点是异常体系、try-catch-finally、自定义异常 |
| 常用类（9） | 重点是 String 不可变性、StringBuilder/StringBuffer 区别 |
| IO 流（11） | 重点是字节流 vs 字符流、缓冲流提升性能 |

### 🟢 了解、看过即可

| 模块 | 学习策略 |
|------|----------|
| Java 入门（1） | 安装配置而已 |
| 网络编程（13） | 简单了解 Socket 即可，工作用框架 |
| 注解与反射（14） | 框架基础，但二刷可了解即可 |

## 🧠 JavaSE 知识体系全景图

```
JavaSE
├── 基础语法层
│   ├── 数据类型、变量、常量、Scanner
│   ├── 运算符、表达式
│   ├── 流程控制（if/switch/循环）
│   └── 数组、方法
├── 面向对象层 ⭐核心
│   ├── 类与对象、构造器
│   ├── 封装（private + getter/setter）
│   ├── 继承（extends、super、方法重写）
│   ├── 多态（向上转型、instanceof）
│   ├── 抽象类（abstract）
│   ├── 接口（interface）
│   └── 内部类（成��/静态/局部/匿名）
├── 进阶特性层
│   ├── 异常体系（try-catch-throws-throw）
│   ├── 常用类（Object、String、Math、Date）
│   ├── 包装类（装箱、拆箱）
│   └── 枚举（enum）
├── 集合框架层 ⭐核心
│   ├── Collection（List/Set）
│   ├── Map
│   ├── 泛型
│   └── Collections 工具类
├── IO 层
│   ├── File 类
│   ├── 字节流（InputStream/OutputStream）
│   ├── 字符流（Reader/Writer）
│   └── 缓冲流、对象流
├── 并发层 ⭐核心
│   ├── Thread、Runnable
│   ├── 线程同步（synchronized）
│   └── 锁、volatile
└── 应用层
    ├── 网络编程（Socket）
    ├── 注解（Annotation）
    └── 反射（Reflection）
```

## 💡 二刷常见问题（提前避坑）

1. **"学了就忘"** → 笔记结构化 + 关键代码敲 3 遍
2. **"面向对象学了但不会用"** → 必须自己手写小项目练
3. **"集合/IO 类太多记不住"** → 记住"父接口 + 子类特点"框架，具体类用时查
4. **"多线程难理解"** → 先理解进程/线程概念，再画图理解执行流
5. **"注解反射有啥用"** → 了解 Spring/ORM 框架底层用就行

## 🎯 学完 JavaSE 的检验标准

- [ ] 能手写 ArrayList、LinkedList 的核心方法
- [ ] 能解释 HashMap 的 put 流程（扩容、链表转红黑树）
- [ ] 能手写生产者-消费者模型（wait/notify）
- [ ] 能用反射获取类的所有信息
- [ ] 看到 `equals`、`hashCode`、`toString` 能立刻说出何时重写
- [ ] 能口述 String 为什么不可变、StringBuilder/StringBuffer 区别
- [ ] 能解释 synchronized 锁的是什么（对象锁 vs 类锁）

完成这些 → JavaSE 过关！
