🚀 二刷复习路线（4 周）

第一周：基础 + OOP

  • Day 1-2：环境 + 基础语法 + 流程控制（快速过）
  • Day 3-4：方法 + 数组（重点看内存分析）
  • Day 5-7：面向对象（5、6、7 三章）— 重中之重

第二周：进阶 + 集合

  • Day 8-9：异常 + 常用类 + 包装类
  • Day 10-12：集合框架（核心章节，建议多敲代码）
  • Day 13-14：泛型深入���Collections 工具类

第三周：IO + 多线程

  • Day 15-16：IO 流（文件复制练习）
  • Day 17-19：多线程（理解并发本质）
  • Day 20-21：网络编程 + 注解与反射（了解即可）

第四周：综合实战

  • Day 22-23：选 2-3 个小项目练手
    • 简易文件管理器（集合 + IO）
    • 多线程下载器（IO + 多线程）
  • Day 24-25：回顾所有笔记中的"常见坑"和"面试常问"
  • Day 26-28：模拟面试、写总结

💡 二刷常见问题（提前避坑）

  1. "学了就忘" → 笔记结构化 + 关键代码敲 3 遍
  2. "面向对象学了但不会用" → 必须自己手写小项目练
  3. "集合/IO 类太多记不住" → 记住"父接口 + 子类特点"框架，具体类用时查
  4. "多线程难理解" → 先理解进程/线程概念，再画图理解执行流
  5. "注解反射有啥用" → 了解 Spring/ORM 框架底层用就行

🎯 学完 JavaSE 的检验标准

  • 能手写 ArrayList、LinkedList 的核心方法
  • 能解释 HashMap 的 put 流程（扩容、链表转红黑树）
  • 能手写生产者-消费者模型（wait/notify）
  • 能用反射获取类的所有信息
  • 看到 equals、hashCode、toString 能立刻说出何时重写
  • 能口述 String 为什么不可变、StringBuilder/StringBuffer 区别
  • 能解释 synchronized 锁的是什么（对象锁 vs 类锁）

完成这些 → JavaSE 过关！
