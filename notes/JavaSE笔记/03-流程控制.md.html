## 三、选择结构

### 3.1 if 语句

```java
// 单分支
if (条件) {
    // 条件为 true 时执行
}

// 双分支
if (条件) {
    // true
} else {
    // false
}

// 多分支
if (条件1) {
    // ...
} else if (条件2) {
    // ...
} else {
    // 都不满足
}
```

### 3.2 switch 多分支 ⭐⭐

```java
switch (表达式) {
    case 值1:
        // ...
        break;          // 必须 break，否则穿透
    case 值2:
        // ...
        break;
    default:
        // 都不匹配时执行
}
```

### 3.3 switch 新特性（Java 14+）

```java
// 箭头语法（不再需要 break）
int day = 3;
String result = switch (day) {
    case 1, 2, 3, 4, 5 -> "工作日";
    case 6, 7 -> "周末";
    default -> "非法";
};
```

### 3.4 switch 表达式支持的数据类型

- `byte`, `short`, `int`, `char`, **`String`**, **枚举**
- 不支持 `long`, `float`, `double`, `boolean`

> ⚠ **常见坑**：
> 1. **case 穿透** —— 每个 case 末尾如果不写 break，会继续执行下一个 case
> 2. **default 不是必须的** —— 但建议加上，处理非法输入
> 3. **case 标签**必须是常量，不能是变量

```java
// 故意利用穿透的写法
int month = 4;
int season = switch (month) {
    case 3, 4, 5 -> 2;       // 春
    case 6, 7, 8 -> 3;       // 夏
    case 9, 10, 11 -> 4;     // 秋
    case 12, 1, 2 -> 1;      // 冬
    default -> 0;            // 非法
};
```

## 四、循环结构

### 4.1 while 循环

```java
while (条件) {
    // 循环体
}
```

**特点**：先判断后执行，**条件不满足则一次都不执行**。

### 4.2 do-while 循环

```java
do {
    // 循环体
} while (条件);
```

**特点**：先执行后判断，**至少执行一次**。

### 4.3 for 循环 ⭐⭐

```java
for (初始化; 条件; 迭代表达式) {
    // 循环体
}
```

**执行流程**：
1. 初始化（仅一次）
2. 判断条件 → false 则退出
3. 执行循环体
4. 执行迭代表达式
5. 回到步骤 2

```java
for (int i = 0; i < 10; i++) {
    System.out.println(i);
}
```

### 4.4 增强 for 循环（for-each）⭐

```java
// 遍历数组
int[] arr = {1, 2, 3, 4, 5};
for (int num : arr) {
    System.out.println(num);
}

// 遍历集合
List<String> list = Arrays.asList("a", "b", "c");
for (String s : list) {
    System.out.println(s);
}
```

**优点**：简洁
**缺点**：不能访问下标，无法修改原数组

## 五、跳转语句 ⭐⭐

### 5.1 break

- 用于**终止当前循环**或 switch
- **不会跳过 finally**（如有）

```java
for (int i = 0; i < 10; i++) {
    if (i == 5) break;   // i=5 时跳出循环
    System.out.println(i);
}
// 输出：0 1 2 3 4
```

### 5.2 continue

- 用于**跳过本次循环**，继续下一次
- 不会终止循环

```java
for (int i = 0; i < 10; i++) {
    if (i % 2 == 0) continue;   // 跳过偶数
    System.out.println(i);
}
// 输出：1 3 5 7 9
```

### 5.3 return

- **结束整个方法**，并返回值
- 跳出多层循环可用：给外层加标签（不推荐）

## 六、循环练习 ⭐

### 6.1 累加 1~100

```java
int sum = 0;
for (int i = 1; i <= 100; i++) {
    sum += i;
}
System.out.println(sum);  // 5050
```

### 6.2 打印九九乘法表 ⭐⭐

```java
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        System.out.print(j + "*" + i + "=" + (i*j) + "\t");
    }
    System.out.println();
}
```

输出：
```
1*1=1
1*2=2	2*2=4
1*3=3	2*3=6	3*3=9
...
```

### 6.3 打印三角形

```java
for (int i = 1; i <= 5; i++) {
    for (int j = 5; j > i; j--) System.out.print(" ");
    for (int j = 1; j <= 2*i-1; j++) System.out.print("*");
    System.out.println();
}
```

输出：
```
    *
   ***
  *****
 *******
*********
```

### 6.4 break + 标签跳出多层循环

```java
outer:
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 3; j++) {
        if (i == 1 && j == 1) break outer;   // 直接跳出外层
        System.out.println(i + "," + j);
    }
}
```

## 七、面试常问

> 💡 **while 和 do-while 的区别？**
> - while 先判断后执行，可能一次都不执行
> - do-while 先执行后判断，至少执行一次

> 💡 **break 和 continue 的区别？**
> - break 终止整个循环
> - continue 跳过本次循环，继续下一次

> 💡 **for 和 while 的选择？**
> - 循环次数已知 → for
> - 循环次数未知 → while
