## 二、核心概念

### 2.1 Java 三大版本

| 版本 | 全称 | 用途 |
|------|------|------|
| **Java SE** | Standard Edition | 桌面级应用、标准库（我们要学的） |
| Java EE | Enterprise Edition | 企业级（现在叫 Jakarta EE） |
| Java ME | Micro Edition | 嵌入式（已淘汰） |

### 2.2 JDK / JRE / JVM 三者关系

```
JDK (Java Development Kit)        ← 开发者使用
  └── JRE (Java Runtime Environment)   ← 运行环境
        └── JVM (Java Virtual Machine)  ← 虚拟机
              └── 字节码运行（.class 文件）
```

**记忆口诀**：
- **JDK = JRE + 开发工具**（javac、javadoc、jar）
- **JRE = JVM + 核心类库**
- **JVM**：跨平台核心，一次编写到处运行（Write Once, Run Anywhere）

### 2.3 环境变量配置

| 环境变量 | 值 | 作用 |
|----------|----|----|
| `JAVA_HOME` | `D:\Java\jdk1.8` | JDK 安装路径 |
| `Path` | 加 `%JAVA_HOME%\bin` | 让 cmd 能找到 javac/java |
| `CLASSPATH` | `.` 或 `.;%JAVA_HOME%\lib` | 类搜索路径（新版 JDK 可不配） |

**验证**：
```bash
java -version
javac -version
```

## 三、第一个程序 HelloWorld

### 3.1 编写代码

新建 `HelloWorld.java`：

```java
public class HelloWorld {
    public static void main(String[] args) {
        System.out.println("Hello, World!");
    }
}
```

### 3.2 编译与运行

```bash
# 编译：生成 HelloWorld.class 字节码文件
javac HelloWorld.java

# 运行：JVM 加载并执行
java HelloWorld
# 输出：Hello, World!
```

### 3.3 注意事项

> ⚠ **常见坑**：
> 1. `public class` 的类名必须与文件名**完全一致**
> 2. `main` 方法签名**固定**：`public static void main(String[] args)`
> 3. Java 严格区分大小写
> 4. 每一行代码以分号 `;` 结尾
> 5. 大括号 `{}` 成对出现，注意缩进

## 四、Java 程序运行原理 ⭐

```
HelloWorld.java  (源代码)
       ↓ javac 编译
HelloWorld.class (字节码)
       ↓ 类加载器加载
   JVM 解释执行
       ↓
   操作系统调用硬件
```

**关键点**：
- **编译**：`.java` → `.class`（字节码，与平台无关）
- **解释**：JVM 逐行将字节码翻译成机器码执行
- **JIT（即时编译器）**：热点代码编译为本地机器码，提高性能

## 七、关键字与标识符

### 7.1 关键字

Java 预定义的有特殊含义的单词，**全部小写**：

```
class, public, static, void, int, long, double,
if, else, switch, case, default, while, for, do,
break, continue, return, true, false, null,
new, this, super, abstract, final, interface, ...
```

### 7.2 标识符命名规则

- 由字母、数字、下划线、美元符 `$` 组成
- **不能以数字开头**
- 不能是关键字
- 区分大小写

### 7.3 命名规范（约定）

| 类型 | 规范 | 例子 |
|------|------|------|
| 类名 | 大驼峰 | `HelloWorld`, `UserService` |
| 方法名、变量名 | 小驼峰 | `getName`, `userAge` |
| 常量 | 全大写 + 下划线 | `MAX_VALUE` |
| 包名 | 全小写 | `com.kuangshen.utils` |

## 八、面试常问

> 💡 **JDK、JRE、JVM 的区别？**
> - JDK 是开发工具包（包含 JRE 和编译器等开发工具）
> - JRE 是运行时环境（包含 JVM 和核心类库）
> - JVM 是虚拟机，负责执行字节码
> 关系：JDK ⊃ JRE ⊃ JVM

> 💡 **Java 为什么跨平台？**
> Java 程序编译成字节码（.class），由 JVM 解释执行。不同平台有不同的 JVM 实现，但字节码一致��所��"一次编写到处运行"。
