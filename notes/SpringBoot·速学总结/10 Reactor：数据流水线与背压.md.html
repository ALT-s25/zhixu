10 Reactor：数据流水线与背压

约 2 分钟阅读你的知识，慢慢成林

原文：第188—218页。优先级：扩展路线，先学Java Lambda与Stream。

响应式流水线像传送带，订阅者表达需求，操作符负责转换和组合。边界：不是写了Mono就自动异步，也不是所有阻塞调用包进Mono都会变成非阻塞。

Mono表示0或1个元素，Flux表示0到多个。先学just/fromIterable、map/filter，再学flatMap、错误处理和组合；flatMap可能改变顺序，顺序需求要明确。背压关注下游处理能力与上游发送节奏，不是所有源都能无限安全地减速。

java
Flux.just(1,2,3,4)
    .filter(n -> n % 2 == 0)
    .map(n -> n * n)
    .subscribe(System.out::println); // 简单演示输出4、16

WebFlux处理请求时通常返回Publisher给框架订阅，不在Controller内部随意subscribe后立即返回“完成”。错误要沿流水线处理；返回一个Publisher与任务已完成不同。

练习：用map处理普通值，用flatMap组合返回Mono的方法，并解释结果类型。验收：能说出订阅、完成、错误分别是什么信号。
