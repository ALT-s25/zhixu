04 基础特性：环境配置与测试

约 2 分钟阅读你的知识，慢慢成林

原文：第84—98页。优先级：必学；启动Banner可略读。

Profile像给同一应用切换不同工作环境的配置套装。边界：环境名本身不是安全隔离，错误激活prod仍可能访问生产资源。

先明确默认配置，再分dev/test等环境。排查“配置写了却没生效”时记录实际激活Profile、启动参数和外部配置来源；高优先级来源可能覆盖文件中的值。不要只盯着一个application.yml反复修改。

测试像可重复的验收单：输入、执行、断言。原文介绍JUnit 5、断言、嵌套与参数化测试。@SpringBootTest会加载应用上下文，普通Java算法不必为每次单元测试启动整个应用。

java
@Test
void checksMaximum() {
    assertEquals(5, Math.max(2,5));
    assertEquals(-1, Math.max(-3,-1));
}

练习：测试环境使用独立数据库，写成功、参数非法、不存在三类用例。验收：能解释失败断言，而不是仅看到控制台有输出就说“测试通过”。需要连接外部服务的测试属于集成测试，应明确依赖条件。
