二、模板基础 ⭐⭐

2.1 为什么需要模板

实现泛型，编写与类型无关的代码。

cpp
// 不使用模板：每种类型都要写一个
int max(int a, int b) { return a > b ? a : b; }
double max(double a, double b) { return a > b ? a : b; }
std::string max(std::string a, std::string b) { return a > b ? a : b; }

// 使用模板：一个搞定
template <typename T>
T max(T a, T b) { return a > b ? a : b; }

2.2 两种模板

  • 函数模板：通用函数
  • 类模板：通用类

2.3 模板分类 ⭐

  • 编译时多态（静态）：模板（本章）
  • 运行时多态（动态）：虚函数（前章）

三、函数模板 ⭐⭐

3.1 基本语法

cpp
template <typename T>      // 声明模板
T max(T a, T b) {          // T 是类型参数
    return a > b ? a : b;
}

max(3, 5);                 // 自动推导 T = int
max(3.14, 1.5);            // T = double
max<double>(3, 5.5);       // 显式指定

3.2 多个模板参数

cpp
template <typename T, typename U>
auto add(T a, U b) -> decltype(a + b) {
    return a + b;
}

add(3, 5.5);      // auto = double

3.3 非类型模板参数

cpp
template <typename T, int N>
class Array {
    T data_[N];
public:
    int size() const { return N; }
};

Array<int, 10> a;        // 10 个 int 的数组

3.4 函数模板 vs 函数重载 ⭐

cpp
// 函数模板
template <typename T>
T max(T a, T b) { return a > b ? a : b; }

// 函数重载
int max(int a, int b) { return a > b ? a : b; }
double max(double a, double b) { return a > b ? a : b; }

💡 模板更通用（一个模板适用所有类型），但重载更精确（可为特定类型定制）。

3.5 模板实例化

编译器根据调用自动生成具体类型的代码（模板实例化）。

cpp
max(3, 5);           // 实例化 max<int>(int, int)
max(3.14, 1.5);      // 实例化 max<double>(double, double)

四、类模板 ⭐⭐

4.1 基本语法

cpp
template <typename T>
class Stack {
    std::vector<T> data_;

public:
    void push(const T& x) { data_.push_back(x); }
    void pop() { data_.pop_back(); }
    const T& top() const { return data_.back(); }
    bool empty() const { return data_.empty(); }
    size_t size() const { return data_.size(); }
};

Stack<int> s;
s.push(1);
s.pop();

4.2 类模板的成员函数

cpp
template <typename T>
class MyClass {
public:
    void func();           // 类内定义（隐式 inline）

    void func2();          // 类内声明
};

// 类外定义
template <typename T>
void MyClass<T>::func2() {
    // ...
}

4.3 多模板参数类

cpp
template <typename K, typename V>
class Pair {
    K key_;
    V value_;

public:
    Pair(const K& k, const V& v) : key_(k), value_(v) {}
    K getKey() const { return key_; }
    V getValue() const { return value_; }
};

Pair<std::string, int> p("age", 18);

4.4 默认模板参数

cpp
template <typename T = int, int N = 10>
class Array {
    T data_[N];
};

Array<> a;           // 默认 T=int, N=10
Array<double> b;     // T=double, N=10

4.5 模板别名（C++11）

cpp
template <typename T>
using Vec = std::vector<T>;

Vec<int> v;          // 等价 std::vector<int>

五、模板特化 ⭐⭐

5.1 为什么需要特化

某些类型需要特殊处理（如 const char* 不能直接比较）。

cpp
template <typename T>
bool compare(const T& a, const T& b) {
    return a == b;
}

// 字符串特化
template <>
bool compare<const char*>(const char* const& a, const char* const& b) {
    return strcmp(a, b) == 0;
}

5.2 函数模板特化

cpp
template <typename T>
void print(const T& x) {
    std::cout << x;
}

template <>
void print<bool>(const bool& x) {       // bool 特化
    std::cout << (x ? "true" : "false");
}

5.3 类模板特化 ⭐

cpp
template <typename T>
class MyClass {
public:
    void print() { std::cout << "通用版本\n"; }
};

// 全特化
template <>
class MyClass<bool> {
public:
    void print() { std::cout << "bool 特化\n"; }
};

MyClass<int> a;
MyClass<bool> b;
a.print();    // 通用版本
b.print();    // bool 特化

5.4 偏特化（部分特化）⭐

cpp
// 针对指针类型的偏特化
template <typename T>
class MyClass<T*> {
    T* p_;
public:
    void print() { std::cout << "指针版本\n"; }
};

int x = 10;
MyClass<int*> p;
p.print();    // 指针版本

六、模板参数推导 ⭐

6.1 推导规则

cpp
template <typename T>
void func(T x);

int a = 10;
const int b = 20;
int& ref = a;

func(a);        // T = int
func(b);        // T = int（去 const）
func(ref);      // T = int（去引用）

6.2 显式指定模板参数

cpp
template <typename T>
T max(T a, T b);

max<double>(3, 5.5);   // 显式指定 T = double

七、可变参数模板 ⭐（了解）

C++11 引入，支持任意数量的模板参数。

cpp
// 递归终止
void print() { }

// 递归调用
template <typename T, typename... Args>
void print(T first, Args... rest) {
    std::cout << first << " ";
    print(rest...);
}

print(1, "hello", 3.14, 'a');    // 1 hello 3.14 a

八、模板元编程（了解）

用模板实现编译期计算。

cpp
// 编译期计算阶乘
template <int N>
struct Factorial {
    static const int value = N * Factorial<N-1>::value;
};

template <>
struct Factorial<0> {
    static const int value = 1;
};

constexpr int x = Factorial<5>::value;   // 120（编译期计算）

九、常见模板实例：std::pair 与 std::tuple

cpp
std::pair<std::string, int> p("age", 18);
std::cout << p.first << ": " << p.second;

std::tuple<int, double, std::string> t(1, 3.14, "hi");
std::cout << std::get<0>(t);    // 1

// C++17 结构化绑定
auto [a, b, c] = t;
std::cout << a << b << c;

十、面试常问 ⭐⭐

💡 模板的实例化发生在什么时候？ 编译时。编译器根据调用生成具体类型的代码。

💡 模板与宏的区别？ | 模板 | 宏 | |------|-----| | 有类型检查 | | 文本替换 | | 调试友好 | | 难调试 | | 编译期实例化 | | 预编译期展开 |

💡 什么是全特化、偏特化？

  • 全特化：所有模板参数都指定
  • 偏特化：部分模板参数指定（如指针、引用版本）

💡 函数模板 vs 类模板？

  • 函数模���：参数自动推导
  • 类模板：必须显式指定（除非有默认值）

💡 typename 和 class 区别？ 在模板中完全等价，都是声明类型参数。推荐 typename（语义更清晰）。
