2.1 基本数据类型

类型 关键字 大小（32/64位） 取值范围
布尔 bool 1 字节 true / false
字符 char 1 字节 -128 ~ 127

💡 用 sizeof 查大小：

cpp

2.2 字面值常量 ⭐

cpp
// 整型
int a = 100;          // 十进制
int b = 0144;         // 八进制（0 开头）
int c = 0xFF;         // 十六进制（0x 开头）
int d = 0b1010;       // 二进制（C++14）
int e = 1'000'000;    // 分隔符（C++14，可读性）

// 浮点
double pi = 3.14;
double g = 3.14f;     // float 字面值（f/F 后缀）
double h = 3.14L;     // long double（l/L 后缀）

// 字符
char c1 = 'A';
char c2 = '\n';       // 转义
char c3 = u8'a';      // UTF-8 字符

// 布尔
bool flag = true;     // 1
bool stop = false;    // 0

// C++14：二进制字面值
int bin = 0b1010;     // 10

2.3 字符串字面值

cpp
const char* s1 = "hello";                    // C 风格字符串
std::string s2 = "hello";                    // C++ 字符串（推荐）
auto s3 = u8"hello";                          // UTF-8（C++11）
auto s4 = u"hello";                           // char16_t
auto s5 = U"hello";                           // char32_t
auto s6 = L"hello";                           // wchar_t
auto s7 = R"(hello\nworld)";                  // 原始字符串（C++11）

⚠ C 风格字符串以 \0 结尾，不能直接比较 / 拼接。

三、变量与常量

3.1 变量定义

cpp
int age = 18;
double pi = 3.14;
char ch = 'A';
std::string name = "张三";

// 列表初始化（C++11）
int a{10};

3.2 常量

cpp
// 1. C 风格宏（不推荐）
#define PI 3.14159

// 2. const 常量（推荐）
const double PI = 3.14159;
const int MAX = 100;

// 3. constexpr 常量（C++11）—— 编译期常量
constexpr double PI = 3.14159;
constexpr int SIZE = 100;

💡 constexpr vs const：

  • const：运行时不能修改（不一定编译期常量）
  • constexpr：编译期就能算出值（C++11）
  • consteval：强制编译期（C++20）

3.3 变量作用域

cpp
int x = 10;          // 全局变量

void func() {
    int y = 20;      // 局部变量
    {
        int z = 30;  // 块作用域
    }
    // z 不可访问
}

五、类型转换 ⭐⭐

5.1 隐式转换

cpp
int i = 3.14;           // double → int（截断）
double d = 5;            // int → double
char c = 65;             // int → char（'A'）

5.2 显式转换（C 风格）

cpp
int i = (int)3.14;
double d = (double)5 / 2;    // 2.5

5.3 C++ 强制类型转换（推荐���⭐���

cpp
// 1. static_cast：常规转换
int i = static_cast<int>(3.14);
double d = static_cast<double>(5) / 2;    // 2.5

// 2. const_cast：去 const
const int* p = &x;
int* q = const_cast<int*>(p);

// 3. dynamic_cast：父子类安全转换（多态中）
Derived* d = dynamic_cast<Derived*>(basePtr);

// 4. reinterpret_cast：底层重新解释（慎用）
int* p = reinterpret_cast<int*>(0x1234);

⚠ C++ 强制转换更安全、语义更清晰，推荐使用 C++ 风格而非 C 风格。

六、auto 与 decltype ⭐⭐

6.1 auto（C++11）

让编译器自动推导类型。

cpp
auto i = 42;           // int
auto d = 3.14;         // double
auto s = "hello";      // const char*
auto str = std::string("hi");  // std::string

// 配合迭代器
std::vector<int> v;
for (auto it = v.begin(); it != v.end(); ++it) { }

// 配合范围 for（C++11）
for (auto& num : v) {
    std::cout << num;
}

6.2 auto 的推导规则 ⭐

声明 推导规则
auto x = expr; 忽略 const/volatile/引用
auto& x = expr; 保留 const/volatile
auto* x = expr; 指针
cpp
const int a = 10;
auto b = a;           // int（去掉 const）
auto& c = a;          // const int&

int x = 5;
int& ref = x;
auto y = ref;          // int（去掉引用）
auto& z = ref;         // int&（保留引用）

6.3 decltype（C++11）

推导表达式的类型，但不使用该表达式。

cpp
int a = 10;
decltype(a) b = 20;      // int

decltype((a)) c = a;     // int&（双括号 = 引用）

// 用于模板
template <typename T, typename U>
auto add(T x, U y) -> decltype(x + y) {
    return x + y;
}

6.4 auto vs decltype ⭐

维度 auto decltype
用法 声明变量 推导类型
是否赋值 必须赋值 可不赋值
顶层 const 去除 保留

七、命名空间与作用域 ⭐

7.1 命名空间

cpp
namespace my {
    int x = 10;
    void func() { }
}

my::x = 20;
my::func();

7.2 using

cpp
// 单个引入
using std::cout;
cout << "hi";

// 全部引入（慎用）
using namespace std;
cout << "hi";

7.3 作用域

cpp
int x = 10;   // 全局

void f() {
    int x = 20;       // 局部（隐藏全局）
    ::x = 30;          // 显式访问全局（::作用域运算符）
}

九、面试常问 ⭐

💡 const 和 #define 的区别？ | const | #define | |-------|---------| | 有类型检查 | 纯文本替换 | | 有作用域 | 全局 | | 可调试 | 难调试 | | 现代 C++ 推荐 | 不推荐 |

💡 auto 的限制？

  • 不能作为函数形参（C++20 之前）
  • 不能用于非静态成员变量
  • 必须初始化

💡 auto 和 decltype 的区别？

  • auto 声明变量并初始化，会去掉引用和 const
  • decltype 仅推导类型，可保留 const 和引用

💡 C++ 四种强制类型转换？

  • static_cast：常规转换
  • const_cast：去 const
  • dynamic_cast：父子类安全转换（多态）
  • reinterpret_cast：底层重新解释

💡 sizeof 是函数还是运算符？ 运算符（编译期计算），不是函数调用。
