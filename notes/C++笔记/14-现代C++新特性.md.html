三、左值 vs 右值 ⭐⭐⭐

3.1 概念

  • 左值（lvalue）：有名字、可取地址、生命周期长
  • 右值（rvalue）：临时值、不可取地址、生命周期短
cpp
int a = 10;          // a 是左值
int b = a + 5;       // a+5 是右值（临时）
std::string s1 = "hello";
std::string s2 = s1 + " world";   // s1+" world" 是右值

详细分类：

text
表达式
├── 左值
│   ├── 变量
│   ├── 函数返回值（返回引用）
│   └── 前置++ / --
└── 右值
    ├── 字面值（42, "hello"）
    ├── 函数返回值（返回临时对象）
    ├── 后置++ / --
    └── 临时对象

3.2 引用折叠规则 ⭐

cpp
int a = 10;
int& lref = a;        // 左值引用
int&& rref = 10;       // 右值引用

// 引用折叠
int& &   → int&
int& &&  → int&
int&& &  → int&
int&& && → int&&

💡 这是 std::forward 的基础。

四、右值引用 ⭐⭐⭐

4.1 语法

cpp
int a = 10;
int& lref = a;        // 左值引用
int&& rref = 10;       // 右值引用（绑定到字面值）

// std::move 把左值转为右值引用
int&& rref2 = std::move(a);

4.2 右值引用延长生命周期

cpp
std::string&& r = std::string("hello");   // 临时对象的生命周期延长
// r 离开作用域才释放

五、移动语义 ⭐⭐⭐⭐

5.1 为什么需要移动语义

避免不必要的拷贝。

cpp
// C++03：拷贝构造（深拷贝）
std::string a = "hello";
std::string b = a;              // 拷贝 a 的内容给 b（开销大）

// C++11：移动构造（移动资源）
std::string c = std::move(a);   // 移动 a 的指针给自己（快）
// a 现在是空字符串

5.2 移动构造函数

cpp
class MyString {
    char* data_;
    size_t size_;

public:
    // 移动构造：从右值"窃取"资源
    MyString(MyString&& other) noexcept
        : data_(other.data_), size_(other.size_) {
        other.data_ = nullptr;       // 防止 double-free
        other.size_ = 0;
    }
};

MyString a("hello");
MyString b = std::move(a);    // 调移动构造

5.3 移动赋值

cpp
MyString& operator=(MyString&& other) noexcept {
    if (this != &other) {
        delete[] data_;
        data_ = other.data_;
        size_ = other.size_;
        other.data_ = nullptr;
        other.size_ = 0;
    }
    return *this;
}

5.4 移动语义的性能优势

cpp
std::vector<std::string> v;
v.push_back(std::string("hello"));   // 移动构造（快）
v.push_back("hello");                // 隐式构造 + 移动
v.push_back(std::move(someString));  // 移动构造（避免拷贝）

5.5 Rule of Five

如果定义了析构、拷贝构造、拷贝赋值、移动构造、移动赋值 之一，通常需要考虑其他几个。

cpp
class MyClass {
public:
    ~MyClass();                                // 析构
    MyClass(const MyClass&);                   // 拷贝构造
    MyClass& operator=(const MyClass&);        // 拷贝赋值
    MyClass(MyClass&&) noexcept;               // 移动构造
    MyClass& operator=(MyClass&&) noexcept;    // 移动赋值
};

5.6 何时会调用移动语义

cpp
// 1. 函数返回局部对象（隐式移动）
std::vector<int> make_vec() {
    std::vector<int> v;
    return v;            // NRVO / 移动
}

// 2. std::move
std::string a = "hi";
std::string b = std::move(a);

// 3. push_back / emplace_back 等
v.push_back(std::move(s));

六、std::move ⭐⭐⭐

将左值强制转换为右值引用，触发移动语义。

cpp
template <typename T>
constexpr std::remove_reference_t<T>&& move(T&& t) {
    return static_cast<std::remove_reference_t<T>&&>(t);
}

std::string a = "hi";
std::string b = std::move(a);    // a 变为"移后源"，b 接管资源

⚠ std::move 不移动任何东西，只是类型转换，真正的移动在移动构造/赋值中完成。

七、完美转发 ⭐⭐

保持参数的值类别（左值仍是左值，右值仍是右值）。

cpp
template <typename T>
void wrapper(T&& arg) {
    // std::forward 保持原类型
    func(std::forward<T>(arg));
}

wrapper(42);        // T = int，arg 是右值，转发给 func 的右值参数
wrapper(x);          // T = int&，arg 是左值，转发给 func 的左值参数

💡 完美转发用于模板包装函数，常见于工厂模式、emplace。

八、nullptr（C++11）⭐

cpp
int* p1 = NULL;          // C 风格（实际是 0）
int* p2 = nullptr;       // C++11 风格（类型安全的空指针）

template <typename T>
void func(T* p);

func(NULL);              // ❌ 推导为 int
func(nullptr);           // ✅ 推导为 nullptr_t

💡 现代 C++ 一律用 nullptr。

九、constexpr 进阶 ⭐⭐

cpp
constexpr int square(int x) { return x * x; }

constexpr int arr[square(3)];          // int arr[9]
constexpr auto pi = 3.14;              // double

// constexpr 函数中允许局部变量、循环（C++14）
constexpr int factorial(int n) {
    int result = 1;
    for (int i = 1; i <= n; i++) result *= i;
    return result;
}

// constexpr 构造（C++11）
struct Point {
    int x, y;
    constexpr Point(int a, int b) : x(a), y(b) {}
};
constexpr Point p(1, 2);    // 编译期构造

十、范围 for（C++11）⭐

cpp
std::vector<int> v = {1, 2, 3, 4, 5};

for (int x : v) { }             // 读
for (auto& x : v) { x *= 2; }   // 写
for (const auto& x : v) { }     // 读（避免拷贝）

十一、结构化绑定（C++17）⭐⭐

cpp
// 1. pair / tuple
std::pair<int, double> p{1, 3.14};
auto [a, b] = p;        // a = 1, b = 3.14

// 2. 数组
int arr[] = {1, 2, 3};
auto [x, y, z] = arr;

// 3. 结构体
struct Point { int x, y; };
Point pt{1, 2};
auto [px, py] = pt;

// 4. map 遍历
std::map<std::string, int> m;
for (const auto& [k, v] : m) { /* k 是 key, v 是 value */ }

十二、if / switch 初始化（C++17）

cpp
// if 初始化
if (auto it = m.find(key); it != m.end()) {
    std::cout << it->second;
}

// switch 初始化
switch (auto x = compute(); x) {
    case 1: /* ... */ break;
    default: /* ... */;
}

💡 作用域限制在 if/switch 内，避免污染外部。

十三、其他特性

13.1 std::optional（C++17）

cpp
std::optional<int> opt = 42;
if (opt) std::cout << *opt;

opt = std::nullopt;
opt = 100;

13.2 std::variant（C++17）

cpp
std::variant<int, std::string> v = 42;

std::visit([](auto&& arg) { std::cout << arg; }, v);

13.3 std::string_view（C++17）

不拷贝的字符串视图，用于只读参数。

cpp
void print(std::string_view s) {     // 不分配内存
    std::cout << s;
}

print("hello");        // 字面值 → 不会构造 std::string

13.4 std::filesystem（C++17）

cpp
#include <filesystem>

for (auto& entry : std::filesystem::directory_iterator(".")) {
    std::cout << entry.path() << "\n";
}

13.5 tuple 解包

cpp
auto t = std::make_tuple(1, "hi", 3.14);
std::cout << std::get<0>(t);    // 1
std::cout << std::get<1>(t);    // hi

十四、面试常问 ⭐⭐⭐

💡 左值和右值的区别？

  • 左值：有名字、可取地址
  • 右值：临时值、不可取地址

💡 std::move 是什么？ 本质是类型转换（T → T&&），不移动任何东西。真正的移动在移动构造中。

💡 移动语义解决了什么问题？

  • 避免不必要的深拷贝
  • 对临时对象"窃取"资源

💡 什么是完美转发？ 模板函数转发参数时保持原值类别（左值/右值）。用 std::forward<T>(arg)。

💡 emplace_back vs push_back？

  • push_back：先构造临时对象，再移动到容器
  • emplace_back：直接在容器内存中构造（少一次移动）

💡 Rule of Five 是什么？ 析构、拷贝构造、拷贝赋值、移动构造、移动赋值是配套的。

💡 nullptr vs NULL？

  • NULL 是宏（实际是 0 或 (void*)0）
  • nullptr 是类型安全的空指针（C++11）

💡 结构化绑定能用在哪些场景？

  • pair / tuple
  • 数组
  • 结构体（所有非静态成员）
  • map 遍历
