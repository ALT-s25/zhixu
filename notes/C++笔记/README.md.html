## 🎯 二刷者重点（哪些必看、哪些快过）

### 🔴 必看、必须深入理解

| 模块 | 为什么重要 |
|------|-----------|
| 指针与引用（5） | C++ 的灵魂，**所有 C++ 难点都源自指针** |
| 面向对象基础（6） | 类/对象、构造/析构、this、访问控制 |
| 继承多态（7） | **虚函数是 C++ 三大特性中最难的**，面试必问 |
| 模板（9） | 现代 C++ 的基石，STL 全是模板 |
| STL 容器（10） | 工作 80% 时间在用 vector、map |
| 现代 C++ 新特性（14） | 移动语义、右值引用是现代 C++ 核心 |

### 🟡 重要、但可快过

| 模块 | 学习策略 |
|------|----------|
| 基础语法（2、3） | 重点是类型系统、引用、重载、内联函数 |
| 数组与字符串（4） | 重点是 string 和 vector |
| 运算符重载（8） | 理解原理，知道何时用 |
| STL 算法（11） | 重点是 lambda + algorithm |
| 智能指针（12） | 必看 unique_ptr、shared_ptr 原理 |
| 类型转换与关键字（13） | 重点是 const 修饰、enum class |

### 🟢 了解、看过即可

| 模块 | 学习策略 |
|------|----------|
| 入门（1） | 安装配置而已 |
| 异常与多线程（15） | 了解即可，工作用框架 |

## 🧠 现代 C++ 知识体系全景图

```
现代 C++ (C++11/14/17)
├── 基础语法层
│   ├── 数据类型、变量、常量
│   ├── 运算符、表达式
│   ├── 流程控制（if/switch/循环）
│   ├── 函数（重载、内联、参数传递）
│   ├── 数组与字符串（C数组 / std::string）
│   └── 指针与引用 ⭐核心
├── 面向对象层 ⭐核心
│   ├── 类与对象、构造器、析构函数
│   ├── 封装（private/public/protected）
│   ├── 继承（单继承、多继承、菱形继承）
│   ├── 多态（虚函数、override/final、抽象类）
│   ├── 运算符重载
│   └── 友元（friend）
├── 模板与泛型层 ⭐核心
│   ├── 函数模板
│   ├── 类模板
│   ├── 模板特化
│   └── 可变参数模板
├── STL 层 ⭐核心
│   ├── 容器（vector/list/deque/set/map/unordered_*）
│   ├── 迭代器
│   ├── 算法（algorithm）
│   ├── 函数对象（lambda、bind、function）
│   └── 适配器（stack/queue/priority_queue）
├── 现代特性层 ⭐核心
│   ├── auto / decltype
│   ├── 右值引用与移动语义
│   ├── 智能指针（unique_ptr/shared_ptr/weak_ptr）
│   ├── lambda 表达式
│   ├── nullptr、constexpr
│   └── 结构化绑定（C++17）
└── 高级层
    ├── 异常处理
    ├── 类型转换（static_cast 等）
    ├── 关键字（const、static、explicit）
    └── 多线程（thread/mutex/async）
```

## 💡 二刷常见问题（提前避坑）

1. **"指针/引用搞不清"** → 画内存图，对照代码看变量与内存的关系
2. **"虚函数表是什么"** → 画虚函数表布局图
3. **"模板元编程太难"** → 先掌握函数模板、类模板基础，模板元编程了解即可
4. **"STL 容器太多记不住"** → 记住"底层结构 + 增删查复杂度"框架
5. **"智能指针的循环引用"** → 画循环引用图，配合 weak_ptr
6. **"右值引用是什么"** → 先理解左值/右值概念，再学移动语义
