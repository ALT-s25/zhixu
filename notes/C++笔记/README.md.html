💡 二刷常见问题（提前避坑）

  1. "指针/引用搞不清" → 画内存图，对照代码看变量与内存的关系
  2. "虚函数表是什么" → 画虚函数表布局图
  3. "模板元编程太难" → 先掌握函数模板、类模板基础，模板元编程了解即可
  4. "STL 容器太多记不住" → 记住"底层结构 + 增删查复杂度"框架
  5. "智能指针的循环引用" → 画循环引用图，配合 weak_ptr
  6. "右值引用是什么" → 先理解左值/右值概念，再学移动语义

🎯 学完现代 C++ 的检验标准

  • 能手写智能指针（unique_ptr 或简易 shared_ptr）
  • 能口述 vector 扩容机制（2 倍 vs 1.5 倍）
  • 能解释虚函数表（vtable）的结构和动态绑定过程
  • 能口述移动语义解决了什么问题、为什么快
  • 能用 lambda 表达式简化 STL 算法调用
  • 能说出 auto 的推导规则、与 decltype 的区别
  • 能��分左值与右值，区分 std::move 和 std::forward
  • 能解释 const、constexpr、consteval 的层次

完成这些 → 现代 C++ 过关！
