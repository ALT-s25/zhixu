二、运算符重载基础 ⭐⭐

2.1 什么是运算符重载

让自定义类型也能用 +、-、== 等运算符。

cpp
class Complex {
    double real_, imag_;

public:
    Complex(double r = 0, double i = 0) : real_(r), imag_(i) {}

    // 成员函数形式
    Complex operator+(const Complex& other) const {
        return Complex(real_ + other.real_, imag_ + other.imag_);
    }
};

Complex a(1, 2), b(3, 4);
Complex c = a + b;       // 等价于 a.operator+(b)

2.2 两种重载形式

cpp
// 1. 成员函数（左侧是 this）
class MyClass {
    int x;
public:
    MyClass operator+(const MyClass& other) const {
        return MyClass(x + other.x);
    }
};

// 2. 友元/普通函数（左侧是参数）
class MyClass {
    int x;
    friend MyClass operator+(const MyClass& a, const MyClass& b);
};

MyClass operator+(const MyClass& a, const MyClass& b) {
    return MyClass(a.x + b.x);
}

三、可重载与不可重载的运算符 ⭐

3.1 可重载（40+ 个）

text
算术：+  -  *  /  %  ++  --
关系：==  !=  <  >  <=  >=
逻辑：&&  ||  !
位运算：&  |  ^  ~  <<  >>
赋值：=  +=  -=  *=  /=  %=  &=  |=  ^=  <<=  >>=
其他：[]  ()  ->  ->*  ,  new  delete
流：<<  >>（仅友元函数）

3.2 不可重载

text
::       // 作用域
.        // 成员访问
.*       // 成员指针访问
?:       // 三元
sizeof   // 大小
typeid   // 类型

⚠ 优先级、结合性、操作数个数都不可变！

四、常用运算符重载 ⭐⭐

4.1 算术运算符

cpp
class Complex {
    double real_, imag_;

public:
    Complex(double r = 0, double i = 0) : real_(r), imag_(i) {}

    // 二元运算符
    Complex operator+(const Complex& o) const {
        return Complex(real_ + o.real_, imag_ + o.imag_);
    }
    Complex operator-(const Complex& o) const { /* ... */ }
    Complex operator*(const Complex& o) const { /* ... */ }

    // 一元运算符
    Complex operator-() const {                    // 取负
        return Complex(-real_, -imag_);
    }

    // 前置++
    Complex& operator++() {
        real_++;
        return *this;
    }
    // 后置++（int 参数仅用于区分）
    Complex operator++(int) {
        Complex tmp(*this);
        real_++;
        return tmp;
    }
};

4.2 关系运算符 ⭐

cpp
bool operator==(const MyClass& o) const {
    return x == o.x && y == o.y;
}
bool operator!=(const MyClass& o) const { return !(*this == o); }
bool operator<(const MyClass& o) const {
    return x < o.x || (x == o.x && y < o.y);
}

💡 C++20 <=> 三路比较运算符（spaceship operator），自动生成 6 个比较运算符。

4.3 流运算符 << >> ⭐⭐

只能重载为友元函数。

cpp
class Student {
    std::string name_;
    int age_;

public:
    Student(const std::string& n, int a) : name_(n), age_(a) {}

    friend std::ostream& operator<<(std::ostream& os, const Student& s) {
        return os << "Student{name=" << s.name_ << ", age=" << s.age_ << "}";
    }

    friend std::istream& operator>>(std::istream& is, Student& s) {
        return is >> s.name_ >> s.age_;
    }
};

Student s("张三", 18);
std::cout << s;     // Student{name=张三, age=18}
std::cin >> s;

4.4 下标运算符 [] ⭐⭐

cpp
class MyArray {
    int data_[10];

public:
    // 非 const 版本
    int& operator[](int i) {
        return data_[i];
    }

    // const 版本（用于 const 对象）
    const int& operator[](int i) const {
        return data_[i];
    }
};

MyArray a;
a[0] = 100;        // 调用非 const 版本，返回引用可写

const MyArray& ca = a;
ca[0];              // 调用 const 版本

4.5 函数调用运算符 () ⭐⭐

让对象像函数一样调用。

cpp
class Add {
public:
    int operator()(int a, int b) const {
        return a + b;
    }
};

Add add;
std::cout << add(3, 5);    // 8

💡 这是 函数对象（Function Object / Functor），STL 算法常用。

4.6 解引用运算符 *

cpp
class SmartPtr {
    int* p_;
public:
    SmartPtr(int* p) : p_(p) {}
    ~SmartPtr() { delete p_; }

    int& operator*() { return *p_; }
    int* operator->() { return p_; }
};

SmartPtr p(new int(10));
std::cout << *p;       // 10

五、赋值运算符 =

详见 06-面向对象基础.md 的拷贝构造部分

cpp
// 拷贝赋值
MyClass& operator=(const MyClass& o) {
    if (this != &o) {              // 自赋值检查
        // 释放旧资源
        // 拷贝新资源
    }
    return *this;                  // 返回 *this 以支持链式
}

// 移动赋值（C++11）
MyClass& operator=(MyClass&& o) noexcept {
    if (this != &o) {
        // 转移资源
        o.资源 = nullptr;          // 置空
    }
    return *this;
}

⚠ 赋值运算符必须处理自赋值（a = a）！

六、友元 ⭐

详见 06-面向对象基础.md

6.1 友元函数

cpp
class Student {
    std::string name_;
    int age_;

    friend void print(const Student& s);     // 友元函数声明
};

void print(const Student& s) {
    std::cout << s.name_ << " " << s.age_;   // 可访问私有
}

6.2 友元类

cpp
class Teacher {
public:
    void view(const Student& s) {
        std::cout << s.name_;    // 可访问 Student 私有
    }
};

class Student {
    friend class Teacher;         // 友元类
private:
    std::string name_;
};

6.3 友元运算符重载

cpp
class Vec2 {
    double x_, y_;

public:
    Vec2(double x, double y) : x_(x), y_(y) {}

    // 二元运算符（左侧不是 this，必须友元）
    friend Vec2 operator+(const Vec2& a, const Vec2& b) {
        return Vec2(a.x_ + b.x_, a.y_ + b.y_);
    }
};

七、运算符重载最佳实践

7.1 Rule of Five

如果定义了析构、拷贝构造、拷贝赋值、移动构造、移动赋值中的任何一个，通常都要定义其他四个。

7.2 优先级建议

  1. 优先使用 STL 算法 + lambda
  2. 优先使用成员函数重载（如 +）
  3. 流运算符、复合赋值必须友元

7.3 重载的语义要自然

cpp
// ✅ 自然的
a + b       // 表示 "相加"
a == b      // 表示 "相等"

// ❌ 不自然的
a + b       // 表示 "比较"（不应该）

八、面试常问 ⭐⭐

💡 哪些运算符不能重载？ ::、.、.*、?:、sizeof、typeid

💡 成员函数 vs 友元���数重载？

  • 成员函数：左侧是 this，如 a + b 等价 a.operator+(b)
  • 友元函数：左侧也是参数，如 <<、>>、a + b（交换律）

💡 operator++ 前置和后置的区别？

  • 前置：++a → 先加后用，返回引用
  • 后置：a++ → 先用后加，返回旧值（拷贝）
  • 后置用 int 占位参数区分

💡 << 运算符为什么要重载为友元？ 因为 cout << obj 中，左侧是 ostream，不是 this，必须用友元函数。

💡 为什么运算符重载不能改变优先级？ 保证语言的一致性，避免歧义。
