## 二、STL 六大组件

1. **容器（Containers）**：存放数据的数据结构
2. **算法（Algorithms）**：操作数据的函数（`<algorithm>`）
3. **迭代器（Iterators）**：访问容器元素的桥梁
4. **函数对象（Functors）**：行为类似函数的对象（`operator()`）
5. **适配器（Adapters）**：转换容器/迭代器接口
6. **分配器（Allocators）**：管理内存分配

## 三、序列容器 ⭐⭐

### 3.1 vector（动态数组）⭐⭐⭐

**最常用**，底层是动态数组。

```cpp
#include <vector>

std::vector<int> v = {1, 2, 3, 4, 5};

// 增
v.push_back(6);            // 末尾追加
v.emplace_back(7);          // 原地构造（更高效）
v.insert(v.begin() + 2, 99);// 中间插入 O(n)

// 删
v.pop_back();              // 删末尾 O(1)
v.erase(v.begin());         // 删指定 O(n)
v.erase(v.begin(), v.begin()+2);
v.clear();

// 查/改
v[0];                      // 不检查越界
v.at(0);                    // 检查越界，抛异常
v.front();                  // 首元素
v.back();                   // 末元素

// 大小
v.size();
v.capacity();               // 容量
v.empty();
v.shrink_to_fit();          // 缩容
v.reserve(100);             // 预留空间（避免扩容）

// 遍历
for (int x : v) cout << x;
for (auto it = v.begin(); it != v.end(); ++it) cout << *it;
```

**vector 扩容机制** ⭐⭐：
- 通常按 **1.5 倍或 2 倍** 扩容（取决于编译器，GCC 2 倍）
- 扩容会重新分配内存 + 拷贝元素，**性能开销大**
- 建议 `reserve` 提前分配足够空间

**emplace_back vs push_back**：
```cpp
// push_back：先构造临时对象，再拷贝/移动到 vector
v.push_back(MyClass("hi", 18));

// emplace_back：直接在 vector 内存中构造（更快）
v.emplace_back("hi", 18);
```

### 3.2 deque（双端队列）

**双端插入/删除都是 O(1)**，但比 vector 慢。

```cpp
std::deque<int> dq = {1, 2, 3};
dq.push_front(0);     // 头部插入
dq.push_back(4);      // 尾部插入
dq.pop_front();       // 头部删除
dq.pop_back();        // 尾部删除
```

### 3.3 list（双向链表）

**任意位置插入/删除 O(1)**，但**不能随机访问**。

```cpp
std::list<int> lst = {1, 2, 3};
lst.push_front(0);
lst.push_back(4);
lst.insert(++lst.begin(), 99);

auto it = lst.begin();
std::advance(it, 2);    // 移动到第 3 个位置
lst.insert(it, 100);    // O(1) 插入

// list 特有操作
lst.remove(2);           // 删除所有值为 2 的
lst.sort();              // 链表专用排序（不能用 algorithm::sort）
lst.unique();            // 去重
lst.reverse();           // 反转
lst.merge(other);        // 合并（要求已排序）
lst.splice(pos, other);  // 拼接（不复制，直接移动）
```

### 3.4 array（C++11）

**固定大小**的数组封装（替代 C 数组）。

```cpp
#include <array>

std::array<int, 5> arr = {1, 2, 3, 4, 5};
arr.size();
arr[0];
arr.fill(0);             // 全部填充为 0
```

## 四、关联容器 ⭐⭐

**元素有序**（默认升序），底层是**红黑树**。

### 4.1 set

```cpp
#include <set>

std::set<int> s = {3, 1, 4, 1, 5};     // {1, 3, 4, 5}（自动去重+排序）

s.insert(2);            // O(log n)
s.erase(1);
s.count(3);             // 是否存在
s.find(3);              // 返回迭代器，没找到返回 s.end()

// 范围查询
auto lo = s.lower_bound(3);     // ≥ 3 的第一个
auto hi = s.upper_bound(3);     // > 3 的第一个

// 自定义排序
std::set<int, std::greater<int>> s2 = {3, 1, 4};   // {4, 3, 1}
```

### 4.2 map ⭐⭐⭐

**键值对**，按键排序。

```cpp
#include <map>

std::map<std::string, int> m;
m["张三"] = 18;
m["李四"] = 20;

// 增删
m.emplace("王五", 22);
m.erase("张三");

// 查
m.count("张三");                 // 是否存在
m.find("张三");                  // 迭代器
m.at("张三");                    // 不存在抛异常

// 遍历（按 key 升序）
for (const auto& [key, value] : m) {
    std::cout << key << ": " << value << "\n";
}

// 自定义比较器（按 value 排序）
std::map<std::string, int, std::function<bool(const std::string&, const std::string&)>> m2(
    [](const std::string& a, const std::string& b) { return a > b; }
);
```

### 4.3 multiset / multimap

**允许重复**元素。

```cpp
std::multiset<int> ms = {1, 2, 2, 3};
std::multimap<std::string, int> mm;
mm.insert({"A", 1});
mm.insert({"A", 2});         // 允许重复 key
```

## 五、无序容器 ⭐⭐

**哈希表实现**，**O(1) 平均**增删查，**无序**。

### 5.1 unordered_map ⭐⭐⭐

**最常用**，key 不需要排序时优先使用。

```cpp
#include <unordered_map>

std::unordered_map<std::string, int> um;
um["张三"] = 18;
um["李四"] = 20;

// 用法与 map 类似
um.emplace("王五", 22);
um.count("张三");

// 遍历（无序）
for (const auto& [key, value] : um) { /* ... */ }

// 自定义哈希
struct MyHash {
    size_t operator()(const MyKey& k) const { return /* ... */; }
};
std::unordered_map<MyKey, int, MyHash> custom_map;
```

### 5.2 unordered_set

```cpp
std::unordered_set<int> us = {3, 1, 4};   // 无序
```

### 5.3 map vs unordered_map ⭐⭐⭐

| 维度 | map | unordered_map |
|------|-----|---------------|
| 底层 | 红黑树 | 哈希表 |
| 有序 | ✅ | ❌ |
| 增删查复杂度 | O(log n) | O(1) 平均，O(n) 最坏 |
| 内存占用 | 较少 | 较多 |
| 自定义比较 | 用 comparator | 用 hash 函数 |

> 💡 **选型建议**：
> - 需要**有序** → map
> - 不需要有序，**追求性能** → unordered_map
> - 大部分情况下 **unordered_map 更优**

## 六、容器适配器

### 6.1 stack（栈）⭐

```cpp
#include <stack>

std::stack<int> s;
s.push(1);
s.pop();
s.top();
s.empty();
s.size();
```

### 6.2 queue（队列）⭐

```cpp
#include <queue>

std::queue<int> q;
q.push(1);
q.pop();
q.front();
q.back();
q.empty();
```

### 6.3 priority_queue（优先队列 / 堆）⭐⭐

```cpp
std::priority_queue<int> pq;        // 默认大顶堆
pq.push(3);
pq.push(1);
pq.push(4);
pq.top();                            // 4（最大元素）
pq.pop();

// 小顶堆
std::priority_queue<int, std::vector<int>, std::greater<int>> min_pq;

// 自定义比较
auto cmp = [](int a, int b) { return a > b; };
std::priority_queue<int, std::vector<int>, decltype(cmp)> custom_pq(cmp);
```

> 💡 **优先队列的底层是 vector + 堆算法**。

## 七、迭代器 ⭐⭐

迭代器是 STL 的"灵魂"，提供统一访问容器元素的方式。

### 7.1 5 种迭代器

| 类型 | 支持操作 | 类别 |
|------|---------|------|
| 输入迭代器 | 读，单向 | istream_iterator |
| 输出迭代器 | 写，单向 | ostream_iterator |
| 前向迭代器 | 读写，单向 | forward_list |
| 双向迭代器 | 读写，双向 | list、set、map |
| **随机访问迭代器** | 读写，随机访问 | vector、deque |

### 7.2 迭代器使用

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

// begin/end
auto it = v.begin();          // 指向首元素
auto end = v.end();           // 指向末尾之后

*it;                          // 解引用
it++;                         // 前进
it += 3;                      // 随机访问（仅 vector 等）

// 常量迭代器（不能修改元素）
auto cit = v.cbegin();

// 反向迭代器
auto rit = v.rbegin();
```

### 7.3 迭代器失效 ⭐⭐

> **重要**：容器操作可能使迭代器失效！

| 容器 | 失效场景 |
|------|---------|
| **vector** | 插入：可能失效（扩容或中间插入）<br>删除：删除点及之后失效 |
| **deque** | 插入到首尾之外会全部失效 |
| **list/set/map** | 删除点失效（不影响其他） |

```cpp
std::vector<int> v = {1, 2, 3};
auto it = v.begin();
v.push_back(4);     // 可能扩容，it 失效！
```

### 7.4 const_iterator vs iterator

```cpp
std::vector<int> v;
auto it = v.begin();            // iterator（可改元素）
auto cit = v.cbegin();          // const_iterator（不可改）

std::vector<int>::const_iterator cit2 = v.begin();   // 显式
```

## 八、容器对比总结 ⭐⭐⭐

| 容器 | 底层 | 随机访问 | 增删复杂度 | 有序 | 适用场景 |
|------|------|---------|----------|------|----------|
| **vector** | 动态数组 | O(1) | 末尾 O(1)，中间 O(n) | ❌ | 默认首选 |
| **deque** | 双端队列 | O(1) | 头尾 O(1)，中间 O(n) | ❌ | 需要头尾插入 |
| **list** | 双向链表 | ❌ | 任意位置 O(1) | ❌ | 频繁插入删除 |
| **set/map** | 红黑树 | ❌ | O(log n) | ✅ | 需要有序 |
| **unordered_set/map** | 哈希表 | ❌ | O(1) 平均 | ❌ | 追求性能 |
| **stack/queue/priority_queue** | 适配器 | - | 取决于底层 | - | 特定场景 |

## 九、面试常问 ⭐⭐⭐

> 💡 **vector 的底层原理？扩容机制？**
> - 3 个指针：begin、end、capacity_end
> - 扩容：通常 2 倍（GCC）或 1.5 倍（MSVC）
> - 扩容会重新分配 + 拷贝，性能开销大
> - 用 `reserve` 避免扩容

> 💡 **vector 插入元素 O(n)？**
> 是的，**头部/中间插入**为 O(n)。末尾为 O(1) 均摊。

> 💡 **vector 和 list 的区别？**
> | 维度 | vector | list |
> |------|--------|------|
> | 底层 | 数组 | 链表 |
> | 随机访问 | O(1) | O(n) |
> | 中间插入 | O(n) | O(1) |
> | 内存 | 连续 | 离散 |
> | 缓存友好 | ✅ | ❌ |

> 💡 **map 和 unordered_map 区别？**
> | 维度 | map | unordered_map |
> |------|-----|---------------|
> | 底层 | 红黑树 | 哈希表 |
> | 有序 | ✅ | ❌ |
> | 时间 | O(log n) | O(1) 平均 |

> 💡 **迭代器失效场景？**
> - vector：插入可能全失效，删除删除点之后失效
> - list/set/map：删除点失效
> - 总原则：**修改容器后不要继续使用之前的迭代器**

> 💡 **emplace_back vs push_back？**
> - `push_back`：先构造临时对象，再移动到容器
> - `emplace_back`：直接在容器内存中构造（少一次移动/拷贝）

> 💡 **priority_queue 的底层？**
> vector + 堆算法（默认大顶堆）
