## 二、算法总览

所有 STL 算法都在 `<algorithm>` 中，是**函数模板**，通过迭代器操作容器。

```cpp
#include <algorithm>
```

**特点**：
- 与容器**解耦**（不关心底层）
- 通过**迭代器**操作
- 可用 lambda / 函数对象定制行为

## 三、非修改算法 ⭐

### 3.1 find / count

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};

auto it = std::find(v.begin(), v.end(), 3);     // 找 3，返回迭代器
if (it != v.end()) std::cout << *it;             // 3

int n = std::count(v.begin(), v.end(), 3);     // 计数
```

### 3.2 for_each

```cpp
std::for_each(v.begin(), v.end(), [](int x) {
    std::cout << x << " ";
});

// C++11 后更推荐 range-for
for (int x : v) std::cout << x << " ";
```

### 3.3 min / max / minmax

```cpp
int a = 3, b = 5;
std::min(a, b);                          // 3
std::max(a, b);                          // 5
std::min({1, 2, 3});                     // 1（初始化列表）
auto [lo, hi] = std::minmax(3, 5);       // 解构（C++11）
```

### 3.4 equal / mismatch

```cpp
std::vector<int> a = {1, 2, 3};
std::vector<int> b = {1, 2, 4};
std::equal(a.begin(), a.end(), b.begin());     // false
```

## 四、修改算法 ⭐⭐

### 4.1 copy

```cpp
std::vector<int> src = {1, 2, 3, 4, 5};
std::vector<int> dst(5);
std::copy(src.begin(), src.end(), dst.begin());

// C++11 推荐
std::vector<int> dst2(src.begin(), src.end());
```

### 4.2 replace

```cpp
std::replace(v.begin(), v.end(), 3, 99);   // 所有 3 替换为 99
```

### 4.3 remove（erase-remove 惯用法）⭐

```cpp
// remove 不是真的删除，而是把不要的元素移到末尾，返回新的 end
auto it = std::remove(v.begin(), v.end(), 3);
v.erase(it, v.end());     // 真的删除

// C++20 之前最简洁写法（erase-remove idiom）
v.erase(std::remove(v.begin(), v.end(), 3), v.end());
```

> 💡 **C++20** 提供 `std::erase()` / `std::erase_if()`，直接完成两步。

### 4.4 transform（重要）⭐⭐

```cpp
std::vector<int> v = {1, 2, 3, 4};
std::vector<int> result(4);

// 1. 一元变换
std::transform(v.begin(), v.end(), result.begin(),
               [](int x) { return x * 2; });
// result = {2, 4, 6, 8}

// 2. 二元变换
std::vector<int> v2 = {10, 20, 30, 40};
std::vector<int> sum(4);
std::transform(v.begin(), v.end(), v2.begin(), sum.begin(),
               std::plus<int>());
// sum = {11, 22, 33, 44}
```

### 4.5 fill / generate

```cpp
std::fill(v.begin(), v.end(), 0);     // 全部填充 0

std::generate(v.begin(), v.end(), []() { return rand() % 100; });
```

### 4.6 reverse / rotate

```cpp
std::reverse(v.begin(), v.end());
std::rotate(v.begin(), v.begin() + 2, v.end());
```

## 五、排序相关 ⭐⭐

### 5.1 sort

```cpp
std::vector<int> v = {3, 1, 4, 1, 5, 9, 2, 6};

// 默认升序
std::sort(v.begin(), v.end());

// 自定义排序
std::sort(v.begin(), v.end(), std::greater<int>());   // 降序

// lambda
std::sort(v.begin(), v.end(), [](int a, int b) {
    return a > b;       // 降序
});
```

### 5.2 stable_sort

**保持相等元素的相对顺序**（稳定的排序）。

```cpp
std::stable_sort(v.begin(), v.end());
```

### 5.3 partial_sort

**部分排序**，只排前 k 个。

```cpp
std::partial_sort(v.begin(), v.begin() + 3, v.end());
// 前 3 个元素排好，其他顺序不定
```

### 5.4 nth_element ⭐

**第 k 小的元素**（快选算法）。

```cpp
std::nth_element(v.begin(), v.begin() + k, v.end());
// v[k] 是第 k 小的元素
```

> 💡 求 Top K 问题：**`nth_element` 比 `sort` 快得多**。

## 六、查找算法 ⭐

### 6.1 binary_search（二分）

```cpp
std::vector<int> v = {1, 2, 3, 4, 5};      // 必须有序！
bool found = std::binary_search(v.begin(), v.end(), 3);  // true
```

### 6.2 lower_bound / upper_bound

```cpp
std::vector<int> v = {1, 2, 2, 2, 3};

auto lo = std::lower_bound(v.begin(), v.end(), 2);   // 指向第一个 2
auto hi = std::upper_bound(v.begin(), v.end(), 2);   // 指向第一个 > 2
int count = hi - lo;                                  // 3（2 的个数）
```

### 6.3 equal_range

```cpp
auto [lo, hi] = std::equal_range(v.begin(), v.end(), 2);
```

## 七、函数对象（Functor）⭐

### 7.1 什么是函数对象

**重载了 `operator()` 的类**，行为类似函数。

```cpp
struct Square {
    int operator()(int x) const {
        return x * x;
    }
};

Square sq;
std::cout << sq(5);   // 25

// 用于 STL
std::transform(v.begin(), v.end(), v.begin(), Square{});
```

### 7.2 预定义函数对象（<functional>）⭐

```cpp
#include <functional>

std::plus<int>();          // a + b
std::minus<int>();          // a - b
std::multiplies<int>();     // a * b
std::divides<int>();        // a / b
std::modulus<int>();        // a % b
std::negate<int>();         // -a

std::equal_to<int>();       // a == b
std::not_equal_to<int>();   // a != b
std::greater<int>();        // a > b
std::less<int>();            // a < b
std::greater_equal<int>();  // a >= b
std::less_equal<int>();     // a <= b

std::logical_and<int>();    // a && b
std::logical_or<int>();     // a || b
std::logical_not<int>();    // !a
```

```cpp
// 用于 sort
std::sort(v.begin(), v.end(), std::greater<int>());

// 用于 transform
std::transform(v.begin(), v.end(), v2.begin(), out.begin(), std::plus<int>());
```

## 八、Lambda 深入 ⭐⭐

### 8.1 完整语法

```cpp
[capture-list](params) mutable constexpr exception -> return_type {
    body
}
```

| 部分 | 说明 |
|------|------|
| `capture-list` | 捕获列表：`[]`、`[=]`、`[&]`、`[x]`、`[&x]` |
| `params` | 参数列表（可省略为空） |
| `mutable` | 允许修改值捕获的变量（默认 const） |
| `constexpr` | 显式声明 constexpr |
| `exception` | 异常规范（C++20 已废弃） |
| `return-type` | 返回类型（可省略自动推导） |

### 8.2 捕获方式

```cpp
int x = 10, y = 20;

auto f1 = []() { /* 不捕获 */ };
auto f2 = [x, y]() { return x + y; };      // 值捕获（副本）
auto f3 = [&x, &y]() { x++; y++; };       // 引用捕获
auto f4 = [=]() { return x + y; };          // 全部值捕获
auto f5 = [&]() { x++; };                    // 全部引用捕获
auto f6 = [=, &y]() { /* x 值，y 引用 */ };
auto f7 = [&, x]() { /* 其他引用，x 值 */ };
auto f8 = [this]() { /* 捕获当前对象的 this */ };
```

### 8.3 mutable（允许修改值捕获）

```cpp
int x = 10;
auto f = [x]() mutable {
    x++;        // 允许修改副本
    return x;
};
std::cout << f();   // 11
std::cout << x;     // 10（原值未变）
```

### 8.4 泛型 Lambda（C++14）⭐

```cpp
auto print = [](auto x) {
    std::cout << x;
};

print(42);          // int
print("hello");     // const char*
print(3.14);        // double
```

### 8.5 Lambda 的实际类型

Lambda 实际上是一个**匿名类**，含一个 `operator()`。

```cpp
auto lambda = [](int a, int b) { return a + b; };
std::cout << typeid(lambda).name();  // 类似 "Z4mainEUliiE_"
```

## 九、std::function 与 std::bind ⭐

### 9.1 std::function（函数包装器）⭐

```cpp
#include <functional>

// 1. 包装普通函数
std::function<int(int, int)> f1 = [](int a, int b) { return a + b; };
std::cout << f1(3, 5);    // 8

// 2. 包装成员函数
struct Calculator {
    int add(int a, int b) { return a + b; }
};
Calculator c;
std::function<int(Calculator*, int, int)> f2 = &Calculator::add;
std::cout << f2(&c, 3, 5);     // 8

// 3. 包装函数对象
std::function<int(int)> f3 = Square{};
std::cout << f3(5);              // 25
```

### 9.2 std::bind（参数绑定）⭐

```cpp
int add(int a, int b, int c) { return a + b + c; }

// 绑定部分参数
auto f = std::bind(add, 10, std::placeholders::_1, 20);
std::cout << f(30);    // add(10, 30, 20) = 60

// 调整顺序
auto g = std::bind(add, std::placeholders::_2, 100, std::placeholders::_1);
std::cout << g(1, 2);   // add(2, 100, 1) = 103
```

> 💡 **C++11 之后**：很多场景用 **lambda 替代 std::bind**（更清晰）。

## 十、常用算法速查表

| 类别 | 算法 |
|------|------|
| 查找 | find、count、binary_search、lower_bound |
| 排序 | sort、stable_sort、partial_sort、nth_element |
| 修改 | copy、remove、replace、transform、fill |
| 数值 | accumulate、iota（`<numeric>`） |
| 集合 | set_intersection、set_union（需排序） |
| 堆 | make_heap、push_heap、pop_heap |

```cpp
// accumulate（求和）
std::vector<int> v = {1, 2, 3, 4, 5};
int sum = std::accumulate(v.begin(), v.end(), 0);     // 15

// iota（递增填充）
std::vector<int> v2(5);
std::iota(v2.begin(), v2.end(), 1);     // {1, 2, 3, 4, 5}
```

## 十一、面试常问 ⭐⭐

> 💡 **sort 和 stable_sort 的区别？**
> - sort：不保证相等元素的相对顺序
> - stable_sort：保证（基于归并排序）

> 💡 **erase-remove 惯用法？**
> ```cpp
> v.erase(std::remove(v.begin(), v.end(), 3), v.end());
> ```
> remove 不能真的删除，需要配合 erase 才能真正移除。

> 💡 **Lambda 捕获方式？**
> - `[=]` 值捕获全部
> - `[&]` 引用捕获全部
> - 默认值捕获的变量是 const（mutable 解除）

> 💡 **`std::function` vs `std::bind` vs Lambda？**
> | std::function | std::bind | Lambda |
> |---------------|-----------|--------|
> | 类型擦除包装 | 参数绑定 | 匿名函数 |
> | 有运行开销 | 复杂 | **推荐** |
> | 可存储回调 | 兼容老代码 | C++11+ 推荐 |

> 💡 **`nth_element` 的应用？**
> - 求 Top K 问题（比 sort 快得多）
> - O(n) 平均复杂度

> 💡 **泛型 Lambda 怎么写？**
> ```cpp
> auto f = [](auto x) { return x * 2; };
> ```
