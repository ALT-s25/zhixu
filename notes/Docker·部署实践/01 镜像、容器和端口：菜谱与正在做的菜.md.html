01 镜像、容器和端口：菜谱与正在做的菜

约 2 分钟阅读你的知识，慢慢成林

把三个对象分清

镜像像固定版本的菜谱和备料，容器像按该版本启动的一次制作，仓库像存放各版本菜谱的地方。镜像不会因为你启动两次就自动复制出两套独立数据库备份。

容器是隔离运行的进程，不是完整虚拟机。Linux容器依赖Linux内核环境，Windows上的相关运行环境通常由工具提供虚拟化支持；不能简单理解成一个镜像无条件运行在任意系统和CPU上。

跟课程做一次Nginx实验

先安装并确认Docker可用，再逐行执行。镜像标签是练习示例，真实项目应固定并核对自己环境的版本。

sh
docker version
docker run --name learn-nginx -d -p 127.0.0.1:8088:80 nginx:stable
docker ps
docker logs --tail 30 learn-nginx

浏览器访问http://127.0.0.1:8088。8088:80左边是宿主机端口，右边是容器内Nginx监听端口；它不是把Nginx内部也改成8088。绑定127.0.0.1使此练习入口仅在本机访问。

sh
docker stop learn-nginx
docker start learn-nginx

stop暂停的是这次容器运行，start启动同一个已存在的容器；再次run是创建新容器，重复使用同名会冲突。停止不是删除镜像。

看不见页面时按这个顺序查

先看docker ps是否运行→docker logs是否启动报错→宿主端口是否冲突→端口映射是否写反→访问地址是否正确。容器Exited不一定是Docker坏了，可能主进程已完成或启动失败。

自测与答案

题目：同一镜像能同时运行两份Nginx吗？答案：可以，但容器名不同，宿主机对外映射端口不能冲突，例如第二份用8089映射内部80。

完成标准：能不查笔记解释镜像、容器、进程、宿主端口和容器端口。
