## 二、核心概念

### 2.1 串的基本概念

- **串**：零个或多个字符组成的有限序列
- **空串 `""`**、**空格串 `"   "`**、**子串**、**主串**
- **串相等**：长度相同且对应位置字符相同

### 2.2 串的��储结构

| 存储方式 | 特点 |
|----------|------|
| 定长顺序存储 | 类似静态数组，下标 0 弃用或存长度 |
| 堆分配存储 | 动态分配，类似动态数组 |
| 链式存储 | 每个结点存 1 个或多个字符（块链） |

### 2.3 基本操作时间复杂度

| 操作 | 时间复杂度 |
|------|-----------|
| 求子串 | O(m)（m 为子串长度） |
| 比较 | O(min(n,m)) |
| 定位（朴素模式匹配） | **O(nm)** |
| 定位（KMP） | **O(n+m)** |

## 三、朴素模式匹配

主串指针 i、子串指针 j 同步推进，失配时 i 回退到 `i-j+2`，j 重置为 1。最坏情况 `O(nm)`。

---

## 四、KMP 算法 ★★★★★

### 4.1 核心思想

**主串指针 i 永不回退**，子串指针 j 根据 next 数组动态调整。

### 4.2 next 数组含义 ★★★★

`next[j]` = 当子串第 j 个字符失配时，j 应回退到的**下一比较位置**。

等价于：`P[1..next[j]] = P[j-next[j]+1 .. j-1]`，即 j 之前的最长相等前后缀长度 + 1。

### 4.3 手算 next 数组（王道版）★

约定 `next[1] = 0`，然后对 j ≥ 2：
1. 看子串第 j 个字符之前的串 `P[1..j-1]`
2. 求这个串的**最长相等前后缀**长度 L
3. `next[j] = L + 1`

**例子**：`T = "abaababa"`

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| T[j] | a | b | a | a | b | a | b | a |
| 最长相等前后缀 | - | 0 | 1 | 1 | 2 | 3 | 2 | 2 |
| next[j] | 0 | 1 | 2 | 2 | 3 | 4 | 3 | 3 |

j=8 时，前面 "ababab" 最长相等前后缀 = "ab"，长度 2，所以 next[8] = 3。

### 4.4 nextval 数组（优化版）★

若 `P[j] == P[next[j]]`，则失配时 next[j] 仍可能再失配，**递归地**把 next[j] 替换为 next[next[j]]。

**计算步骤**：
1. `nextval[1] = 0`
2. 对 j ≥ 2：若 `P[j] ≠ P[next[j]]`，则 `nextval[j] = next[j]`；否则 `nextval[j] = nextval[next[j]]`

**接上例求 nextval**：

| j | 1 | 2 | 3 | 4 | 5 | 6 | 7 | 8 |
|---|---|---|---|---|---|---|---|---|
| P[j] | a | b | a | a | b | a | b | a |
| next | 0 | 1 | 2 | 2 | 3 | 4 | 3 | 3 |
| nextval | 0 | 1 | 0 | 2 | 1 | 0 | 3 | 0 |

说明：j=3 时 `P[3]=a = P[next[3]]=P[2]=b` 的 nextval，递归取 nextval[1]=0。

## 五、关键代码 ★★★★★

### 5.1 求 next 数组

```c
// 约定 T[1..T[0]] 存串，T[0] 存长度
void GetNext(char T[], int next[]) {
    int j = 1, k = 0;
    next[1] = 0;
    while (j < T[0]) {                // 还没到串尾
        if (k == 0 || T[j] == T[k]) {
            j++; k++;
            next[j] = k;
        } else {
            k = next[k];              // k 回退
        }
    }
}
```

### 5.2 KMP 匹配

```c
int KMP(char S[], char T[], int next[]) {
    int i = 1, j = 1;
    while (i <= S[0] && j <= T[0]) {
        if (j == 0 || S[i] == T[j]) {
            i++; j++;                 // 继续匹配
        } else {
            j = next[j];              // j 回退，i 不变
        }
    }
    if (j > T[0]) return i - T[0];    // 匹配成功，返回起始位置
    return 0;                          // 匹配失败
}
```

### 5.3 求 nextval 数组

```c
void GetNextval(char T[], int nextval[]) {
    int j = 1, k = 0;
    nextval[1] = 0;
    while (j < T[0]) {
        if (k == 0 || T[j] == T[k]) {
            j++; k++;
            if (T[j] == T[k]) nextval[j] = nextval[k];
            else nextval[j] = k;
        } else {
            k = nextval[k];
        }
    }
}
```

## 六、真题套路

### 套路 A：手算 next 数组
- 先把 next[1] = 0 写上
- 然后**看当前位置的前面串**，用最长的"前缀=后缀"长度+1 填入

### 套路 B：手算 nextval 数组
- 关键：当前位置字符 == next 位置的字符 → 递归跳 nextval

### 套路 C：KMP 匹配过程
- 主串不回退是核心
- 失配时 j ���退到 next[j]，i 保持
- 当 j 回退到 0 时，i++、j++ 继续

### 套路 D：KMP 时间复杂度证明
- get_next O(m)
- kmp_match O(n)
- 总 O(n+m)
