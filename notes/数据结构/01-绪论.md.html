## 二、核心概念

### 1.1 基本概念表

| 概念 | 定义 | 举例 |
|------|------|------|
| 数据 (Data) | 信息的载体，能输入计算机被处理 | 数字、字符、图像 |
| 数据元素 | 数据的基本单位 | 一个学生记录 |
| 数据项 | 数据元素的不可分割最小单位 | 学号、姓名 |
| 数据对象 | 性质相同的数据元素的集合 | 所有学生记录 |
| 数据结构 | 数据元素 + 元素之间的关系 | 线性表、树、图 |

### 1.2 数据结构三要素

- **逻辑结构**：元素之间的逻辑关系（与存储无关）
  - 集合、线性、树、图（网状）四类
- **存储结构（物理结构）**：数据结构在计算机中的表示
  - 顺序存储、链式存储、索引存储、散列存储
- **数据的运算**：针对逻辑结构定义，针对存储结构实现

> ⚠ **易错**：逻辑结构独立于存储结构。同一种逻辑结构可以有不同的存储结构（线性表→顺序表/链表），同一种存储结构也可承载不同逻辑结构（数组→可实现线性表/完全二叉树/邻接矩阵）。

### 1.3 算法的五特性

- **有穷性**：执行有限步后终止
- **确定性**：相同输入→相同输出，无歧义
- **可行性**：基本操作可通过已实现基本运算执行有限次实现
- **输入**：零个或多个输入
- **输出**：一个或多个输出

### 1.4 好算法的特性

- 正确性、可读性、健壮性
- 高效率、低存储量

## 三、关键算法 ★★★★

### 3.1 时间复杂度计算步骤

1. 找循环中**最深层循环**的语句
2. 计算该语句的执行次数
3. 取最高阶项，忽略系数

### 3.2 两条规则

- **加法规则（顺序）**：
  `T(n) = T1(n) + T2(n) = O(f(n)) + O(g(n)) = O(max(f(n), g(n)))`
- **乘法规则（循环嵌套）**：
  `T(n) = T1(n) × T2(n) = O(f(n) × g(n))`

### 3.3 常见复杂度档次

| 复杂度 | 名称 | 备注 |
|--------|------|------|
| O(1) | 常数阶 | 最优 |
| O(log₂n) | 对数阶 | 折半查找 |
| O(n) | 线性阶 | 顺序遍历 |
| O(n log n) | 线性对数阶 | 快排、归并、堆排 |
| O(n²) | 平方阶 | 冒泡、直接插入 |
| O(n³) | 立方阶 | 朴素矩阵乘法 |
| O(2ⁿ) | 指数阶 | 递归斐波那契（最坏） |
| O(n!) | 阶乘阶 | 旅行商暴力解 |

**从优到劣排序**：
O(1) < O(log₂n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)

### 3.4 空间复杂度

- 算法所需额外存储空间 `S(n) = O(g(n))`
- **递归调用栈深度也要计入**

> ⚠ 递归算法空间复杂度 = 递归深度，如快排递归深度 O(log n) ~ O(n)

### 3.5 三种 T(n) 比较

- **最坏时间复杂度**：必须考虑，几乎都用这个
- **平均时间复杂度**：所有输入按概率平均
- **最好时间复杂度**：几乎不考，了解

## 四、真题套路

### 套路 A：判断 T(n) 阶数
```c
// 例：求下面代码的时间复杂度
int i = 1;
while (i <= n) {
    i = i * 2;   // i 翻倍
}
// T(n) = O(log₂n)，因为 i 从 1 加倍到 n，需要 log₂n 次
```

### 套路 B：循环嵌套
```c
for (i = 0; i < n; i++)          // n
    for (j = 0; j < n; j++)      // n
        k++;                       // 1
// T(n) = n × n = O(n²)
```

### 套路 C：递归 + 复杂度
```c
// 斐波那契
int Fib(int n) {
    if (n < 2) return n;
    return Fib(n-1) + Fib(n-2);
}
// T(n) = O(2ⁿ)，空间（递归栈）= O(n)
```

## 六、自测题

1. **选择题**：数据结构中，与存储结构无关的是？
   - A. 顺序表  B. 链表  C. 索引表  D. 栈
   - **答案**：D（栈是逻辑结构，与存储无关）

2. **计算题**：语句 `x++;` 在下面代码中执行次数为？
   ```c
   for (i = 0; i < n; i++)
       for (j = 0; j < i; j++)
           x++;
   ```
   - **答案**：n(n-1)/2 次 → O(n²)
