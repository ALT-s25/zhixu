二、核心概念

2.1 线性表定义

由 n (n≥0) 个相同类型数据元素组成的有限序列。

  • 除首尾元素外，每个元素有唯一前驱和后继
  • 逻辑特性：一对一关系

2.2 顺序表 ★★

存储结构：

  • 用一段连续的内存依次存放元素
  • 支持随机访问（按下标 O(1) 访问）
  • 存储密度高（=1），但插入/删除需移动大量元素

基本操作时间复杂度：

操作 时间复杂度 说明
按下标访问 O(1) 随机存取
按值查找 O(n) 顺序扫描
插入/删除 O(n) 平均移动 n/2 个元素

动态顺序表扩容：

  • 申请更大数组（一般 2 倍），复制旧元素，释放旧数组
  • 均摊时间复杂度：插入为 O(1)（均摊）

⚠ 易错："第 i 个位置插入"含义区分

  • 王道：位序 i，合法范围 1 ≤ i ≤ n+1
  • 实际代码：下标 i-1，合法范围 0 ≤ i-1 ≤ n

2.3 链表 ★★★★

单链表

  • 每个结点：data | next
  • 带头结点（推荐）：方便统一操作第一个结点，统一判空条件 L->next == NULL
  • 不带头结点：第一个结点的处理需特殊代码

双链表

  • 结点：prior | data | next
  • 可双向遍历，删除/查找前驱 O(1)

循环链表

  • 循环单链表：尾结点 next 指向头结点
  • 循环双链表：头结点 prior 指向尾结点，尾结点 next 指向头结点

静态链表

  • 用数组模拟链表，游标 next 存下一结点下标
  • 考研较少考，了解即可

基本操作时间复杂度

操作 单链表 双链表
头插/头删 O(1) O(1)
尾插/尾删（带尾指针） O(1) O(1)
按位序查找 O(n) O(n)
按值查找 O(n) O(n)
已知结点位置插入/删除 O(n) 找前驱 O(1)

2.4 顺序表 vs 链表 ★★★

维度 顺序表 链表
存储空间 连续 可离散
随机访问 ✓ O(1) ✗ O(n)
插入删除 O(n) 移动元素 O(1) 改指针（已知位置）
存储密度 =1 <1（有指针开销）
空间分配 预先分配，扩缩容 动态分配，按需
适用场景 频繁查找、少增删 频繁增删、规模不可预知

三、关键代码 ★★★★★

3.1 带头单链表结构定义

c
typedef struct LNode {
    int data;
    struct LNode *next;
} LNode, *LinkList;

// 初始化（带头结点）
bool InitList(LinkList &L) {
    L = (LNode*)malloc(sizeof(LNode));
    if (L == NULL) return false;
    L->next = NULL;
    return true;
}

// 判空
bool Empty(LinkList L) {
    return L->next == NULL;
}

3.2 单链表按位序插入

c
// 在第 i 个位置插入元素 e（位序从 1 开始）
bool ListInsert(LinkList &L, int i, int e) {
    if (i < 1) return false;
    LNode *p = L;             // p 指向头结点（从 0 开始走 i-1 步）
    int j = 0;
    while (p != NULL && j < i - 1) {
        p = p->next;
        j++;
    }
    if (p == NULL) return false;
    LNode *s = (LNode*)malloc(sizeof(LNode));
    s->data = e;
    s->next = p->next;
    p->next = s;
    return true;
}

3.3 双链表结构 + 插入

c
typedef struct DNode {
    int data;
    struct DNode *prior, *next;
} DNode, *DLinkList;

// 在 p 结点后插入 s 结点
bool InsertNextDNode(DNode *p, DNode *s) {
    if (p == NULL || s == NULL) return false;
    s->next = p->next;
    if (p->next != NULL) p->next->prior = s;
    s->prior = p;
    p->next = s;
    return true;
}

3.4 两个有序链表合并 ⭐⭐⭐⭐⭐

c
// 将两个升序链表 A、B 合并为一个升序链表 C
LinkList Merge(LinkList A, LinkList B) {
    LNode *pa = A->next, *pb = B->next;
    LinkList C = (LinkList)malloc(sizeof(LNode));
    LNode *pc = C;
    while (pa && pb) {
        if (pa->data <= pb->data) {
            pc->next = pa; pc = pa; pa = pa->next;
        } else {
            pc->next = pb; pc = pb; pb = pb->next;
        }
    }
    pc->next = pa ? pa : pb;     // 接剩余尾
    free(B);                      // B 头结点释放（可选）
    return C;
}

3.5 链表逆置（头插法）⭐⭐⭐⭐

c
// 头插法：将原链表结点逐个按头插法插入新链表
void Reverse(LinkList &L) {
    LNode *p = L->next, *r;
    L->next = NULL;          // 新链表置空
    while (p != NULL) {
        r = p->next;          // 暂存后继
        p->next = L->next;    // 头插
        L->next = p;
        p = r;                // p 前进
    }
}

3.6 链表判环 & 找入口 ⭐⭐⭐⭐

c
// Floyd 判环：快慢指针
bool HasCycle(LinkList L) {
    LNode *slow = L, *fast = L;
    while (fast != NULL && fast->next != NULL) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) return true;   // 相遇则有环
    }
    return false;
}

// 找环入口：相遇后，一个从 head、一个从相遇点，同步走，再次相遇即为入口
LNode* CycleEntry(LinkList L) {
    LNode *slow = L, *fast = L;
    while (fast && fast->next) {
        slow = slow->next;
        fast = fast->next->next;
        if (slow == fast) {
            LNode *p = L;
            while (p != slow) { p = p->next; slow = slow->next; }
            return p;
        }
    }
    return NULL;
}

3.7 删除所有值为 x 的结点

c
// 头结点技巧：避免删头结点的特殊情况
void DeleteX(LinkList &L, int x) {
    LNode *p = L->next, *pre = L;     // pre 指向 p 的前驱
    while (p != NULL) {
        if (p->data == x) {
            pre->next = p->next;
            free(p);
            p = pre->next;
        } else {
            pre = p;
            p = p->next;
        }
    }
}

四、真题套路

套路 A：两链表合并

  • 必背模板：3.4
  • 变形：合并到 A 中（节省空间）、合并为降序

套路 B：链表逆置

  • 头插法（O(n) 时间，O(1) 空间）
  • 三指针原地翻转（类似）
  • 局部逆置：m 到 n 区间逆置

套路 C：判环 + 找入口

  • 快慢指针 Floyd
  • 求环长度：相遇后继续走一圈

套路 D：删除特定值结点

  • 头结点技巧处理边界
  • 双指针法：pre 跟踪前驱

💡 链表题统一心法：先画图 → 找临界点（头/尾/中点）→ 写代码 → 验证边界 王道的链表真题 90% 都是这 4 个套路的变形。

六、自测题

  1. 选择：n 个结点的单链表，访问第 i 个结点的时间复杂度是？

    • A. O(1) B. O(log n) C. O(n) D. O(n²)
    • 答案：C

  2. 应用题：已知 L 是带头结点的单链表，写算法删除所有值为偶数的结点。

    • 提示：复用 3.7 模板，x 改为 x % 2 == 0

  3. 算法题：判断两个无环单链表是否相交（设两链表均无环）。

    • 思路：遍历两个链表到尾结点，看尾指针是否相同
    • 或：长链表先走 |len1-len2| 步，再同步走，看是否相遇
