二、核心概念

2.1 基本概念

  • 内部排序：在内存中完成
  • 外部排序：内存+外存（归并排序的扩展）
  • 稳定性：关键字相等的两记录，相对位置是否��化
    • 稳定的：直接插入、折半插入、冒泡、归并、基数
    • 不稳定的：希尔、快排、简单选择、堆排

2.2 插入排序

A. 直接插入排序 ★★★

思想：将待排序元素逐个插入到已排序序列的合适位置。

  • 时间：最好 O(n)（已排好），最坏/平均 O(n²)
  • 空间：O(1)
  • 稳定
  • 适用：基本有序或数据量小

B. 折半插入排序

  • 寻找插入位置用折半，但移动仍是 O(n)
  • 时间仍是 O(n²)，仅减少比较次数
  • 稳定

C. 希尔排序 ★★

思想：缩小增量排序（gap 逐渐缩小直到 1）。

  • 时间：最坏 O(n²)，平均 O(n^1.3)
  • 空间：O(1)
  • 不稳定
  • 最后一步 gap=1 等于直接插入排序

2.3 交换排序

A. 冒泡排序 ★★

  • 从后往前（或从前往后）两两比较，逆序则交换，每趟把最大（小）元素冒到末尾
  • 时间：最好 O(n)（加 flag 提前结束），平均/最坏 O(n²)
  • 空间：O(1)，稳定

B. 快速排序 ★★★★★（重点！）

思想：分治：选 pivot（基准）→ 分区为左右两段（左 ≤ pivot ≤ 右）→ 递归两段。

Partition 模板（王道版：Hoare 思想）：

c
int Partition(int A[], int low, int high) {
    int pivot = A[low];              // 用第一个元素作枢轴
    while (low < high) {
        while (low < high && A[high] >= pivot) high--;
        A[low] = A[high];            // 小于枢轴挪到左端
        while (low < high && A[low] <= pivot) low++;
        A[high] = A[low];            // 大于枢轴挪到右端
    }
    A[low] = pivot;
    return low;
}

void QuickSort(int A[], int low, int high) {
    if (low < high) {
        int pos = Partition(A, low, high);
        QuickSort(A, low, pos - 1);
        QuickSort(A, pos + 1, high);
    }
}

性能：

情况 时间 空间（递归栈）
最好（每次平均划分） O(n log n) O(log n)
平均 O(n log n) O(log n)
最坏（已排序 / 逆序） O(n²) O(n)
  • 不稳定
  • 优化：随机选 pivot / 三数取中 / 递归到小区间改插入排序

💡 快排 4 问：① 递归终止条件 low < high ② pivot 选择 ③ 越界判空 ④ 手写第一趟。 王道快排题最爱让你手写第一趟划分结果，记牢！

2.4 选择排序

A. 简单选择排序 ★★

  • 每趟选最小元素放到已排序末尾
  • 时间 O(n²)，空间 O(1)，不稳定

B. 堆排序 ★★★★★（重���！）

大根堆 / 小根堆：

  • 大根堆：父 ≥ 子（升序排序用大根堆）
  • 小根堆：父 ≤ 子（降序排序用小根堆）

思想（升序排序）：

  1. 把序列建成大根堆（建堆 O(n)）
  2. 堆顶（最大元素）与堆尾交换，堆大小 -1
  3. 对新堆顶做下沉（sift down），恢复大根堆
  4. 重复 2-3，直到堆剩 1 个元素

建堆与堆调整复杂度：

  • 建堆：O(n)
  • 每次下沉：O(log n)，共 n-1 次
  • 总时间：O(n log n)
  • 空间：O(1)，不稳定

堆插入：上浮。新元素放末尾，向上与父比较，若大则交换，直到不大于父。

⚠ 注意：堆排序时间复杂度永远是 O(n log n)，与数据无关（不像快排最坏 O(n²)）。

2.5 归并排序 ★★★★

思想：分治：把序列从中间分两半，各自归并排序，再合并两个有序序列。

  • 时间：O(n log n)（所有情况）
  • 空间：O(n)（辅助数组）
  • 稳定
  • 思想：是外部排序的核心

2.6 基数排序 ★★

思想：按关键字的每一位（个、十、百……）进行分配-收集，d 趟完成。

  • 时间：O(d(n+r))，r 为基数
  • 空间：O(r)
  • 稳定
  • 适用：数据范围小但位数少（如 0~999 内��量数据）

三、关键代码

3.1 直接插入排序

c
void InsertSort(int A[], int n) {
    for (int i = 1; i < n; i++) {          // 从 1 开始，前 1 个元素视为已排序
        if (A[i] < A[i-1]) {
            int x = A[i];
            int j;
            for (j = i - 1; j >= 0 && A[j] > x; j--)
                A[j+1] = A[j];              // 后移
            A[j+1] = x;
        }
    }
}

3.2 希尔排序

c
void ShellSort(int A[], int n) {
    for (int dk = n/2; dk >= 1; dk /= 2) {  // 增量序列
        for (int i = dk; i < n; i++) {
            if (A[i] < A[i-dk]) {
                int x = A[i];
                int j;
                for (j = i - dk; j >= 0 && A[j] > x; j -= dk)
                    A[j+dk] = A[j];
                A[j+dk] = x;
            }
        }
    }
}

3.3 冒泡排序（带 flag 优化）

c
void BubbleSort(int A[], int n) {
    bool flag;
    for (int i = 0; i < n - 1; i++) {
        flag = false;
        for (int j = n - 1; j > i; j--) {   // 从后往前冒
            if (A[j-1] > A[j]) {
                swap(A[j-1], A[j]);
                flag = true;
            }
        }
        if (!flag) return;                  // 已排好
    }
}

3.5 堆排序 ⭐⭐⭐⭐⭐

c
// 下沉：将 A[low..high] 中以 low 为根的子树调整为大根堆
void siftDown(int A[], int low, int high) {
    int i = low, j = 2 * i + 1;             // j 是左孩子
    int tmp = A[i];
    while (j <= high) {
        if (j < high && A[j] < A[j+1]) j++;  // 选较大孩子
        if (tmp >= A[j]) break;
        A[i] = A[j];                          // 孩子上移
        i = j;
        j = 2 * i + 1;
    }
    A[i] = tmp;
}

void HeapSort(int A[], int n) {
    // 1. 建堆：从最后一个分支结点开始下沉
    for (int i = n/2 - 1; i >= 0; i--)
        siftDown(A, i, n - 1);
    // 2. 排序：堆顶与堆尾交换，再下沉
    for (int i = n - 1; i > 0; i--) {
        swap(A[0], A[i]);
        siftDown(A, 0, i - 1);
    }
}

3.6 归并排序 ⭐⭐⭐⭐

c
// 合并两个有序子数组 A[low..mid] 和 A[mid+1..high]
void Merge(int A[], int low, int mid, int high) {
    int B[MaxSize];                  // 辅助数组
    for (int k = low; k <= high; k++) B[k] = A[k];
    int i = low, j = mid + 1, k = low;
    while (i <= mid && j <= high) {
        if (B[i] <= B[j]) A[k++] = B[i++];
        else A[k++] = B[j++];
    }
    while (i <= mid) A[k++] = B[i++];
    while (j <= high) A[k++] = B[j++];
}

void MergeSort(int A[], int low, int high) {
    if (low < high) {
        int mid = (low + high) / 2;
        MergeSort(A, low, mid);
        MergeSort(A, mid + 1, high);
        Merge(A, low, mid, high);
    }
}

3.7 基数排序

c
// 假设关键字是 0~999 的整数（d=3 位，r=10）
void RadixSort(int A[], int n) {
    // 10 个桶，每个桶是链表头
    LinkList B[10];
    for (int k = 0; k < 3; k++) {                // 处理个、十、百位
        // 分配
        for (int i = 0; i < 10; i++) B[i] = NULL;
        for (int i = 0; i < n; i++) {
            int digit = (A[i] / (int)pow(10, k)) % 10;
            // 把 A[i] 按 digit 插入 B[digit] 链表尾
        }
        // 收集：依次合并 B[0..9] 回 A
        int idx = 0;
        for (int i = 0; i < 10; i++)
            for (LinkNode *p = B[i]; p; p = p->next)
                A[idx++] = p->data;
    }
}

  • 给出具体反例序列证明不稳定
  • 例：堆排的不稳定：(1, 2, 2) 排序后两个 2 相对位置会变

七、自测题

  1. 手写快排第一趟：对序列 (49, 38, 65, 97, 76, 13, 27, 49) 执行快速排序第一趟，pivot 选第一个。

    • 步骤：49 为 pivot，从右找 < 49 的，13 → A[low]=13；从左找 > 49 的，65 → A[high]=65；...
    • 第一趟结果：(27, 38, 13) 49 (76, 97, 65, 49)

  2. 堆排序：序列 (20, 15, 30, 10, 5)，建大根堆 → (30, 20, 15, 10, 5)

    • 排序过程：
      • 30 与 5 交换 → (5, 20, 15, 10) 30
      • 下沉 → (20, 10, 15, 5) 30
      • 20 与 5 交换 → (5, 10, 15) 20, 30
      • 下沉 → (15, 10, 5) 20, 30
      • 15 与 5 交换 → (5, 10) 15, 20, 30
      • 下沉 → (10, 5) 15, 20, 30
      • 10 与 5 交换 → (5) 10, 15, 20, 30

  3. 稳定性：判断堆排序是否稳定并举例

    • 不稳定
    • 例：(3₁, 2, 3₂) 建堆后 3₂ 上浮到根，与 3₁ 相对位置变化

  4. 场景选择：10 GB 大数据排序用什么？

    • 归并排序（外部排序场景，必须稳定）
