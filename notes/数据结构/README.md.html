🚀 复习路线建议

  1. 第一轮（30 天）：2 倍速刷王道视频，每章配合王道书课后题
  2. 第二轮（15 天）：只看不熟的章节 + 整理错题本
  3. 第三轮（10 天）：9 套必背代码闭卷默写 + 真题 2020-2025
  4. 第四轮（5 天）：全章节概念清单快速回顾

💻 9 套必背代码（上考场前默写）

  1. 链表合并（两个有序链表）
  2. 链表逆置（头插法 / 三指针）
  3. 二叉树遍历（递归 + 非递归，至少会中序）
  4. 层次遍历（队列）
  5. KMP next 数组手算
  6. AVL 4 种调整画图
  7. 快速排序（含 Partition）
  8. 堆排序（建堆 + sift down）
  9. Dijkstra 手算（更新 dist 数组）
