二、核心概念

5.1 树的基本概念

  • 结点的度：子树个数
  • 树的度：所有结点中最大度数
  • 叶子/分支结点：度=0 的结点 / 度≠0 的结点
  • 层次/深度/高度：根为第 1 层；深度从根往下数；高度从叶子往上数
  • 有序树 vs 无序树：子树是否有序
  • 森林：m (m≥0) 棵互不相交树的集合

常考公式：

  • 度为 m 的树，第 i 层最多 m^(i-1) 个结点
  • 高度为 h 的 m 叉树最多 (m^h - 1)/(m - 1) 个结点
  • n 个结点的 m 叉树最小高度 = ⌈log_m(n(m-1)+1)⌉

5.2 二叉树

定义：每个结点至多两棵子树，且子树有左右之分（有序树）。

5 条性质（必背）★★★★

  1. 第 i 层最多 2^(i-1) 个结点 (i≥1)
  2. 深度为 k 的二叉树最多 2^k - 1 个结点 (k≥1)
  3. 对任何二叉树，叶子数 n₀ = 度为 2 的结点数 n₂ + 1
  4. n 个结点的完全二叉树深度 = ⌊log₂n⌋ + 1
  5. 完全二叉树按层编号：i 的双亲为 ⌊i/2⌋，左孩子 2i，右孩子 2i+1

特殊二叉树

  • 满二叉树：深度 k，2^k - 1 个结点
  • 完全二叉树：按层编号与等深满二叉树对应位置相同（叶结点集中在最后两层）
  • 二叉排序树（BST）：左 < 根 < 右
  • 平衡二叉树（AVL）：左右子树深度差 ≤ 1

存储结构

  • 顺序存储：用数组按层编号，仅适合完全二叉树，否则浪费空间
  • 链式存储：
    • 二叉链表：结点 lchild | data | rchild，n 个结点有 n+1 个空链域
    • 三叉链表：加 parent 指针，方便找双亲

三、二叉树遍历 ★★★★★

3.1 三种递归遍历

遍历 顺序
先序 NLR 根 → 左 → 右
中序 LNR 左 → 根 → 右
后序 LRN 左 → 右 → 根

3.2 三种非递归遍历（用栈模拟）

  • 中序非递归：一路向左压栈，到底出栈访问，转右子树
  • 先序非递归：先访问再压栈，转右时换为先访问再入栈、转向左
  • 后序非递归：最复杂，需要标记右子树是否已被访问

3.3 层次遍历（队列实现）

根入队 → 出队访问 → 左右孩子入队 → 循环。

3.4 由遍历序列构造二叉树 ★★★★

  • 必须已知中序 + 任意一种（先序或后序）才能唯一确定
  • 先序 + 中序：先序首元素是根，到中序里切出左右子树���递���
  • 后序 + 中序：后序末元素是根，到中序里切左右子树，递归
  • 层次 + 中序：层次首元素是根

⚠ 易错：先序 + 后序不能唯一确定二叉树。

四、关键代码 ★★★★★

4.1 中序非递归遍历

c
typedef struct BiNode {
    int data;
    struct BiNode *lchild, *rchild;
} BiNode, *BiTree;

void InOrder(BiTree T) {
    InitStack(S); BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {
            Push(S, p);
            p = p->lchild;              // 一路向左压栈
        } else {
            Pop(S, p); visit(p);         // 出栈访问，转右子树
            p = p->rchild;
        }
    }
}

4.2 先序非递归

c
void PreOrder(BiTree T) {
    InitStack(S); BiTree p = T;
    while (p || !StackEmpty(S)) {
        if (p) {
            visit(p);                    // 根
            Push(S, p);
            p = p->lchild;               // 一路向左
        } else {
            Pop(S, p);
            p = p->rchild;               // 转向右子树
        }
    }
}

4.3 后序非递归（用标记）

c
void PostOrder(BiTree T) {
    InitStack(S); BiTree p = T, r = NULL;
    while (p || !StackEmpty(S)) {
        if (p) {
            Push(S, p);
            p = p->lchild;
        } else {
            GetTop(S, p);                // 看栈顶，不弹出
            if (p->rchild && p->rchild != r) {
                p = p->rchild;           // 右子树未访问过
            } else {
                Pop(S, p); visit(p);
                r = p;                   // 标记上次访问
                p = NULL;                // 重置
            }
        }
    }
}

4.4 层次遍历（队列实现）

c
void LevelOrder(BiTree T) {
    InitQueue(Q); EnQueue(Q, T);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, p); visit(p);
        if (p->lchild) EnQueue(Q, p->lchild);
        if (p->rchild) EnQueue(Q, p->rchild);
    }
}

4.5 由先序 + 中序构造二叉树

c
BiTree PreInBuild(int pre[], int in[], int preL, int preR, int inL, int inR) {
    if (preL > preR) return NULL;
    BiTree root = (BiTree)malloc(sizeof(BiNode));
    root->data = pre[preL];              // 先序首元素 = 根
    int k;
    for (k = inL; k <= inR; k++)
        if (in[k] == pre[preL]) break;   // 在中序里定位根
    int leftNum = k - inL;               // 左子树结点数
    root->lchild = PreInBuild(pre, in, preL+1, preL+leftNum, inL, k-1);
    root->rchild = PreInBuild(pre, in, preL+leftNum+1, preR, k+1, inR);
    return root;
}

4.6 中序线索二叉树

c
typedef struct ThreadNode {
    int data;
    struct ThreadNode *lchild, *rchild;
    int ltag, rtag;        // 0=孩子，1=线索
} ThreadNode, *ThreadTree;

ThreadNode *pre = NULL;   // 全局变量：当前访问结点的前驱

void InThread(ThreadNode *p) {
    if (p) {
        InThread(p->lchild);
        if (p->lchild == NULL) {
            p->lchild = pre;
            p->ltag = 1;
        }
        if (pre && pre->rchild == NULL) {
            pre->rchild = p;
            pre->rtag = 1;
        }
        pre = p;
        InThread(p->rchild);
    }
}

// 中序线索遍历（不用栈/递归）
void InOrderThread(ThreadTree T) {
    ThreadNode *p = T;
    while (p) {
        while (p->ltag == 0) p = p->lchild;   // 找最左下
        visit(p);
        while (p->rtag == 1 && p->rchild) {
            p = p->rchild;                     // 沿线索到后继
            visit(p);
        }
        p = p->rchild;                         // 转向右子树
    }
}

五、树、森林

5.1 树的存储

表示法 特点
双亲表示法 数组存结点 + parent 下标，找双亲 O(1)，找孩子 O(n)
孩子表示法 每个结点的孩子用链表串起（邻接表思想）
孩子兄弟表示法（最常用） 结点 firstchild \| data \| nextsibling，用二叉链表实现

5.2 树 → 二叉树转换

  1. 加线：兄弟结点之间加一根线
  2. 抹线：每个结点只保留与第一个孩子的连线，抹掉其他孩子的连线
  3. 旋转：以根为轴心旋转

5.3 森林 → 二叉树

把每棵树分别转为二叉树，再把后一棵二叉树的根当作前一棵根的右孩子。

5.4 遍历对应关系

树/森林遍历 对应二叉树遍历
先根遍历 先序遍历
后根遍历 中序遍历
层次遍历 （无直接对应）

5.5 树转二叉树代码

c
// 树的二叉链表表示
typedef struct CSNode {
    int data;
    struct CSNode *firstchild;    // 第一个孩子
    struct CSNode *nextsibling;   // 下一个兄弟
} CSNode, *CSTree;

// 森林 → 二叉树：F[] 存 m 棵树的根
CSTree ForestToBiTree(CSTree F[], int n) {
    CSTree T = NULL;
    for (int i = n - 1; i >= 0; i--) {   // 从后往前
        F[i]->nextsibling = T;           // 后一棵的根 → 前一棵根的右孩子
        T = F[i];
    }
    return T;
}

���、哈夫曼树 ★★★★

6.1 基本概念

  • 结点的权：赋予结点有意义的数值
  • 路径长度：两结点间路径上的分支数
  • 树的带权路径长度 WPL：所有叶子结点权 × 根到该叶子路径长度 之和

6.2 哈夫曼树（最优二叉树）

WPL 最小的二叉树。

6.3 构造步骤 ★★★

  1. 给定 n 个权值，做 n 棵只有根的二叉树，构成森林 F
  2. 每次从 F 选权值最小的两棵树作新树的左右子树，新树根权 = 左右权之和
  3. 从 F 删去这两棵树，加入新树
  4. 重复直到 F 中只剩一棵树，即为哈夫曼树

哈夫曼树性质：

  • 权越大的叶子离根越近
  • 结点总数 = 2n - 1（无度为 1 的结点）
  • n 个权值构造的哈夫曼树形态不一定唯一，但 WPL 唯一

6.4 哈夫曼编码

  • 左分支写 0，右分支写 1，从根到叶子的路径即编码
  • 是前缀编码（任一编码都不是另一编码的前缀），保证解码无歧义
  • 编码总长度 = WPL

WPL 计算示例：叶子权 {2, 3, 4, 7}

  • (2,3)→5，(4,5)→9，7+(9)=16 → 根=16
  • WPL = 7×1 + 4×2 + 3×3 + 2×3 = 30

七、真题套路

套路 A：二叉树遍历结果推演

  • 给定一棵树，遍历得到序列
  • 给出两个序列，求树结构

套路 B：结点个数计算

  • 利用性质 3：n₀ = n₂ + 1
  • 利用性质 4：完全二叉树深度
  • 给定 n 个结点，求 n₀、n₁、n₂

套路 C：哈夫曼树 + WPL

  • 手算哈夫曼树
  • WPL 计算 = 编码总长

套路 D：线索二叉树

  • 给遍历序列画线索二叉树
  • 求前驱/后继

  • 树的度、深度、高度定义
  • 二叉树 5 条性质（尤其 n₀ = n₂ + 1）
  • 完全二叉树深度公式 ⌊log₂n⌋ + 1
  • 二叉链表空链域数 = n+1
  • 三种递归 + 三种非递归 + 层次遍历

九、自测题

  1. 选择：一棵完全二叉树有 1000 个结点，其高度为？

    • 答案：⌊log₂1000⌋ + 1 = 9 + 1 = 10

  2. 应用题：画出 ABC##DE#G##F###（# 表示空）对应的二叉树，并写出先序、中序、后序。

    • 提示：按前序遍历建树规则递归

  3. 计算：叶子权 {5, 6, 2, 9, 7} 的哈夫曼树 WPL = ?

    • 步骤：5+2=7，(6,7)→13，7+13=20，9+20=29 → 根=29
    • WPL = 9×2 + 5×3 + 6×3 + 2×3 + 7×2 = 18+15+18+6+14 = 71
