二、核心概念

3.1 栈

定义：LIFO（后进先出），只允许在一端（栈顶）进行插入和删除。

  • 顺序栈：用数组实现，栈顶指针 top 指向栈顶元素
  • 链栈：用单链表实现，栈顶在链表头部，无头结点写法更常见

出栈序列数（卡特兰数） ★

n 个不同元素依次入栈，合法的出栈序列数 = 卡特兰数 Cₙ = C(2n,n)/(n+1)

n 1 2 3 4
Cₙ 1 2 5 14

3.2 队列

定义：FIFO（先进先出），一端入队（队尾），另一端出队（队首）。

循环队列（顺序队列）★★★

  • 解决假溢出问题：逻辑上成环，物理上仍是数组
  • 判空/判满两种方案：
    1. 牺牲一个单元：队满 (Q.rear + 1) % MaxSize == Q.front，队空 Q.front == Q.rear
    2. 增设 size 字段：size == 0 为空，size == MaxSize 为满
  • 队列长度：len = (rear - front + MaxSize) % MaxSize
  • 王道默认指向"队尾元素的下一个位置"，入队先存再 rear = (rear+1) % MaxSize

链队：带头尾指针的单链表，头出尾入，O(1)。

3.3 双端队列

两端都允许入队/出队，是判断"合法输出序列"的常考载体。

三、关键代码

3.1 顺序栈

c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int top;        // 栈顶指针，指向栈顶元素
} SqStack;

// 初始化
void InitStack(SqStack &S) { S.top = -1; }

// 判空
bool StackEmpty(SqStack S) { return S.top == -1; }

// 入栈（指针先加再存）
bool Push(SqStack &S, int x) {
    if (S.top == MaxSize - 1) return false;
    S.data[++S.top] = x;
    return true;
}

// 出栈（先取再减）
bool Pop(SqStack &S, int &x) {
    if (S.top == -1) return false;
    x = S.data[S.top--];
    return true;
}

// 取栈顶元素
bool GetTop(SqStack S, int &x) {
    if (S.top == -1) return false;
    x = S.data[S.top];
    return true;
}

3.2 链栈（不带头结点，栈顶=头指针）

c
typedef struct LinkNode {
    int data;
    struct LinkNode *next;
} LinkNode, *LinkStack;

bool Push(LinkStack &S, int x) {
    LinkNode *p = (LinkNode*)malloc(sizeof(LinkNode));
    p->data = x;
    p->next = S;       // 新结点插到表头
    S = p;
    return true;
}

bool Pop(LinkStack &S, int &x) {
    if (S == NULL) return false;
    LinkNode *p = S;
    x = p->data;
    S = S->next;
    free(p);
    return true;
}

3.3 循环队列（牺牲一个单元判满）

c
#define MaxSize 50
typedef struct {
    int data[MaxSize];
    int front, rear;       // front 队首，rear 指向队尾的下一个
} SqQueue;

void InitQueue(SqQueue &Q) { Q.front = Q.rear = 0; }

bool QueueEmpty(SqQueue Q) { return Q.front == Q.rear; }

bool EnQueue(SqQueue &Q, int x) {
    if ((Q.rear + 1) % MaxSize == Q.front) return false;
    Q.data[Q.rear] = x;
    Q.rear = (Q.rear + 1) % MaxSize;
    return true;
}

bool DeQueue(SqQueue &Q, int &x) {
    if (Q.front == Q.rear) return false;
    x = Q.data[Q.front];
    Q.front = (Q.front + 1) % MaxSize;
    return true;
}

四、应用 ★★★★

4.1 括号匹配

  • 扫到左括号入栈
  • 扫到右括号看是否与栈顶匹配，否则非法
  • 最终栈空才合法

4.2 表达式求值（重点）

三种表达式：

  • 中缀：操作符在操作数中间，a + b
  • 前缀（波兰式）：操作符在前，+ a b
  • 后缀（逆波兰式）：操作符在后，a b +

中缀 → 后缀（手算）：

  1. 按运算顺序完全加括号
  2. 把运算符移到对应括号外侧
  3. 去掉括号

中缀 → 后缀（机算：栈操作）★★★★★

  1. 遇到操作数 → 直接输出
  2. 遇到左括号 → 入栈
  3. 遇到右括号 → 弹出栈顶运算符直到遇到左括号（括号弹出但不输出）
  4. 遇到运算符：弹出栈顶优先级 ≥ 当前运算符的所有运算符输出，再把当前运算符入栈
  5. 扫描完毕 → 弹出栈中剩余运算符

⚠ 优先级：乘除 > 加减。左括号在栈外优先级最高（必须入栈），在栈内优先级最低（必须等���右括号才弹）。

后缀表达式求值（机算）：

  1. 从左到右扫：操作数入栈；运算符则弹出栈顶两元素运算，结果入栈
  2. 栈底元素即为结果

4.3 递归 → 非递归

用栈模拟递归调用栈，保存每次调用的参数与返回地址。

4.4 层次遍历二叉树（队列实现）

队列实现：根入队 → 出队访问 → 左右孩子入队 → 循环。

五、真题套路

套路 A：合法出栈序列判断

  • 用栈模拟入栈，依次看每个出栈元素是否等于栈顶
  • 若不等就继续入栈直到能弹，所有元素都能匹配则合法

套路 B：中缀 → 后缀（机算）

  • 按上面 5 步规则
  • 必考手算

套路 C：循环队列判空判满

  • 题目要先确认用哪种方案
  • 队列长度计算公式

套路 D：双端队列输出序列

  • 进队出队序列是否合法的判断
  • 实质仍是栈/队列的模拟

六、概念清单（必背）

  • 栈/队列定义（LIFO/FIFO）
  • 卡特兰数公式 Cₙ = C(2n,n)/(n+1)
  • 循环队列的两种判空判满方案
  • 三种表达式转换手算 + 机算
  • 栈优先级 vs 栈内优先级（括号特例）
  • 栈/队列 5 大应用：括号匹配、表达式、递归消除、层次遍历、DFS/BFS

七、自测题

  1. 选择：循环队列用牺牲一个单元方案，front=4, rear=2, MaxSize=6，队长为？

    • 答案：(2 - 4 + 6) % 6 = 4

  2. 应用：将中缀 a + b * c - d / e 转为后缀。

    • 手算：加括号 ((a + (b*c)) - (d/e)) → a b c * + d e / -
    • 即后缀 a b c * + d e / -

  3. 代码题：用栈实现队列（用两个栈 in、out）。

    • 入队 → push(in)
    • 出队 → 若 out 空，先把 in 全部倒入 out，再 pop(out)
    • 复杂度均摊 O(1)
