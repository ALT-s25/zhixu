## 二、核心概念

### 6.1 图的基本概念

**定义**：图 G = (V, E)，V 顶点集，E 边集。

#### 分类

| 分类 | 细分 | 特征 |
|------|------|------|
| 有向图 vs 无向图 | 边是否有方向 | 用 `<v,w>` vs `(v,w)` 表示 |
| 简单图 vs 多重图 | 是否存在重复边 | 考研考简单图 |
| 完全图 | 任意两顶点都有边 | 无向完全图 n(n-1)/2，有向 n(n-1) |
| 稀疏图 vs 稠密图 | `|E| < |V|log|V|` 一般为稀疏 | 反过来是稠密 |
| 网（带权图） | 边上带权 | 最短路径问题载体 |

#### 度数

- **无向图**：TD(v) = 度，`∑ TD(v) = 2|E|`
- **有向图**：出度 OD(v) + 入度 ID(v) = 度，`∑ OD = ∑ ID = |E|`

#### 路径与连通

- **路径长度**：路径上边数 / 权值之和（带权图）
- **回路**：起点=终点的路径
- **简单路径**：顶点不重复出现的路径
- **连通（无向）**：两顶点间有路径。极大连通子图 = **连通分量**
- **强连通（有向）**：任意两顶点双向可达。极大强连通子图 = **强连通分量**

#### 生成树

连通图的**极小连通子图**，包含 n 顶点 + n-1 边。
**生成森林**：非连通图的连通分量的生成树集合。

#### 有向树

一个有向图，**恰有一��顶点入度为 0，其余入度为 1**。

## 三、图的存储 ★★★★★

### 3.1 邻接矩阵

二维数组 `A[i][j]` 表示边 (i,j) 的信息（无权 1/0；有权即权值，∞ 表示无）。

| 维度 | 说明 |
|------|------|
| 空间 | O(V²)，适合稠密图 |
| 判边 | O(1) |
| 求度 | 无向图：行/列求和 O(V)；有向图：行=出度，列=入度 |
| 对称性 | 无向图的矩阵是对称的 |

### 3.2 邻接表

顶点数组 + 每个顶点挂一条边链表。

| 维度 | 说明 |
|------|------|
| 空间 | 无向图 O(V+2E)，有向图 O(V+E)，适合稀疏图 |
| 判边 | O(度数) |
| 求度 | 无向图不方便（要遍历所有链表）；有向图出度=链表长，入度需建逆邻接表 |

### 3.3 十字链表（仅用于有向图）

边结点同时挂在起点链表（出边）和终点链表（入边）上。求入度/出度都方便。

### 3.4 邻接多重表（仅用于无向图）

每条边只对应一个边结点，同时出现在两个顶点的链表中。删除边方便。

> 💡 **选择建议**：稠密图 → 邻接矩阵；稀疏图 → 邻接表；考代码大题 → **邻接表**（最适）。

typedef struct ArcNode {        // 边表结点

    AdjList vertices;

### 4.2 邻接矩阵 DFS（递归）

```c
bool visited[MaxVertexNum];

void DFS(MGraph G, int v) {
    visit(v);
    visited[v] = true;
    for (int w = 0; w < G.vexnum; w++)
        if (G.edge[v][w] != 0 && !visited[w])
            DFS(G, w);
}

// 主调：对所有未访问顶点调一次
void DFSTraverse(MGraph G) {
    for (int i = 0; i < G.vexnum; i++) visited[i] = false;
    for (int i = 0; i < G.vexnum; i++)
        if (!visited[i]) DFS(G, i);
}
```

### 4.3 邻接矩阵 BFS（队列）

```c
void BFS(MGraph G, int v) {
    visit(v); visited[v] = true;
    EnQueue(Q, v);
    while (!QueueEmpty(Q)) {
        DeQueue(Q, v);
        for (int w = 0; w < G.vexnum; w++) {
            if (!visited[w] && G.edge[v][w] != 0) {
                visit(w);
                visited[w] = true;
                EnQueue(Q, w);
            }
        }
    }
}
```

### 4.4 Prim 算法（O(V²)）

```c
void Prim(MGraph G, int v0) {
    // lowcost[i] = 当前最小边权；closest[i] = 该边对应的起点
    int lowcost[MaxVertexNum], closest[MaxVertexNum];
    for (int i = 0; i < G.vexnum; i++) {
        lowcost[i] = G.edge[v0][i];
        closest[i] = v0;
    }
    lowcost[v0] = 0;          // v0 已加入 U

    for (int i = 1; i < G.vexnum; i++) {
        int min = INF, k = -1;
        for (int j = 0; j < G.vexnum; j++)
            if (lowcost[j] != 0 && lowcost[j] < min) {
                min = lowcost[j]; k = j;
            }
        if (k == -1) break;
        printf("(%d, %d)\n", closest[k], k);
        lowcost[k] = 0;       // k 加入 U
        for (int j = 0; j < G.vexnum; j++)
            if (lowcost[j] != 0 && G.edge[k][j] < lowcost[j]) {
                lowcost[j] = G.edge[k][j];
                closest[j] = k;
            }
    }
}
```

### 4.5 Kruskal 算法 + 并查集

```c
// 并查集
int parent[MaxVertexNum];

int Find(int x) {
    while (parent[x] != x) x = parent[x];
    return x;
}

void Union(int x, int y) {
    int rx = Find(x), ry = Find(y);
    if (rx != ry) parent[rx] = ry;
}

// Kruskal
typedef struct { int u, v, w; } Edge;

void Kruskal(ALGraph G, Edge E[], int e) {
    for (int i = 0; i < G.vexnum; i++) parent[i] = i;
    Sort(E, e);              // 边按权值升序
    int cnt = 0;
    for (int i = 0; i < e; i++) {
        int fu = Find(E[i].u), fv = Find(E[i].v);
        if (fu != fv) {
            Union(fu, fv);
            printf("(%d, %d) %d\n", E[i].u, E[i].v, E[i].w);
            if (++cnt == G.vexnum - 1) break;
        }
    }
}
```

### 4.6 Dijkstra（单源最短路径）

```c
// dist[v] = 当前 v 到源点 v0 的最短距离；path[v] = 路径上前驱
void Dijkstra(MGraph G, int v0) {
    bool final[MaxVertexNum];          // final[v] = true 表示已确定
    for (int v = 0; v < G.vexnum; v++) {
        dist[v] = G.edge[v0][v];
        final[v] = false;
        path[v] = (dist[v] < INF) ? v0 : -1;
    }
    dist[v0] = 0; final[v0] = true;

    for (int i = 1; i < G.vexnum; i++) {
        int min = INF, v = -1;
        for (int w = 0; w < G.vexnum; w++)
            if (!final[w] && dist[w] < min) { v = w; min = dist[w]; }
        if (v == -1) break;
        final[v] = true;
        for (int w = 0; w < G.vexnum; w++)
            if (!final[w] && dist[v] + G.edge[v][w] < dist[w]) {
                dist[w] = dist[v] + G.edge[v][w];
                path[w] = v;
            }
    }
}
```

void Floyd(MGraph G) {

    for (int k = 0; k < G.vexnum; k++)

            for (int j = 0; j < G.vexnum; j++)
                if (A[i][k] + A[k][j] < A[i][j]) {
                    A[i][j] = A[i][k] + A[k][j];
                    path[i][j] = k;
                }
}

## 五、关键算法 ★★★★

### 5.1 最小生成树

**定义**：带权连通无向图中，**边权之和最小**的生成树（可能不唯一）。

| 算法 | 思想 | 复杂度 | 适合 |
|------|------|--------|------|
| Prim | 点视角：选当前 U 到 V-U 最小边 | O(V²) | 稠密图 |
| Kruskal | 边视角：按权升序 + 并查集 | O(E log E) | 稀疏图 |

> **核心区别**：Prim 从点扩张（贪心当前点集中最小边），Kruskal 从边贪心（必须用到并查集）。

### 5.2 最短路径

#### Dijkstra（单源最短路径）★★★★★
- **无负权图**上一个顶点到其他所有顶点的最短路径，O(V²)
- **思想**：集合 S（已确定最短路径）+ 集合 V-S。每次选 dist 最小的 u 加入 S，更新 u 的所有邻居

**手算步骤**：
1. 写出各顶点到源点的当前距离 dist[]
2. 选未确定集合中 dist 最小的顶点加入确定集
3. 以该顶点为中转，更新其邻居的 dist = min(dist, dist[该点] + 边权)
4. 重复直到所有顶点确定

> ⚠ **易错**：Dijkstra **不适用负权图**，负权用 Bellman-Ford 或 SPFA。

#### Floyd（任意两点间最短路径）
- 动态规划，三重循环，O(V³)
- 可处理负权但不能有负权回路

### 5.3 拓扑排序 ★★★

**应用**：**AOV 网**（顶点表示活动、边表示先后关系）上，输出一个满足所有先后关系的线性序列。

**算法**：
1. 选一个**入度为 0**的顶点输出
2. 删除该顶点及其所有出边（邻居入度 -1）
3. 重复 1-2，直到图为空或不存在入度为 0 顶点（后者则有环）

**复杂度**：O(V+E)。**拓扑序列可能不唯一**。

> 💡 拓扑排序的两个用途：① 判断有向图是否有环；② 求 AOV 网的合理序列。

### 5.4 关键路径（AOE 网）★★

- **AOE 网**：顶点表示**事件**、边表示**活动**、边上权表示活动持续时间
- **关键活动**：最早开始时间 = 最迟开始时间的活动，组成**关键路径**
- **关键路径长度 = 项目最短完成时间**

| 量 | 公式 | 方向 |
|----|------|------|
| 事件最早发生时间 ve(k) | `ve(k) = max{ve(j) + 权<j,k>}` | 从前往后（拓扑序） |
| 事件最迟发生时间 vl(k) | `vl(k) = min{vl(j) - 权<k,j>}` | 从后往前（逆拓扑序） |
| 活动最早开始时间 e(i) | `e(i) = ve(j)` | 边 `<j,k>` 的最早开始 |
| 活动最迟开始时间 l(i) | `l(i) = vl(k) - 权<j,k>` | 边 `<j,k>` 的最迟开始 |
| 关键活动判定 | `e(i) == l(i)` | 两者相等即关键 |
