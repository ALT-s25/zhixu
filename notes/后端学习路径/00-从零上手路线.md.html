后端学习路径：每一段都做出一个可验证的小成果

约 5 分钟阅读你的知识，慢慢成林

这条路径根据你提供的课程资料安排。目标是用尽量少的重复学习打通 Java → SQL → HTTP接口 → 数据持久化；学时取决于练习反馈，不承诺几天“精通”。默认先读速学总结，再运行例子，卡住时查原课件。

  • Java基础：26章速学总结
  • MySQL：9章SQL学习总结
  • Spring Boot：12章学习总结

先认清四种材料

材料 用来做什么 不用怎么做
速学总结 建立概念、类比、操作顺序、排错与自测 不把“看完”当成掌握

第一段：让代码按你的想法运行

读Java速学01—06：环境、变量、IDEA、流程控制、数组、方法。每天选一小节，用30—60分钟完成一个“预测→运行→改写→解释”的循环；时间仅是安排建议，卡住就拆小任务。

成果：命令行成绩统计器，输入一组成绩，输出人数、平均分、最高分；对空输入与非法输入给出明确反馈。

过关：不用复制能写循环与方法；知道数组越界、空指针和编译错误分别是什么。进制细节与工具快捷键先按需查。

第二段：用对象组织小项目

读Java07—09，接学生管理系统09a；再读10—15理解继承、接口、多态、异常和常用API。类像模板、对象像实例；业务规则由代码维护，不是把所有字段公开就叫面向对象。

成果：学生管理系统：添加、查询、修改、删除，编号不重复、找不到时明确提示。

过关：能画出菜单→业务方法→数据的调用关系；新增一个字段时知道哪些地方需要改。此阶段暂不要求保存到磁盘。

第三段：从内存记录走向文件保存

读Java18—22（集合、泛型、Map、IO），再读24中的Lambda与Stream。16—17多线程、23网络、25反射可放到后面按需补；基础内容仍完整保留，没有删掉。

成果：把第二段系统升级为集合存储和文件持久化，退出再启动仍能读到数据。

过关：能区分内存对象与文件内容；测试重复编号、空文件、坏数据、中文编码，不让失败保存破坏原数据。原提纲的StudentApp可作对照，但先自己写。

第四段：让数据库管理结构化数据

读MySQL01—07，再做09综合练习；08先关注事务，其他高级机制可以后学。SQL不是Java方法名的另一种写法，要先说清“输出一行代表什么”。

成果：学生、课程、选课三表；查询学生所选课程、没有选课的学生、每门课人数。然后回到原路径要求的五表电商练习扩展。

过关：能说明主键、外键、INNER/LEFT JOIN和COUNT(*)/COUNT(列)差异；用有匹配、无匹配、一对多三类数据验证。

第五段：补上框架前置概念，再做接口

进入Spring Boot前需要知道：Maven的pom.xml管理项目与依赖；依赖不是复制代码，而是让编译和运行能找到库。HTTP由方法、路径、请求头、请求体和响应组成；JSON是一种数据格式，不是Java对象本身。注解是元数据，框架读取它后才能产生行为。

Spring容器可类比登记并组装组件的管理者，依赖注入把需要的组件交给使用者；边界是容器不会自动发现任意类，扫描与注册规则仍要满足。先理解“谁创建对象、谁把对象交给谁”，再背注解名。

读Spring Boot01—04：Hello接口→参数与错误响应→MyBatis→环境与测试；接口文档可在06补上，05原理放到跑通项目之后。

成果：学生管理HTTP接口，支持CRUD、分页、校验、统一异常、MySQL持久化。前端不是必要前提，先用浏览器与接口工具验证。

过关：能按HTTP状态与异常链排查问题；重启后数据保留；测试不修改自己的重要数据库。

第六段：完善权限、缓存和运行观察

读Spring Boot06、08、09中的缓存入门、权限和监控。先做小范围，再深入专项课程。把身份认证与授权分开，区分缓存不存在、数据库不存在、远程调用失败。

成果：普通用户只能操作自己的记录；管理员能管理授权范围内数据；查询缓存可失效；能够从日志定位一次失败请求。

过关：用户A不能借改URL访问用户B的数据；缓存丢失不导致业务记录永久丢失。课堂演示的全端点暴露、固定密码不可直接用于公开部署。

第七段：两条进阶支线，不同时硬学

原路线主线：Redis专项→RabbitMQ→Spring Cloud→学成在线。当前目录未找到这四套对应完整讲义，所以保留为待补充，不以通用介绍冒充课程总结。Spring Boot PDF中的消息部分是Kafka，不能拿来替代RabbitMQ。

本次已有扩展：Spring Boot10—12的Reactor、WebFlux、R2DBC、响应式权限。完成MVC项目后另开练习工程，使用提供的reactor代码核对。它不是学会普通后端开发的前提。

每次学习都填写这张小卡

  1. 今天解决什么问题？用一句自己的话说明。
  2. 输入与预期输出是什么？先写预期，再运行。
  3. 哪种边界输入会失败？至少试一种。
  4. 这段类比哪里不适用？把它对应回真实代码。
  5. 明天不看笔记，能否重写核心部分？不能就回查小节。

不用用连续看视频时长衡量努力。真正的进度是：你独立完成了哪个功能、解释了哪个错误、验证了哪个边界。
