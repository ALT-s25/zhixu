二、数组定义 ⭐

数组是存储相同类型数据的容器。

java
// 方式 1：先声明再分配
int[] arr1;               // 推荐
int arr2[];               // C 风格，不推荐

// 方式 2：声明并分配
int[] arr3 = new int[5];   // 默认值 0

3.4 黑马经典案例

用户输入 5 个成绩，求平均分：

java
Scanner sc = new Scanner(System.in);
int[] scores = new int[5];
int sum = 0;

for (int i = 0; i < scores.length; i++) {
    System.out.print("请输入第 " + (i+1) + " 个成绩：");
    scores[i] = sc.nextInt();
    sum += scores[i];
}

double avg = (double) sum / scores.length;
System.out.println("平均分：" + avg);

四、数组的访问

java
int[] arr = {10, 20, 30, 40, 50};

arr[0];       // 10（首元素）
arr[arr.length - 1];   // 50（末元素）
arr.length;   // 5（数组长度）

⚠ 黑马常考：

  • 数组下标范围：0 ~ length-1
  • 数组越界会抛 ArrayIndexOutOfBoundsException

5.2 两个数组指向同一对象

java
int[] a = {1, 2, 3};
int[] b = a;       // 传引用

System.out.println(a[0]);   // 100（共享对象）

5.3 黑马经典题

java
// 案例
public static void main(String[] args) {
    int[] arr1 = new int[3];
    int[] arr2 = new int[3];

    arr1[0] = 10;
    arr2[0] = 20;
    System.out.println(arr1[0]);   // 10
    System.out.println(arr2[0]);   // 20

    arr1 = arr2;            // 共享
    arr1[0] = 100;
    System.out.println(arr2[0]);   // 100
}

💡 理解：数组是引用类型，变量存的是地址。

七、数组操作

7.1 求最值

java
int[] arr = {5, 3, 8, 1, 9, 2};
int max = arr[0];
for (int i = 1; i < arr.length; i++) {
    if (arr[i] > max) max = arr[i];
}
System.out.println("最大值：" + max);   // 9

7.2 求和

java
int sum = 0;
for (int x : arr) sum += x;

7.3 查找

java
int target = 8;
int index = -1;
for (int i = 0; i < arr.length; i++) {
    if (arr[i] == target) {
        index = i;
        break;
    }
}
System.out.println(index == -1 ? "不存在" : "下标：" + index);

7.4 冒泡排序 ⭐⭐（黑马重点）

java
int[] arr = {5, 3, 8, 1, 9};

// 外层：n-1 趟
for (int i = 0; i < arr.length - 1; i++) {
    // 内层：相邻两两比较
    for (int j = 0; j < arr.length - 1 - i; j++) {
        if (arr[j] > arr[j + 1]) {
            // 交换
            int temp = arr[j];
            arr[j] = arr[j + 1];
            arr[j + 1] = temp;
        }
    }
}

System.out.println(Arrays.toString(arr));   // [1, 3, 5, 8, 9]

7.5 反转数组

java
int[] arr = {1, 2, 3, 4, 5};
for (int i = 0, j = arr.length - 1; i < j; i++, j--) {
    int temp = arr[i];
    arr[i] = arr[j];
    arr[j] = temp;
}

for (int i = 0; i < arr.length; i++) {

    System.out.println();

8.3 黑马经典案例：学生成绩

java
// 3 个学生，每个 4 门课
int[][] scores = {
    {85, 90, 78, 92},
    {76, 88, 91, 80},
    {92, 85, 87, 95}
};

// 求每名学生总分
for (int i = 0; i < scores.length; i++) {
    int sum = 0;
    for (int j = 0; j < scores[i].length; j++) {
        sum += scores[i][j];
    }
    System.out.println("学生 " + (i+1) + " 总分：" + sum);
}

十一、力扣实战 ⭐⭐

LeetCode 88. 合并两个有序数组

java
class Solution {
    public void merge(int[] nums1, int m, int[] nums2, int n) {
        int i = m - 1, j = n - 1, k = m + n - 1;
        while (i >= 0 && j >= 0) {
            if (nums1[i] > nums2[j]) nums1[k--] = nums1[i--];
            else nums1[k--] = nums2[j--];
        }
        while (j >= 0) nums1[k--] = nums2[j--];
    }
}

LeetCode 27. 移除元素

java
class Solution {
    public int removeElement(int[] nums, int val) {
        int slow = 0;
        for (int fast = 0; fast < nums.length; fast++) {
            if (nums[fast] != val) {
                nums[slow++] = nums[fast];
            }
        }
        return slow;
    }
}

十二、面试常问 ⭐

💡 数组和 ArrayList 区别？ | 数组 | ArrayList | |------|-----------| | 长度固定 | 长度可变 | | 基本类型或对象 | 只能对象（基本类型用包装类） | | 手动操作 | 自动扩容 |

💡 数组是基本类型还是引用类型？ 引用类型。变量存的是堆中数组对象的地址。
