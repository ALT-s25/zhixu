🚀 黑马视频同步学习路线（4 个月）

第 1 个月：上部 Java 基础

  • Week 1：01-03（Java 入门、基础语法、流程控制）
  • Week 2：04-05（数组、方法）
  • Week 3：06-07（面向对象基础、常用 API）
  • Week 4：08-09（面向对象进阶、内部类常用类）

第 2 个月：下部 Java 进阶

  • Week 5：10-11（��常、集合框架）
  • Week 6：12-13（IO 流、多线程）
  • Week 7：14-15（网络编程、反射与注解）
  • Week 8：16-17（Lambda/Stream、枚举与设计模式）

第 3 个月：实战练习 + 力扣

  • Week 9-10：做黑马课后小项目（学生系统、ATM、斗地主）

第 4 个月：进入 JavaWeb

  • 学习 MySQL、JDBC、Servlet、JSP
  • 学完即可做 JavaWeb 项目

💡 学习技巧（黑马风格）

  1. 每节一练：黑马每节课都有案例，一定要自己敲一遍
  2. 课后作业：每章有练习题（部分含力扣题），做完再看答案
  3. 斯坦福练习题：视频合集包含，挑选做 20~50 道
  4. 大厂面试题：视频合集包含，标记不熟悉的反复看
  5. 笔记结构：本笔记已按"项目驱动"重新组织，先看笔记再看视频更高效

🎯 学完黑马 Java 的检验标准

基础阶段

  • 能手写 9×9 乘法表、冒泡排序、二分查找
  • 能用面向对象思维设计学生类、图书类
  • 能用 String/ArrayList 完成字符串处理

进阶阶段

  • 能手写 ArrayList、LinkedList 的核心方法
  • 能解释 HashMap 的 put 流程（扩容、链表转红黑树）
  • 能手写生产者-消费者模型（wait/notify）
  • 能用反射获取类的所有信息
  • 能用 Lambda + Stream 完成集合操作

实战阶段

  • 完成学生管理系统（集合 + IO）
  • 完成 ATM 模拟（流程 + 类设计）
  • 完成斗地主（集合 + 算法）
  • 力扣做 30+ 简单/中等题

完成这些 → 黑马 Java 过关，可以进入 JavaWeb！
