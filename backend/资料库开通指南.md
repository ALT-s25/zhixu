# 知序资料库：开通与使用

这一版包含资料上传、私人云端书架、管理员发布、回收站和全文搜索。AI 问答未接入，不需要模型 API 密钥。

## 第一步：上传网站更新

将更新包解压，把里面的文件和文件夹上传到 GitHub 仓库根目录，保留 `backend/`、`vendor/library/` 目录结构，覆盖同名文件。不要把 ZIP 本身作为网站文件上传。

这次不会移动或覆盖已经整理好的 `assets/images/notes/` 图片，也不会修改笔记正文。

等待 GitHub Pages 部署完成后，访问：

https://alt-s25.github.io/zhixu/library.html

原有笔记的全文搜索可以直接使用。云端资料需要继续完成下面两步。

## 第二步：创建资料库

1. 打开你现有的 Supabase `zhixu` 项目。
2. 进入 SQL Editor，新建查询。
3. 将本文件旁边的 `library.sql` 全部复制进去，点击 Run。
4. 出现成功提示即可。脚本可以重复运行，不会清空刷题记录。

脚本会创建资料表、管理员名单、保存和搜索函数，以及一个名为 `zhixu-library` 的**私人 Storage 存储桶**。请保持该桶为 Private，不要改成 Public。

## 第三步：指定管理员

先在网站上注册并登录你的邮箱账号。然后在 Supabase SQL Editor 单独运行下面这段，把邮箱替换成你自己的真实登录邮箱：

```sql
insert into public.zhixu_library_admins (user_id)
select id from auth.users
where email = '替换成你的登录邮箱'
on conflict do nothing;
```

检查是否设置成功：

```sql
select u.email
from public.zhixu_library_admins a
join auth.users u on u.id = a.user_id;
```

列表应只有你明确授予权限的管理员。没有查到邮箱时，先确认该邮箱已在网站注册，以及拼写和大小写与 Authentication → Users 中一致。

刷新资料工作台，顶部应显示“管理员已登录”。普通用户可以管理自己的私人资料，不能自己给自己授予管理员身份。管理员也不能直接读取其他用户的私人草稿。

## 第四步：补充登录回跳地址

在现有 Authentication 的 URL Configuration 中，保留原地址，并在 Redirect URLs 新增：

```text
https://alt-s25.github.io/zhixu/library.html
```

如果在本地测试，再单独添加你实际使用的本地地址，例如 `http://localhost:8765/library.html`。

邮箱验证码在当前页面验证；邮件登录链接、确认和找回密码需要正确配置回跳地址。继续使用原来的 SMTP 配置，无需重新创建项目。

## 怎么使用

### 收录资料

1. 点击“收录新资料”。可选择 Markdown、TXT、PDF，也可选择带配图的 ZIP。
2. 等待解析完成。点击左侧每篇笔记，检查标题、专题、正文和缺图提示。
3. 如果缺图，建议补齐文件后重传；也可明确勾选允许保存现有内容。
4. 登录后点击“保存到我的云端书架”。所有新资料都是私人草稿，不会自动公开。
5. 在“云端书架 → 我的资料”打开阅读或编辑。

带配图的 ZIP 示例：

```text
Java/
  集合.md
  assets/
    hashmap.png
```

Markdown 中使用 `![示意图](assets/hashmap.png)`。PNG、JPEG、GIF、WebP 可作为配图；SVG、HTML、脚本和嵌套 ZIP 不作为附件导入。外链图片默认不自动加载，请下载合法可使用的配图并放进 ZIP。

每批最多 30 篇正文、160 个文件，单文件最多 10 MB，解压后总计最多 40 MB；单篇正文提取文字最多 2 MB，配图最多 100 张，PDF 最多 150 页。个人资料表当前最多 500 篇（含回收站）。

PDF 保存原文件并提取可搜索文字。扫描件会提示缺少可提取文字；本版没有 OCR。PDF 原版通过短期链接打开，链接过期时重新打开该资料即可。加密 PDF 请先解密再导入。

### 发布与维护

管理员打开自己的资料后，可点击“发布给所有人”。确认后，所有访客可在云端公开书架和全文搜索中访问。公开资料通过 Supabase 动态读取，不需要每次重新上传 GitHub。

“取消公开”将资料转回私人草稿。“移入回收站”是可恢复操作，附件会保留；到“我的回收站”恢复。已经签发的附件链接最长还有 60 秒有效期；别人已经下载的内容无法收回。

修改公开资料需要管理员权限。若另一台设备先保存了修改，系统会提示版本冲突，不会悄悄覆盖；保留自己的文字，重新打开最新资料后再编辑。

### 全文搜索

输入关键词，选择搜索范围：站内原有笔记、云端公开资料、自己的云端资料或所有可访问内容。支持中文、英文和字面短语，不要求标题包含关键词。

结果显示命中片段。站内文章跳转到对应章节，原有 PDF 跳转到对应页；云端笔记打开后高亮关键词。每轮最多显示 30 条站内结果和 30 条云端结果，云端可继续加载。静态索引首次加载约 4 MB，后续复用浏览器内存。

现有 122 份站内资料使用随网站打包的正文索引。后续通过云端上传的内容保存后即可搜索。若你继续手工向 GitHub 增加静态笔记，需要重新生成 `library-search-index.json`。

### 旧“导入中心”和新“资料工作台”的区别

- `import.html`：原来的题单和简单笔记导入，保存在当前浏览器，备份方式保持不变。
- `library.html`：这次新增的云端笔记管理，支持 PDF / ZIP 与账号隔离。
- 旧本地资料不会未经确认自动上传；如需上云，请在新工作台重新选择原始笔记文件。
- 本次未实现题单的云端同步，也没有 Word / Excel 解析。

## 开通后验收

1. 用账号 A 上传一篇私人笔记，重新打开页面确认仍在。
2. 退出登录或使用账号 B，确认不能通过链接读取 A 的私人笔记。
3. 用管理员发布一篇资料，退出登录后确认能阅读和搜索。
4. 取消发布后，匿名刷新该资料应无法访问。
5. 上传带图 ZIP，确认图片显示；上传缺图 ZIP，应出现明确提示。
6. 上传文字型 PDF，搜索其中一个词，确认命中后能打开原文件。

## 常见问题

- **“资料库尚未开通”**：确认 `library.sql` 已成功执行，等待 Supabase schema cache 刷新后重试。
- **登录后没有发布按钮**：确认管理员名单包含当前账号，然后刷新页面。
- **上传部分失败**：已成功的资料不会重复上传；失败项显示原因，可以重试。若网络或账号切换导致清理未完成，在“我的资料”检查未完成的草稿，移入回收站后重新上传。
- **相同内容已存在**：同一账号按原始正文与附件的摘要去重。要重新导入，先将旧资料移入回收站；正常修改请直接编辑原资料。
- **搜索不到扫描 PDF**：没有文字层的 PDF 需要额外 OCR，本版不会假装已经提取成功。
