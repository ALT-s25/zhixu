## 今天先种下一道题

打开题单，三千道题迎面而来，学习的热情可能先被滚动条劝退。

知序想让开始变得容易一点：找到当前要学的专题，读懂一个例子，动手做一道题，再给今天留下一片小叶子。卡住时翻翻模板和笔记，做完后看看自己的积累。今天只做一道，也算认真向前走了一步。

这里适合准备数据结构课程、算法考试和技术面试的同学，也欢迎每一位想把刷题坚持下去的人。

## 三步开启冒险

1. **选一条路。** 想打基础就从课程题单开始，准备面试可以先看 Hot 100，系统学习可以沿着专题逐节练习。
2. **定一个够得着的目标。** 每天 1 / 3 / 5 / 10 题，自行选择。看懂思路后亲手写一遍，再标记完成，记下自己的卡点。
3. **回来看看小芽。** 收藏待复习的题，把完成记录留在成长页。难题可以明天再战，今天的努力已经记下了。

题目链接会带你前往原平台做题与提交，知序负责整理路线、讲解方法和记录进度。

## 你的进度，有自己的位置

- **先逛再登录：** 游客记录保存在当前浏览器；登录后使用个人账号记录，游客数据可以主动导入。
- **邮箱验证码：** 已有邮箱验证后进入原账号，新邮箱验证成功后自动注册；同时保留密码登录与找回密码。
- **云端保存：** 登录状态下同步练习记录，换设备后登录同一账号读取。修改后请留意同步状态。
- **随手备份：** 支持 JSON 导入、导出，成长页也提供备份入口。
- **同一道题只算一份积累：** 跨专题共享进度、收藏和题目笔记，反复勾选不会刷出额外的独立题数量。

历史导入记录不会被凭空补上练习日期。成长统计从实际记录出发，徽章慢慢解锁就好。

> 手机短信与微信登录尚未接入；当前提供邮箱登录方式。

## 在自己电脑上运行

前端使用原生 HTML、CSS 和 JavaScript，无需 npm 安装或构建。

下载仓库，在项目根目录打开终端。如果已安装 Python，可运行：

```bash
python -m http.server 8765
```

然后访问 `http://localhost:8765/`。静态页面可本地浏览；账号功能需要网络及有效的 Supabase 配置，认证回跳地址也需要与本地地址匹配。

## 部署自己的知序

前端由 GitHub Pages 托管，Supabase 提供账号与个人记录存储。

1. 将完整网站文件放到自己的仓库根目录。
2. 在 GitHub 的 **Settings → Pages** 中选择从 `main` 分支的根目录发布。
3. 如需自己的账号系统，创建 Supabase 项目，执行 [数据库脚本](backend/schema.sql)。
4. 在 `cloud-config.js` 中填写自己的 Project URL 与 Publishable key，并配置网站地址、认证回跳地址和 SMTP 发信服务。
5. 按 [邮箱验证码与其他登录方式说明](backend/验证码与其他登录方式.md)配置邮件模板，再测试注册、登录及记录保存。

**Fork 后请更换为自己的 Supabase 项目配置。** 前端只放公开密钥；SMTP 授权码、数据库密码和服务端密钥应保留在服务端配置中。记录表启用了行级权限，账号只能访问自己的记录。
