# 知序 · 算法研习室

静态算法学习与练习网站。包含课程题单、官方 Hot 100，以及直接从灵茶山艾府在力扣发布的 12 份原文整理的完整题单快照。

截至 2026-11-02，灵神题单包含 **3717 条力扣题目引用 + 1 条 Codeforces 补充题引用，2832 道独立题**。加上原课程题与旧版补充，共 **2964 道独立题**。跨专题同一题共享进度、收藏和笔记；同题多次出现在原文时保留练习位置。完整指本次快照，作者后续更新以各专题原文为准。

## 学习体验

- 12 个专题的方法地图、24 道例题分步推演、29 份可复制 C++17 模板。
- 适用前提、复杂度、易错点与后续练习；每个专题附原作者题单链接。
- 专题 / 小节两级折叠，按需显示题目；支持搜索、难度、完成状态、收藏与备考重点筛选。
- 会员题、原文难度分、Hot 100 标识；考试与面试等级为备考优先级估计，不是真实出题频次。
- 深浅主题、算法轨道动效、例题步骤交互、动效开关，尊重系统减少动态效果设置。
- JSON 备份；兼容旧 LCR / LCP 编号并保留、合并笔记。进度只保存在当前浏览器，换网址或设备需要导出再导入。

## 运行与部署

无需构建或安装依赖。保持所有文件在同一目录，打开 index.html，或部署到 GitHub Pages 等静态托管服务。HTTPS 环境支持一键复制；不支持剪贴板权限时可手动选中代码复制。
