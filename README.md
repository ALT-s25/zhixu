# 知序 · 数据结构练习册

一个无需安装依赖的静态刷题清单。按数据结构课程的 7 个章节组织练习，并在「09 · Hot 100」中收录完整的力扣热题 100。当前共 **550 道独立题目**，跨章节的同一道题共享进度、收藏和笔记。

## 功能

- 按题号、名称或考点搜索，结合难度、完成状态和备考重点筛选。
- 完成勾选、收藏、逐题笔记，以及 JSON 进度备份导入导出。
- 每题展示官方考点标签、Hot 100 标记及考试 / 面试参考等级。
- 随机挑选当前筛选范围内的未完成题目，直接跳转力扣练习。
- 深浅主题、进度环、轻量动画和手机布局；支持减少动态效果的系统偏好。

## 使用

下载本仓库并解压，保持文件在同一目录，双击 `index.html` 即可使用。无需构建、后端或数据库，也可将这些文件部署到静态网站托管服务。

题目链接和在线字体需要网络；在线字体不可用时会使用本机字体。

完成状态、收藏和笔记存储在当前浏览器的 `localStorage` 中，**不会自动跨浏览器、设备或网址同步**。清理浏览器数据可能丢失记录；本地文件的存储行为也因浏览器而异。请定期使用「导出进度」，更换设备或访问地址时再通过「导入备份」恢复。

## 数据与考频说明

课程题单整理自《数据结构相关力扣习题题目列表 - 260910.xlsx》，涵盖线性表、栈和队列、串 / 数组和广义表、树和二叉树、图、查找、排序。

考点采用力扣官方题目标签；Hot 100 依据[官方「LeetCode 热题 100」学习计划](https://leetcode.cn/studyplan/top-100-liked/)整理，核对日期为 **2026-10-28**。

「考试参考」「面试参考」的高 / 中 / 低等级是根据课程关联度、难度和经典题覆盖作出的**备考优先级估计，不是真实出现频率、概率或统计排名**。每道题的「考频依据」提供具体说明；Hot 100 入选也不代表企业面试次数。

## 文件结构

| 文件 | 内容 |
| --- | --- |
| `index.html` | 页面结构与数据说明 |
| `style.css` | 基础样式、主题、动画与响应式布局 |
| `enrichment.css` | 考点、参考等级与 Hot 100 的补充样式 |
| `app.js` | 搜索、进度、笔记、备份及其他交互 |
| `data.js` | 章节与题目数据 |
| `metadata.js` | 考点、Hot 100 归属、参考等级及依据 |
