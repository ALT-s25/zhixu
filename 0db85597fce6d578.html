二、为什么需要数据库

没有数据库之前：数据存在文件（Excel、txt）里，查找慢、修改难、无法多人共享。

有数据库之后：

  • 数据结构化存储（表格形式）
  • 支持快速查询（SQL 语言）
  • 支持多用户并发访问
  • 支持事务（保证数据一致性）

三、数据库分类

3.1 关系型数据库（RDBMS）

数据以表格形式存储，表与表之间有关系。

代表产品：MySQL、Oracle、SQL Server、PostgreSQL

text
用户表（user）          订单表（order）
+----+-------+         +----+---------+--------+
| id | name  |         | id | user_id | amount |
+----+-------+         +----+---------+--------+
| 1  | 张三  |         | 1  |    1    |  100   |
| 2  | 李四  |         | 2  |    1    |  200   |
+----+-------+         +----+---------+--------+
                       通过 user_id 关联用户表

3.2 非关系型数据库（NoSQL）

数据以键值对、文档等形式存储。

代表产品：Redis（键值）、MongoDB（文档）、Elasticsearch（搜索）

3.3 两者对比

关系型 非关系型
数据格式 表格 多种（KV/文档/图）
事务 完整 ACID 部分支持
查询 SQL 标准 各异
适合 业务数据 缓存、搜索

四、MySQL 安装

4.1 Windows 安装（图形界面）

注意事项（先看，避免翻车）：

  • ⚠ 安装目录不能有中文和空格（如 D:\MySQL）
  • ⚠ 用管理员身份运行安装程序
  • 安装完成后记住 root 密码（后面连不上很麻烦）

安装步骤：

  1. 下载 MySQL Installer：https://dev.mysql.com/downloads/installer/
  2. 双击运行，选择 Custom 自定义安装
  3. 选择 MySQL Server 8.0.x
  4. 设置安装目录（无中文无空格）
  5. 设置 root 密码（建议 root1234 或自定义）
  6. 完成安装

验证安装：

bash
# 打开 cmd，输入：
mysql -uroot -p
# 输入密码，看到 mysql> 提示符说明安装成功

4.2 Docker 安装（推荐）

bash
docker run -d \
  --name mysql \
  -p 3306:3306 \
  -e MYSQL_ROOT_PASSWORD=root1234 \
  -v /data/mysql:/var/lib/mysql \
  mysql:8.0

4.3 常见安装报错

报错 1：服务启动失败

text
原因：安装目录有中文或空格
解决：卸载重装，选择无中文无空格的路径

报错 2：1045 Access denied

text
原因：密码错误
解决：
1. 停止 MySQL 服务
2. 以 --skip-grant-tables 启动
3. 修改密码
4. 重启服务

报错 3：ERROR 2003 Can't connect to MySQL server

text
原因：MySQL 服务未启动
解决：services.msc 中启动 MySQL 服务
     或命令行：net start mysql80

五、MySQL 目录结构

text
MySQL 安装目录（如 D:\MySQL\MySQL Server 8.0）
├── bin/           ← 可执行文件（mysql.exe、mysqld.exe）
├── data/          ← 数据文件（每个数据库一个文件夹）
├── include/       ← 头文件
├── lib/           ← 库文件
└── share/         ← 字符集、语言等配置文件

六、基础 SQL 操作（连接 MySQL）

6.1 命令行连接

bash
# 连接本地 MySQL
mysql -uroot -p

# 连接指定主机
mysql -h 127.0.0.1 -P 3306 -uroot -p

# 连接并直接选择数据库
mysql -uroot -p test_db

6.2 常用命令行操作

sql
-- 查看所有数据库
SHOW DATABASES;

-- 创建数据库
CREATE DATABASE mydb;
CREATE DATABASE mydb CHARACTER SET utf8mb4;

-- 选择数据库
USE mydb;

-- 查看当前数据库
SELECT DATABASE();

-- 查看所有表
SHOW TABLES;

-- 退出
EXIT;
-- 或
QUIT;

八、SQL 语言分类

分类 全称 说明
DDL Data Definition Language 数据定义：CREATE、DROP、ALTER
DML Data Manipulation Language 数据操作：INSERT、UPDATE、DELETE
DQL Data Query Language 数据查询：SELECT
DCL Data Control Language 权限控制：GRANT、REVOKE

九、面试常问

💡 MySQL 和 Oracle 的区别？ MySQL：开源免费，轻量，互联网首选；Oracle：商业收费，功能强，企业级首选。

💡 数据库、数据库系统、数据库管理系统的区别？

  • 数据库（DB）：存储数据的仓库
  • 数据库管理系统（DBMS）：管理数据库的软件（如 MySQL）
  • 数据库系统（DBS）：DB + DBMS + 管理员

💡 MySQL 的默认端口？ 3306
