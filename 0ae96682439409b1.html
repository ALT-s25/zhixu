二、微服务基础 ⭐

2.1 单体架构 vs 微服务架构

单体架构 微服务架构
耦合 高 低
部署 简单 复杂
升级 全量发布 单服务发布
扩展 整体扩展 按需扩展
技术 统一 自由选型
适合 小团队、简单业务 大团队、复杂业务

2.2 微服务拆分原则

  • 单一职责：每个服务只做一件事
  • 面向服务：对外暴露接口
  • 高内聚低耦合：内部集中，外部解耦
  • 尽量避免跨服务事务（使用分布式事务）

2.3 SpringCloud 技术栈

功能 新版（推荐） 旧版
注册中心 Nacos Eureka
配置中心 Nacos SpringCloudConfig
远程调用 Feign Ribbon+RestTemplate
网关 Gateway Zuul
服务保护 Sentinel Hystrix
分布式事务 Seata -

3.1 核心概念

text
服务提供者（Provider）→ 注册到 Eureka Server
服务消费者（Consumer）→ 从 Eureka 拉取服务列表 → 负载均衡 → 调用 Provider

  application:
    name: eurekaserver

  client:
    service-url:
      defaultZone: http://127.0.0.1:10086/eureka
java
@SpringBootApplication

public class EurekaApplication { }

四、Nacos 注册中心 ⭐⭐⭐（推荐）

4.1 Nacos vs Eureka ⭐

Nacos Eureka
健康检测 支持客户端/服务端主动检测 客户端心跳
实例类型 临时实例 + 永久实例 临时实例
下线推送 主动推送变更消息 定时拉取
CP/AP 临时 AP，永久 CP AP

💡 Nacos 临时实例（ephemeral=true）走 AP 保高可用；永久实例走 CP 保一致性。

4.2 服务注册到 Nacos

xml
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
</dependency>
yaml
spring:
  cloud:
    nacos:
      server-addr: localhost:8848
  application:
    name: userservice

4.3 服务分级存储模型

text
服务（userservice）
  └── 集群（HZ 杭州）
  │      ├── 实例 1
  │      └── 实例 2
  └── 集群（BJ 北京）
         └── 实例 3

同集群优先：同一集群内先负载均衡，本集群不可用才跨集群。

yaml
spring:
  cloud:
    nacos:
      discovery:
        cluster-name: HZ    # 所属集群
yaml
# 负载均衡策略（同集群优先）
userservice:
  ribbon:
    NFLoadBalancerRuleClassName: com.alibaba.cloud.nacos.ribbon.NacosRule

4.4 Nacos 权重配置

yaml
# Nacos 控制台直接修改实例权重（0~1）
# 权重 0 → 完全不接收流量（灰度发布）

4.5 环境隔离（Namespace）

yaml
spring:
  cloud:
    nacos:
      discovery:
        namespace: dev  # 开发环境
        group: DEFAULT_GROUP

⚠ 不同 Namespace 的服务完全隔离，无法相互调用。

五、Ribbon 负载均衡 ⭐⭐

5.1 负载均衡原理

text
RestTemplate 发请求 → LoadBalancerInterceptor 拦截
  → ILoadBalancer 获取服务列表
  → IRule 选择服务实例
  → 发送实际请求

5.2 内置负载均衡策略

策略类 描述
RoundRobinRule 轮询（默认）
RandomRule 随机
RetryRule 轮询 + 重试
WeightedResponseTimeRule 响应时间加权
BestAvailableRule 请求量最少
NacosRule Nacos 权重 + 同集群优先
yaml
# 全局配置（application.yml）
# 或针对某服务配置
userservice:
  ribbon:
    NFLoadBalancerRuleClassName: com.netflix.loadbalancer.RandomRule

5.3 饥饿加载

yaml
ribbon:
  eager-load:
    enabled: true
    clients: userservice  # 启动时就加载，而非第一次请求时

六、Feign 远程调用 ⭐⭐⭐

6.1 Feign vs RestTemplate

java
// RestTemplate（繁琐）
String url = "http://userservice/user/" + order.getUserId();
User user = restTemplate.getForObject(url, User.class);

// Feign（优雅）
@FeignClient("userservice")
public interface UserClient {
    @GetMapping("/user/{id}")
    User findById(@PathVariable("id") Long id);
}

6.2 快速入门

xml
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-openfeign</artifactId>
</dependency>
java
// 启动类添加注解
@EnableFeignClients
@SpringBootApplication
public class OrderApplication { }

// 定义 Feign 客户端
@FeignClient("userservice")
public interface UserClient {
    @GetMapping("/user/{id}")
    User findById(@PathVariable("id") Long id);
}

// 注入并使用
@Autowired
private UserClient userClient;

public Order findById(Long id) {
    Order order = orderMapper.findById(id);
    User user = userClient.findById(order.getUserId());
    order.setUser(user);
    return order;
}

6.3 Feign 自定义配置

yaml
feign:
  client:
    config:
      default:                 # default = 全局，或填服务名 = 针对某服务
        loggerLevel: FULL      # NONE/BASIC/HEADERS/FULL
        connectTimeout: 5000
        readTimeout: 5000

日志级别：

  • NONE：不记录（默认）
  • BASIC：请求方法、URL、响应码
  • HEADERS：BASIC + 请求头
  • FULL：所有

6.4 Feign 性能优化

默认用 URLConnection，改为 HttpClient / OkHttp（连接池）：

xml
<dependency>
    <groupId>io.github.openfeign</groupId>
    <artifactId>feign-httpclient</artifactId>
</dependency>
yaml
feign:
  httpclient:
    enabled: true
    max-connections: 200
    max-connections-per-route: 50

text
hmall

七、Nacos 配置管理 ⭐⭐⭐

7.1 统一配置管理

优势：修改配置无需重启服务，配置集中管理。

text
Nacos 控制台 → 添加配置文件
  dataId = service-name.yaml（或 service-name-env.yaml）
  group = DEFAULT_GROUP
  config = 配置内容

7.2 微服务拉取 Nacos 配置

xml
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-config</artifactId>
</dependency>
yaml
# bootstrap.yaml（优先于 application.yaml 加载）
spring:
  application:
    name: userservice
  profiles:
    active: dev
  cloud:
    nacos:
      server-addr: localhost:8848
      config:
        file-extension: yaml

💡 配置文件优先级：Nacos 远程配置 > 本地 application.yaml

7.3 配置热更新 ⭐

方式一：@RefreshScope

java
@RestController
@RequestMapping("/user")
@RefreshScope   // 加这个注解
public class UserController {

    @Value("${pattern.dateformat}")
    private String dateformat;

    @GetMapping("/now")
    public String now() {
        return LocalDateTime.now().format(DateTimeFormatter.ofPattern(dateformat));
    }
}

方式二：@ConfigurationProperties（推荐）

java
@Component
@ConfigurationProperties(prefix = "pattern")  // 自动热更新，无需 @RefreshScope
@Data
public class PatternProperties {
    private String dateformat;
    private String envSharedValue;
}

7.4 配置共享优先级

text
Nacos [service-dev.yaml]
  > Nacos [service.yaml]（所有环境共享）
  > 本地 application-dev.yaml
  > 本地 application.yaml

八、Gateway 服务网关 ⭐⭐⭐

8.1 网关作用

text
客户端
  ↓
Gateway（网关）
  ├── 路由转发（到哪个服务）
  ├── 负载均衡
  ├── 身份认证
  ├── 请求限流
  └── 请求/响应修改
  ↓
微服务（order/user/product...）

8.2 快速入门

xml
<dependency>
    <groupId>org.springframework.cloud</groupId>
    <artifactId>spring-cloud-starter-gateway</artifactId>
</dependency>
<dependency>
    <groupId>com.alibaba.cloud</groupId>
    <artifactId>spring-cloud-starter-alibaba-nacos-discovery</artifactId>
</dependency>
yaml
server:
  port: 10010

spring:
  application:
    name: gateway
  cloud:
    nacos:
      server-addr: localhost:8848
    gateway:
      routes:
        - id: user-service
          uri: lb://userservice      # lb:// 表示负载均衡
          predicates:
            - Path=/user/**          # 路径断言
        - id: order-service
          uri: lb://orderservice
          predicates:
            - Path=/order/**
      default-filters:
        - AddRequestHeader=Truth,BlackHorse is a great school

8.3 断言工厂（Predicates）

断言工厂 示例 说明
Path - Path=/user/** 路径匹配
After - After=2037-01-20T... 时间之后
Before - Before=2031-04-13T... 时间之前
Header - Header=X-Request-Id,\d+ 请求头
Query - Query=name,Jack 请求参数
Method - Method=GET,POST 请求方式

8.4 过滤器（Filters）⭐

yaml
filters:
  - AddRequestHeader=X-Request-Id,100     # 添加请求头
  - RemoveRequestHeader=Authorization     # 删除请求头
  - RewritePath=/red(?<segment>.*), $\{segment}  # 重写路径
  - SetStatus=401                          # 设置响应状态
  - StripPrefix=1                          # 去掉路径前缀

8.5 全局过滤器（自定义认证）⭐⭐

java
@Component
@Order(-1)  // 优先级（数字越小越优先）
public class AuthorizeFilter implements GlobalFilter {

    @Override
    public Mono<Void> filter(ServerWebExchange exchange, GatewayFilterChain chain) {
        ServerHttpRequest request = exchange.getRequest();
        MultiValueMap<String, String> params = request.getQueryParams();

        // 获取 token
        String token = params.getFirst("authorization");

        // 校验
        if ("admin".equals(token)) {
            return chain.filter(exchange);  // 放行
        }

        // 拦截
        exchange.getResponse().setStatusCode(HttpStatus.UNAUTHORIZED);
        return exchange.getResponse().setComplete();
    }
}

8.6 过滤器执行顺序

text
请求
  ↓
DefaultFilter（default-filters）
  ↓
RouteFilter（routes 下的 filters）
  ↓
GlobalFilter（全局过滤器）

相同 order 时：DefaultFilter → RouteFilter → GlobalFilter

8.7 跨域配置（CORS）

yaml
spring:
  cloud:
    gateway:
      globalcors:
        add-to-simple-url-handler-mapping: true
        cors-configurations:
          '[/**]':
            allowedOrigins:
              - "http://localhost:8090"
            allowedMethods:
              - "GET"
              - "POST"
              - "PUT"
              - "DELETE"
              - "OPTIONS"
            allowedHeaders: "*"
            allowCredentials: true
            maxAge: 360000

九、面试常问 ⭐⭐⭐

💡 Nacos 和 Eureka 的区别？

  • Nacos 支持临时/永久实例，可主动推送变更；Eureka 只有临时实例，定时拉取
  • Nacos 支持配置管理；Eureka 不支持
  • Nacos 临时实例 AP，永久实例 CP；Eureka 只有 AP

💡 Feign 是怎么实现远程调用的？ 基于动态代理，在启动时生成接口的代理对象，调用接口方法时，拼接 URL 通过 HttpClient 发起请求。

💡 Gateway 的核心功能？ 路由转发、负载均衡、身份认证、限流、请求/响应过滤。

💡 Gateway 的过滤器执行顺序？ 同 order 时：Default > Route > Global；order 越小越先执行。

💡 Nacos 配置热更新怎么实现？ @ConfigurationProperties 自动热更新；或 @Value + @RefreshScope。
