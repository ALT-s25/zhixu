💡 学习建议

1. 先掌握 Redis 全套

Redis 是微服务项目的基石：缓存、分布式锁、会话、消息队列。

顺序：03 → 04 → 05 重点：缓存三大问题、分布式锁、Redisson

2. 再学 RabbitMQ

消息队列是解耦微服务的关键。

顺序：01 → 02 重点：可靠性、延迟消息

3. 容器化部署

Docker 是部署微服务的基础。

学习：07 重点：Compose 编排

4. 搜索引擎

ES 是电商、内容项目的搜索方案。

学习：08 重点：DSL 查询、Java 客户端

5. 微服务框架

SpringCloud 是整合上面所有技术的框架。

学习：06 重点：Nacos + Feign + Gateway
